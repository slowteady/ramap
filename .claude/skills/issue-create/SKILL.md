# 이슈 생성 절차

1. 근거 문서(docs/ 아래)를 읽는다. 근거 문서가 없으면 만들지 말고 어떤 문서를 기준으로 할지 묻는다.
2. 분할안을 목록으로만 보여 준다. GitHub에는 아직 올리지 않는다.
   - 이슈마다: 제목, 목표 한 줄, 근거 문서의 절, 충돌 주의(같은 파일을 건드리는 다른 이슈)
   - 이슈 하나는 PR 하나로 끝낼 크기로 나눈다.
3. 사용자가 승인한 항목만 GitHub MCP `issue_write`(method: create)로 만든다. 승인 없이 만들지 않는다.
4. 본문은 아래 양식을 그대로 쓴다. 근거 문서에 없는 기능이나 범위는 넣지 않는다.

## 본문 양식

```markdown
## 목표
(한두 줄)

## 범위 밖
(이번에 하지 않는 것)

## 완료 조건
- [ ] ...

## 근거 문서
docs/... (절 번호까지)

## 충돌 주의
(없으면 "없음")
```
