# 답변 규칙 (공통)

이 파일은 보일러플레이트가 원본이다. 프로젝트에서 고치지 말고 보일러플레이트에서 고친 뒤 복사한다.

기획·브레인스토밍 답변은 하나의 화면으로 보고 닐슨 휴리스틱 6개를 지킨다.

| 휴리스틱 | 답변 규칙 |
|---|---|
| 상태 보여 주기 | 첫 줄에 지금 어디까지 왔는지, 무엇이 정해졌는지 쓴다 |
| 실제 세계와 일치 | 사용자의 말로 쓴다. 내부 용어와 약어는 풀어 쓰거나 뺀다 |
| 일관성 | 같은 대상은 같은 이름으로, 같은 종류의 답은 같은 표 모양으로 쓴다 |
| 기억보다 알아보기 | 번호만 쓰지 않고 이름을 같이 쓴다 |
| 미니멀 | 결정에 필요 없는 정보는 빼고, 상세는 요청할 때 준다 |
| 오류 인식 | 확인한 것과 추측을 구분해 짧게 표시한다 |
