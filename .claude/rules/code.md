# 코드 규칙 (공통)

이 파일은 보일러플레이트가 원본이다. 프로젝트에서 고치지 말고 보일러플레이트에서 고친 뒤 복사한다.

## 꼭 지킬 것
- 코드 주석을 쓰지 않는다. 설명은 이름, 테스트, PR, 이슈, docs에 남긴다. 훅이 막고 리뷰가 지적한다. 외부에서 복사해 온 코드에 원래 있던 주석은 예외.
- 로직은 테스트를 먼저 쓴다(TDD).
- 테스트에서 외부 API를 실제로 호출하지 않는다. 저장된 응답이나 목(mock)을 쓴다.
- 토큰, 키, 비밀번호, 개인정보를 코드·로그·오류 메시지에 넣지 않는다.
- 다른 모듈의 내부 코드를 직접 가져다 쓰지 않는다.
- 색은 디자인 토큰(변수 이름)으로만 쓴다. 색 코드를 직접 쓰지 않는다.

## 이름
| 대상 | 규칙 | 예 |
|---|---|---|
| 파일 | kebab-case | `post-list-filter.tsx` |
| 컴포넌트 | PascalCase | `PostListFilter` |
| 훅 | `use`로 시작 | `use-post-filter.ts` → `usePostFilter` |
| 상수 | UPPER_SNAKE | `MAX_PAGE_SIZE` |
| 환경 변수 | UPPER_SNAKE | `DATABASE_URL` |
