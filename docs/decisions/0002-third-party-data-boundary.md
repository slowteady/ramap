# 타사 플랫폼 데이터 경계

## 맥락

매장 좌표·정보를 모으고 타사 서비스(지도사, 인스타그램, 캐치테이블 등)와 연결해야 한다. 지도사 약관 위반은 서비스 중단 사유다.

## 결정

**금지**
- 지도사(카카오·네이버·VWorld) 지오코딩 결과의 저장·DB화. 좌표는 공공데이터(LOCALDATA 인허가 좌표 등)와 운영자가 확정한 수동 핀만 저장한다. 편의상 배치로 돌려 저장하는 것도 금지.
- 네이버·카카오 플랫폼 데이터 크롤링(장소 카드 대량 수집 포함). 시딩은 공공데이터와 직접 조사만.
- 링크 너머 데이터 스크래핑(예: 실시간 대기 수 표시).
- 인스타그램 직접 조회·스크래핑(Meta 약관). 인스타 계정 확인은 검색엔진 결과(제목·소개글)만 근거로 쓴다.
- 타인 사진 사용(촬영자 저작권). 사진은 직접 촬영했거나 허락받은 것만.
- 타사 로고 사용·제휴 오인 유발. 타사 이름은 텍스트로 가리키는 데까지만.

**허용**
- 아웃바운드 링크(캐치테이블·인스타·라멘 투데이 등)와 사실 기록("원격 웨이팅 사용").
- 카카오 장소 ID·place_url 저장, 자체 확보 좌표를 카카오 지도에 마커로 표시.
- 좌표계 변환(EPSG:5174 → WGS84)은 순수 수학이라 허용.

**지오코딩 API는 도입하지 않는다(2026-09-03).** 좌표는 공공데이터 원천에 이미 들어 있다.

## 근거

- 네이버 Maps 약관 제7조 ⑪ "결과 데이터의 저장·DB화·재사용 엄격 금지".
- 카카오 데브톡 운영진 답변 3건 "실시간 호출만 허용, 제휴·유료로도 저장 검토 안 함". 장소 ID·place_url 저장과 자체 좌표 마커 표시는 허용 답변.
- VWorld 레퍼런스 "별도의 저장장치나 데이터베이스에 저장할 수 없습니다".
- Nominatim은 국내 커버리지 부족(실측 3건 중 2건 도로 중심선 폴백, 춘천 1.4km 오차) + ODbL 전염.
- 단순 링크는 저작권 침해가 아니다.
