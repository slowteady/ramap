# 실시간 "영업 중" 판정을 표시하지 않는다 — 영업시간 원문만

## 맥락

영업시간 문자열을 파싱해 "영업 종료 · 11:30 오픈" 같은 실시간 상태를 보여 주거나(2026-08-28 구현, 2026-08-31 상세 상단에 표시), 지도에 "지금 영업중" 필터를 두자는 제안(2026-10-27 지도·상세 조사 M1·D1, 백로그 P-20)이 있었다. 네이버·카카오·구글, jirolianmap이 이런 표시를 쓴다.

## 결정

- 홈 목록·매장 카드·매장 상세 어디에서도 실시간 영업 판정을 보여 주지 않는다. 영업시간 · 브레이크 · 휴무 원문만 보여 준다(`OpenStatusBadge`). 휴업은 "휴업 중", 폐업·이전은 라벨 + 변경 연월.
- "지금 영업중" 필터를 두지 않는다.
- 다시 검토하려면 데이터 최신성 기준(예: 최근 N개월 안에 확인된 매장만 판정)을 먼저 정한다.

## 근거

- 실시간 영업 여부는 알 수 없다. 등록 영업시간과 현재 시각으로 추정할 뿐이고 임시 휴무·재료 소진 조기 마감·명절이 반영되지 않는다. 오안내는 헛걸음과 신뢰 손실로 이어진다.
- "영업 종료"가 오픈 전 시간대에 폐업으로 읽히는 문제(2026-09-03 PO).
- 데이터 커버리지(2026-10-27, 영업 매장 1,301곳): 영업시간 69%, 브레이크 33%, 휴무 35%, 최종확인일 0%.
- 상세: [지도·상세 검수 조사](../research/2026-10-27-map-detail-review.md) M1·D1.
