# 공통 git 규칙으로 통일

## 맥락

라맵은 소문자 컨벤셔널 커밋(`feat:`)과 머지 커밋을 써 왔다. 보일러플레이트 공통 규칙(`.claude/rules/git.md`)은 대문자 타입과 Squash 머지다.

## 결정

- 2026-10-28 이후 커밋은 `FEAT:`·`FIX:`·`DOCS:`·`STYLE:`·`REFACTOR:`·`TEST:`·`CHORE:` 형식, PR은 Squash 머지.
- 그 전 이력은 고치지 않는다.

## 근거

- PO 결정(2026-10-28): 프로젝트마다 다른 규칙을 두지 않고 보일러플레이트를 원본으로 맞춘다.
