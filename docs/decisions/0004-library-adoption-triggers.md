# 라이브러리는 트리거가 생길 때 도입

## 맥락

흔히 쓰는 라이브러리(TanStack Query, zod, react-hook-form, 전역 스토어, framer-motion 등)를 미리 넣으면 쓰지 않는 추상화와 번들이 쌓인다.

## 결정

- 라이브러리를 미리 넣지 않는다.
- 라이브러리마다 "이 상황이 실제로 생기면 도입한다"는 트리거를 적어 두고, 트리거가 충족됐을 때 도입한다.
- 도입·미도입 현황과 트리거는 [platform 설계의 라이브러리 표](../modules/platform/design.md#라이브러리)가 원천이다. 도입하거나 트리거를 바꾸면 그 표를 같은 PR에서 고친다.

## 근거

- 검토 기록: 로그인 도입(2026-08-27) 때 TanStack Query를 재검토했으나 기록은 1회 로드 + write-through라 보류. zod·react-hook-form은 2026-09-01 검토에서 수동 내로잉·자체 훅으로 충분함을 확인.
