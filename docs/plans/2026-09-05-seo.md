# SEO 설계 — 색인 0에서 장르 쿼리 선점까지

2026-09-05, 딥리서치 3건(기술 SEO·네이버·국내 디렉토리 실측) 종합. 근거 없는 항목 없음 — 각 결정에 출처 표기. 이 문서만 읽고 다른 에이전트가 이어받을 수 있게 코드 포인터·검증 명령 포함.

## 배경과 목표

- `site:ramap.kr` 구글·네이버 색인 **0건** (2026-09-05 실측). 동명 앱 "라멥"(舊 라맵, 웹 부재·다운로드 100+)과의 경쟁에서 웹 검색이 우리의 구조적 우위인데 색인 자체가 막혀 있었다
- 색인을 막던 결함은 수정 완료(아래 "완료" 절): area 이중 인코딩 404 755개·robots.txt 부재·canonical 전무
- 목표 쿼리 우선순위 (SERP 실측 근거):
  1. **브랜드 "라맵"** — 유일하게 웹사이트 영역이 최상단에 오는 쿼리 유형(다이닝코드 대조군 실측). 현재 경쟁이 바누아투 공항(Lamap)뿐인 무주공산
  2. **장르 쿼리** ("니보시 라멘"·"이에케 라멘"·"라멘 종류") — 매장 연결 디렉토리 전무, 위키·커뮤니티 글뿐. 다이닝코드 태그에도 계보 축이 없다. 라맵 택소노미 3축이 유일 차별점. "라멘 종류"는 소규모 개인 사이트(noodleplanet.co.kr)도 이기는 영역임을 실측
  3. **지역×장르 롱테일** ("성수 츠케멘"·"홍대 이에케") — 다이닝코드 미커버 공백
  4. 비타깃: "성수 라멘" 광의 쿼리 정면승부(다이닝코드 Top29 + 리뷰 수천 건) — 단기 불가, 리스트 페이지 품질 축적 후

## 실측에서 확정된 원칙

1. **지도는 SEO에 0 기여** — Airbnb·Zillow·호갱노노 전 사례에서 색인은 지도와 분리된 텍스트 표면(SEO 랜딩)이 담당. 우리의 `/area/*`·`/style/*`·`/guide/*`가 그 표면이고 이미 SSG로 존재. 빠진 것은 **홈→랜딩 크롤러블 앵커(현재 0개)**
2. **승부처는 본문 텍스트량이 아니라 URL 설계·메타·내부링크 메시** — 다이닝코드 리스트는 SSR 50자로도 1위(ItemList 완비+태그 링크 메시). 단, 라맵은 SSR이라 다이닝코드가 CSR로 놓치는 서버 렌더 앵커텍스트까지 가져갈 수 있다
3. **빈 조합은 404가 공식 정답** — 구글 faceted-nav 공식: "no results → 404". `listAreaGenrePages(min=3)` 미생성=404 구조가 이미 부합. 유지
4. **전량 SSG라 스트리밍 메타데이터·크롤 예산 이슈 없음** (Next 공식 문서 v16.3 확인, ~2.1k 페이지는 공식 기준 미달) — 관련 최적화에 시간 쓰지 말 것
5. **네이버는 별도 트랙** — Yeti는 JS 렌더링이 2-pass·지연(공식), SSR인 우리는 유리. 소유확인 검증기는 JS 미실행. IndexNow 공식 지원 — 데이터 파이프라인에 푸시 스텝 추가가 최적

## P0 — 색인 품질 기반 (같은 브랜치, 코드 소규모)

일부는 워킹트리에 구현돼 있음(커밋 보류분). 나머지 포함 일괄:

1. **JSON-LD 이스케이프 공통화**: `toJsonLdHtml()`(`<`→`<`, Next 공식 가이드 스니펫) — 구현됨, `structured-data.ts`
2. **씬 페이지 색인 제어**: `isThinShop()`(영업시간·메뉴·스프세부·사진·한줄소개 전무 = 414곳) → 매장 metadata `robots:{index:false}` + 사이트맵 제외. 구글 scaled content 정책 대응. 데이터 보강 시 자동 복귀 — 구현됨, `derive.ts`·`shop/[slug]/page.tsx`·`sitemap.ts`
3. **브랜드 마크업**: 홈에 `WebSite`(name 라맵·alternateName Ramap — 루트 전용이 구글 요건) + `Organization` — 구현됨, `home-page.tsx`. 보완: Organization `logo`는 112px+ 요건 — icon.svg 대신 512px PNG 별도 제공 검토, 인스타 등 실운영 채널 생기면 `sameAs` 추가(네이버 연관채널 요건, "Lamap 바누아투" 중의성 해소 신호)
4. **`restaurantJsonLd` 형식 수정 3건** (구글 필수 요건): ① `address` 문자열 → `PostalAddress` 객체(+addressCountry KR) ② `openingHours`에 원문 문자열 주입 중 → 구조화 불가 형식은 생략(잘못된 형식이 더 해로움) ③ `url`·`image` 추가. `aggregateRating`은 실데이터 생기기 전 절대 금지
5. **가이드에 Article JSON-LD** (author=Organization 라맵) + **FAQ 마크업 확장 중단**(구글 2026-05·네이버 2026-07 리치결과 폐지 — 기존 잔존은 무해)
6. **루트 openGraph 보강**: `siteName`·`locale: ko_KR`·`type: website` (세그먼트 얕은 병합 주의 — 자식이 openGraph 정의 시 전체 대체)
7. sitemap 매장 항목에 `images`(사진 생기면 자동 포함)
