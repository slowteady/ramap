## 이번 라운드에서 끝난 것 (재작업 방지)

- 게재 매장 721 → **1176곳**, 전국 17개 시도. 좌표 없음 0건
- LOCALDATA **파일 서버는 생존** — `www`·`api`·`openapi`는 죽었으나 `file.localdata.go.kr`은 Referer 헤더만 있으면 인증키 없이 전국 원본(696MB)을 준다. 229만 행 → 영업 중·좌표 확보 654,190건
- 부산·대구는 지자체 포털이 LOCALDATA 미러를 무인증 제공. EPSG:5174 → WGS84 변환은 `scripts/lib/lic-convert.ts`
- **지오코딩 API는 도입하지 않기로 확정.** V-World는 레퍼런스 본문에 "별도의 저장장치나 데이터베이스에 저장할 수 없습니다" 명시 — 카카오·네이버와 동일 제약. Nominatim은 국내 커버리지 부족(실측 3건 중 2건이 도로 중심선 폴백, 춘천 1.4km 오차) + ODbL 전염. 좌표는 공공데이터 원천에 이미 들어 있으므로 변환이 필요 없다
- 파이프라인 결함 3건 교정(판정 마크 합집합 / 주소 없는 행 dedup 우회 / 동일 주소 타업소 정보 오염)

## 우선순위 1 — 제보 경로

### 1. 지도 핀 찍기 (설계 승인 완료 대기)

**문제.** 현재 위치 입력이 링크와 `[지금 보는 지도 위치 첨부]` 토글 둘뿐이고, 후자는 **시트를 열기 직전 지도 중심 좌표를 그대로 스냅샷**한다. 시트가 `fixed inset-0`으로 지도를 완전히 덮은 상태라 사용자가 조준 자체를 할 수 없다. 운영자가 그 좌표를 신뢰할 수 없다.

**레퍼런스 실측 결과** (`scratchpad/pin-refs/`)

- 카카오맵·네이버지도 제보는 앱 전용 — 모바일 웹에 진입점 없음(실측 확인)
- 구글맵은 한국에서 **주소 대신 좌표(DMS) + Plus Code**만 표시. 지도 데이터 반출 제약 때문으로, 우리 제약과 성격이 같다
- OSM 노트가 반면교사 — 패널이 위 55%를 먹어 지도가 45%로 눌린 채 "마커를 정확한 위치로 옮기라"고 요구한다

### 2. 제보 제출 조건 강화

현재 `canSubmitNew`는 `상호명 + (링크 ≥1 또는 핀 또는 사진)`이라 **사진만으로도 제출된다**. 그 경우 위치 정보가 0이라 운영자가 처리할 수 없다. 링크 또는 핀 중 최소 하나를 필수로 올린다.

## 우선순위 2 — 데이터 신뢰도

### 3. 검증 등급 가동

1176곳 **전부** `confidence: "estimated"` / `verification: "pending"`이다. 조사로 장르·메뉴·영업시간까지 확인된 매장과 상호만 아는 매장이 화면에서 구분되지 않는다.

- `scripts/enrich-candidates.ts` `verdictOf` 근처에 등급 산정을 붙인다. 판정 근거는 이미 `sourceNote`·`soupDetail`·필드 충실도로 들어와 있다
- 기준 초안: 플레이스 주소 일치 + 장르 확인 + (메뉴 또는 영업시간) → `confirmed` / 실존만 확인 → `estimated`
- 화면 노출 지점은 `docs/planning/` 스펙 확인 후 결정할 것

### 4. 무키워드 라멘집 발굴 (2차 디깅)

상가정보 `I20301 일식 회/초밥`에 전국 19,499건이 있고 회·초밥·돈까스류 상호를 걸러도 **10,658건**이 남는다. 제주 윤옥·마모루·체면·유라유라·라신비가 전부 여기 숨어 있었다. 전수 조사는 불가하므로 **디깅(지역 검색으로 이름 수집 → 인허가·상가에서 완전 일치 발굴)** 이 유일한 경로다.

- 1차 디깅은 권역당 8~12개 상권만 훑었다. 제주만 해도 애월·성산·중문·함덕이 미탐색
- 발굴 파이프라인은 `scripts/lib/merge-candidates.ts` `discoverByName`·`discoverBySanggwonName` — 완전 일치만(2자 상호 오발굴 방지)
- 배치 관례: 백그라운드 general-purpose 에이전트, **Daum 검색 WebFetch만**(WebSearch·Playwright 금지), 매장당 1~2회, 추측 금지

### 5. 폐업 의심 12건 처리

LOCALDATA 스냅샷과 현실의 시차. 이미 확인된 사례 — 호시노라멘&덮밥 자리(관악구 대학6길 14)는 현재 **코란라멘 본점**, 강릉라멘 자리(난설헌로 228-34)는 **초당모꼬지**(두부전문점). 게이트는 통과했으나 실물이 바뀐 건들이라 개별 확인이 필요하다.

### 6. 영업시간·메뉴 공백 (32% / 47%)

**조사로는 더 못 채운다.** Daum 검색 결과가 이 필드를 텍스트로 노출하지 않는 경우가 많고, 카카오 플레이스 상세 크롤링은 약관 위반이라 금지다. 지역별 수확률이 서울권 30% / 지방 0~15%로 갈린다. 제보(1·2번)와 운영자 검수(`/admin`)로 메우는 것이 원래 설계다.

### 7. 보류 77곳 — 사실상 종결

2라운드 재검증에서 매장당 최대 3회 검색을 소진하고도 웹 흔적을 못 찾은 건들. 상당수가 실제 폐업이거나 애초에 존재하지 않는 업소로 보인다. 추가 투입 대비 수확이 거의 없다.

### 8. 인허가 잔여 공백

LOCALDATA 전국본 확보로 대부분 해소됐다. 남는 것은 원천 자체의 한계 — 울산 북구는 지자체 포털이 반쯤 내려가 있고, 충남 천안·아산은 어떤 경로로도 공개 소스가 없다. LOCALDATA 웹·API가 복구되면 재확인할 것.

## 검증 명령

- `npm test` — 단위 279케이스 (scripts 파이프라인 포함)
