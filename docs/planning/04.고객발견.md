# 04. 고객 발견 / 문제 검증 (상태: H1 사실상 검증 완료, H2·H3 확인 대기)

> **2026-08-25 갱신:** 갤러리 정찰(11.커뮤니티공략 참조)에서 유저 자작 영업변동 사이트 '라멘 투데이'가 파딱 허락 공지로 고정돼 제보 루프가 실작동 중임을 확인 — H1(덕후의 불편 실재)과 H3(제보 참여 의향)의 강력한 실증. 인터뷰는 H2(불편의 구체 형태·장르 필터 수요) 확인용으로 축소.

## 검증할 가설

- **H1 (핵심):** 코어 덕후는 장르·속성 기준 탐색을 원하는데 현재 수단(저장 리스트, 갤러리 스크랩)에 실질적 불편을 느낀다
- **H2:** 불편의 구체 형태는 "장르 필터 부재, 리스트 공유·통합 불가, 신규 오픈 추적 어려움"이다 (추정 — 검증 필요)
- **H3:** 신뢰할 만한 DB가 있으면 덕후는 제보·검증에 참여한다

## 방법: The Mom Test — 친구 네트워크로 덕후 5~7명과 대화

**묻는다 (과거 행동):**
- "지난번에 안 가본 라멘집 새로 찾았을 때 어떻게 찾았어?"
- "가려고 저장해둔 집들 어떻게 관리해? 보여줄 수 있어?"
- "최근에 찾다가 빡쳤던 적 있어?"
- "신규 오픈은 어디서 알게 돼?"

**묻지 않는다 (미래 가정):**
- "이런 앱 있으면 쓸 거야?" → 전원 "쓸 듯"이라 답함, 무가치
- "어떤 기능 있으면 좋겠어?" → 솔루션을 유저에게 묻는 책임 전가

## 판정 기준 (사후 합리화 방지용 사전 확정)

- 5명 중 **3명 이상**이 묻지 않았는데 스스로 탐색·관리 불편을 언급 → H1 통과
- 전원 "네이버 저장으로 충분" → 덕후용 아닌 2인용 토이로 강등, 트래픽 목표 철회
