# 19. 백로그 — 기능·데이터·성장 후보의 단일 원천

**앞으로 할지 말지 정할 후보는 여기에만 둔다.** 날짜별 `docs/plans/*` 문서는 조사·작업 기록(근거)이고, 후보의 현재 상태는 이 표가 기준이다. 상태가 바뀌면 이 문서의 해당 행을 고치고, 근거 문서 링크를 남긴다.

상태: `대기`(검토 전) · `채택`(할 것) · `보류`(조건 충족 시 재검토) · `기각`(하지 않음, 사유 기록) · `완료`

최종 정리: 2026-10-27 (흩어져 있던 `plans/2026-09-03-backlog`, `plans/2026-09-05-benchmark`, `plans/2026-10-05-data-refresh` TODO, `plans/2026-10-27-map-detail-research`, `planning/14` 2·3단을 통합)
