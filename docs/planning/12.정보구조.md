# 12. 정보 구조 (IA) · 내비게이션 — 확정

확정일: 2026-08-26. 근거: 동종 니치 버티컬 맵 7개 서비스 내비 실측 (라멘GPS·라멘투데이·포카맵·워시맵·다이브인포·BlackRoad·ramendb).

## 실측에서 도출한 원칙

1. 살아있는 서비스의 내비 공식: **코어 뷰 1 + 참여 1 + 차별화 콘텐츠 1~2** (3~4개가 스윗스팟)
2. **필터는 메뉴가 아니라 코어 뷰 안의 컨트롤** (워시맵 칩, 다이브인포 필터바)
3. **유저 기여는 메뉴가 아니라 버튼으로 승격** (라멘투데이 "제보하기", 워시맵 "➕등록"). 라벨은 2026-08-31 재실측으로 "라멘집 등록" 확정 — 13번 A-2 참조
4. 메뉴 수와 데이터 깊이는 반비례 (BlackRoad 19개 메뉴 = 전부 얕음, 반면교사)
5. 지도형 서비스는 **홈=지도** (라멘GPS·포카맵·워시맵 공통). 랭킹·이벤트류 메뉴는 데이터 축적 후의 것 (ramendb 6개 메뉴는 30년 도착점)

## 내비게이션 (확정)

```
[라맵 로고]   지도(홈)   신규 오픈   [라멘집 등록 버튼]
```

- 장르 가이드는 메뉴 제외 — 필터·매장 페이지에서 컨텍스트 링크로만
- 랭킹·어워드 메뉴는 3막에 추가

## 라우트 맵 (확정)

| 라우트 | 성격 | 진입 경로 |
|---|---|---|
| `/` | 홈 = 지도 뷰 + 하단 SSR 콘텐츠 섹션 | 직접 방문, 내비 |
| `/new` | 신규 오픈 | 내비 |
| `/?report=new` | 새 라멘집 등록 시트 (구 `/report`는 리다이렉트) | 버튼 |
| `/shop/{slug}` | 매장 상세 (SSR, SEO 단위) | 지도·리스트·검색 |
| `/{지역}/{스프계열}` | 지역×장르 리스트 (SEO 엔진) | 검색 착지 |
| `/style/{계보}` | 계보 랜딩 (이에케이·지로계) | 검색 착지 |
| `/guide/{장르}` | 장르 가이드 | 컨텍스트 링크, 검색 착지 |

- SEO 착지 페이지(하단 4개)는 내비에 없음 — 검색이 입구
- 홈이 순수 SPA면 크롤러에 콘텐츠가 없으므로, 지도 아래 SSR 섹션(신규 오픈·지역별 바로가기) 필수 — 포카맵·워시맵과의 차이점 (그들은 SEO 안 함, 우리는 SEO가 엔진)
