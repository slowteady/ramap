# 05. 가치 제안

## 한 문장

> **"한국 라멘을 장르로 찾는 지도"** — 라멘 덕후가 실제로 고르는 기준 그대로 전국 라멘집을 필터하는, 검증된 라멘 전문 DB.

포지셔닝: "일본에 30년 있던 것(ramendb)의 한국 첫 버전."

## 기존 대안 대비

| 기존 대안 | 못 하는 것 | 라맵 |
|---|---|---|
| 네이버/카카오 지도 | "라멘" 검색만, 장르 축 없음 | 장르·면·스프·주문방식 필터 |
| 라멘GPS | 데이터 얕음, 검증 없음, 신뢰 0 | 라오타 감수 태깅 + 제보·검증 루프 |
| 갤러리 자작 지도 | 갱신 안 됨, 필터 불가 | 지속 갱신되는 구조화 DB |
| 인스타 저장·블로그 | 파편화, 검색 불가 | "성수 이에케이" 조합 검색 |

## 해자 (차별화의 원천)

1. **택소노미** — ramendb 30년 분류 체계의 한국화. 네이버가 못 베끼는 게 아니라 **만들 이유가 없는** 축
2. **검증된 태깅 (2층 데이터)** — 장르 판별은 라오타만 가능. 데이터 자체가 해자
3. **신규 오픈 추적** — 덕후 최대 관심사이자 재방문 훅

## 의도적으로 안 하는 것 (YAGNI)

- 리뷰·평점 — 콜드스타트 함정, 3막 이후
- 예약·주문 연동 — 수익 목표 아님
- 앱 — 웹 우선, SEO가 트래픽 엔진이므로
