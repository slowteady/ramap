# 06. 비즈니스 모델 (무수익 지속 구조)

## 전제

수익은 목표가 아님. 이 단계의 질문은 "수익 없이 성립하는가" — 답은 비용 구조.

## 비용 구조

| 항목 | 금액 |
|---|---|
| 지도 API | 0원 (카카오 JS SDK 무료 쿼터, 초과 시 차단형 — 과금 불가 구조) |
| 호스팅 | 0원 (Vercel/Cloudflare 무료 티어) |
| 도메인 ramap.kr | ~2만 원/년 |
| 데이터 구축·유지 | 팀의 시간 (실질 비용) |

**연 2만 원 + 노동 = 수익 압박 없이 무기한 지속 가능.** 사이드 프로젝트 사망 원인 2위(서버비 부담)를 원천 제거.

## 수익화 옵션 (설계만, 켜지 않음)

- 애드센스 배너 — 카카오 약관 위반 아님 공식 확인됨 (상업 활용 시 비즈앱 전환 권고). 참고: 월 10만 PV여도 월 수만 원 수준 — UX를 해칠 가치 없음
- 어워드 스폰서 (3막)

## 성공 지표 (수익 대신 — 9단계 측정 기준선)

1. **월 오가닉 검색 유입** — SEO 엔진 작동 여부
2. **유저 제보 건수** — 3층 데이터 루프 작동 여부
3. **커뮤니티 자발 언급** — 갤러리·트위터에서 "라맵" 등장 여부 (라멘GPS가 0이었던 지표)
