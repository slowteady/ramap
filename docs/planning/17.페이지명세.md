# 17. 페이지별 상세 명세

기준: 12(IA)·13(UI원칙)·14(참여)·목업 10장. 모바일웹 퍼스트, 데스크톱은 무붕괴(콘텐츠 페이지 중앙 단일 컬럼). 목업 아트보드와 1:1 대응.

## 공통

- 헤더: 로고(홈 링크) · 지도 · 신규 오픈 · [라멘집 등록 버튼]. SEO 페이지는 간소 헤더(로고 + "지도로 보기")
- 디자인 토큰: 흰 배경 + 그레이 4단 + 액센트 1색(라멘 레드 계열) + 시맨틱 그린(영업중). radius: 카드 8~12px / 컨트롤 칩·버튼 pill / 태그 배지 5px. 폰트 Pretendard 5~6단, 위계는 굵기
- 상태 컬러 규칙: 색이 있는 곳 = 인터랙티브
- 모든 페이지에 지도 로드 실패 폴백 필수 (망고플레이트 반면교사): 실패 시 리스트 뷰 + "지도를 불러오지 못했어요" 배너

## 1. 지도 홈 `/`

**요소:** 헤더 / 축 칩 3개(형태·스프·계보)+전체 필터 버튼 / 풀맵(뷰포트 높이) / "이 지역 재검색" 버튼 / 현위치 FAB / **상시 바텀시트**(2026-08-27 변경, 카카오맵 레퍼런스 — 목록 모드↔매장 모드 전환)

- 상시 바텀시트 목록 모드: 접힘(핸들+"이 지역 N곳")↔목록 스냅. 내용 = 현재 지도 범위+필터 결과, 중심 가까운 순. 지도 이동 시 갱신. 항목 탭 → 지도 이동+매장 모드
- 매장 모드: 마커·목록 탭 시 같은 시트가 매장 카드로 전환(§2). X·지도 탭 → 목록 모드 복귀
- 하단 SSR 관문 섹션은 /new로 이동(2026-08-27 — 홈 100dvh 고정, 스크롤 제거)

**동작:**
- 초기 뷰: 서울 중심(또는 마지막 위치). 위치 권한은 현위치 버튼 탭 시에만 요청, 거부 시 동네 선택 대체
- 마커: 스프 색 도트 + 상호 라벨 필. 상태 = 선택(반전·확대) > 저장(북마크) > 기본 > 완식(회색조). NEW 배지. 터치 44px
- 클러스터: 동네 시맨틱형("성수동 12"), 탭 시 bounds 줌인, 필터 결과 반영
- 마커 탭 → peek 카드 (영업상태 → 상호 → 태그 → 거리). 좌우 스와이프 = 인접 매장 순회 + 핀 하이라이트. 위로 드래그 → half. X 또는 지도 탭 → 닫힘. 뒤로가기로 닫힘(history 연동)
- 필터: 축 칩 탭 → 값 선택 시트(§9). 즉시 반영, 뷰포트 자동 이동 금지. 적용 시 칩 라벨 갱신("스프 · 니보시") + 개별 해제
- 상태 URL화: `/?soup=niboshi&view=...` — 공유·뒤로가기 대응
- 0건: "이 지역에 조건에 맞는 매장 없음" 배너 + 필터 칩 유지 + "필터 완화 / 가까운 N곳 보기"

## 2. 바텀시트 half (홈의 상태)

**요소:** 그랩 핸들 + X / 사진 스트립(대표 1 + 서브 2, 직접 촬영·허락분만) / 상호·태그·영업상태·브레이크·접근 / 방문정보 태그(식권기·카에다마 등) / 대표 메뉴 1~3 / [가고 싶다] [완식] [상세 보기]

**동작:** peek↔half 스냅(높이는 실기기 확정 — 미결 5). half에서도 지도 조작 가능(논모달). "상세 보기" → `/shop/{slug}` 라우팅(full 확장 없음). 완식 탭 → 카운트 증가 + 마커 회색조 전환 + 날짜 저장(localStorage)

## 3. 매장 상세 `/shop/{slug}` (SSR)

**요소:** 히어로 사진(뒤로가기 오버레이) / 상호 + 스프 대표 배지 + 저장 아이콘 / 태그 라인 / 영업상태 라인 / 정보 테이블(주문 방식·카에다마·웨이팅[캐치테이블 아웃링크]·좌석) / "니보시가 뭔가요? → 장르 가이드" 컨텍스트 링크 / 오시는 길(정적 지도 facade + "지도에서 보기" → 홈 지도 해당 매장 포커스) / 주소 + 네이버플레이스 아웃링크 / 하단: 영업 변동 안내 자리(라멘 투데이 연동 후보) + "정보 수정 제안" 링크

**SEO:** Restaurant 구조화 데이터(geo·openingHours·servesCuisine·priceRange), 검증 상태 배지 노출. 메뉴 탭은 없음(대표 메뉴는 정보 섹션 내)

## 4. 지역×장르 리스트 `/{지역}/{스프|계보}` (SSR — 트래픽 엔진)

**요소:** 간소 헤더 / 브레드크럼 / H1("성수 니보시 라멘 맛집 N곳 (2026)") / 인트로 1~2문장 / 매장 카드 리스트(72px 정사각 썸네일 + 3줄: 상호 / 태그·접근 / 상태·편의) / "지도에서 보기"(필터 프리셋된 홈으로) / FAQ 2~3개(택소노미 해설 — FAQPage 마크업) / 교차 링크 칩(인근 지역·관련 장르)

**생성 규칙:** 매장 3곳+ & 검색 수요 조합만 정식 URL·색인. 미달 조합은 지도 쿼리로만, canonical 상위 정규화. ItemList(summary) + BreadcrumbList 마크업. 지도 위젯 없음(facade 버튼만)

## 5. 계보 랜딩 `/style/{계보}` (SSR)

4번의 변형 + 상단에 **다크 에디토리얼 헤더**(계보명·설명 3줄·통계 — Hitosara 이원 톤) + **소목록 진행률 바**("서울 이에케 4/7" — localStorage 기록 연동, 기록 없으면 숨김) + 리스트(완식 ✓ 표시 포함) + "가이드 / 관련 계보" 링크

## 6. 장르 가이드 `/guide/{장르}` (SSR)

**요소:** 가이드 헤더(계열명·본문 2~3문단) / 특징 3칸(맛·농도·첫 주문 추천) / "이런 분께" / "비슷한 듯 다른 계열" 비교 카드 / 대표 매장 카드 2~3 / "전체 지도에서 보기" CTA / 감수 표기

**톤:** 에디토리얼. 라이트층 교육 + SEO 보조 + 상세·필터에서 컨텍스트 링크로 진입

## 7. 신규 오픈 `/new`

**요소:** 헤더(신규 오픈 활성) / 타이틀 + "인허가 데이터와 제보로 확인" 설명 / 월별 그룹 리스트(NEW 배지 썸네일 + 3줄, 오픈일 표시) / 하단 등록 유도 배너("새 라멘집을 발견하셨나요? 라멘집 등록 →")

**데이터:** LOCALDATA diff 자동 후보 + 파트너 확인분만 게재. 페이지 자체도 SSR(SEO: "성수 라멘 신규 오픈" 류)

## 8. 제보 (상태 — 풀스크린 시트, 2026-08-31 재설계)

유형 선택 화면 없이 **진입점이 유형을 결정** (실측: 카카오·네이버·구글·캐치테이블·다이닝코드 공통 — 상세는 docs/plans/2026-08-31-report-redesign.md):

- **새 라멘집 등록**: 홈 [라멘집 등록] → `?report=new` 시트. **링크 우선(라멘투데이·네이버 이용자 제보 모델)** — 리드 1줄("아직 라맵에 없는 라멘집을 알려주세요.") + `* 필수` 노트 / 가게 이름* + 지점명(선택, 같은 행) / 링크*(최대 3, 첫 행 삭제 없음, blur 시 형식 검증, 힌트 한 줄 "인스타그램, 카카오맵, 네이버 지도 중 하나면 충분해요") — 링크 없으면 **지도 위치 핀 또는 사진**으로 대체(네이버 영수증→전경→SNS 3단계 관례) / 사진 최대 5(**확인용** — 캡처·SNS 이미지도 받음, 네이버 "SNS 캡처 올려주세요" 관례. 게재는 파트너가 출처 확인 후) / 자유 입력(라벨 없음, 플레이스홀더 "더 알려주실 내용이 있다면 자유롭게 적어주세요"). 장르·영업시간·메뉴·주소·좌석은 **받지 않음**(운영자가 링크로 판별, 장르 힌트는 한마디로). 하단 고정 CTA "등록하기"(버튼 아래 캡션 없음), 완료 화면 "등록 요청이 접수됐어요 / 확인을 거쳐 지도에 올라가요. 보통 며칠 걸려요."
