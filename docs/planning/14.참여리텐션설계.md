# 14. 참여·리텐션 설계 — 글로벌 덕후 서비스 딥리서치 종합

조사일: 2026-08-26. 근거: 멀티에이전트 딥리서치 (Untappd·Vivino·Beli·Beanconqueror·Whiskybase·Sakenowa·ramendb·일본 스탬프랠리 / Letterboxd·Goodreads·Last.fm·Strava·Spotify Wrapped·GitHub 잔디 / Discogs·BGG·MAL·포켓몬GO·블랙야크 명산100 / 실패 사례: Foursquare·Strava 도핑·배지 인플레·과잉정당화 메타분석). 30여 개 메커니즘 → 5계열 분류 → 3단 사다리 매핑.

## 메커니즘 5계열과 배치

| 계열 | 원리 | 라맵 배치 |
|---|---|---|
| A. 기록·축적 (자기완결) | 이미 하는 행위의 외화 → 축적의 단일 시각화. 규모 무관 작동 | **1단 본체** |
| B. 진행·목표 | 유한·권위 목록 + 보이는 빈칸 + 달성 가능 크기 + 0에서 출발 금지 | 1단·2단 |
| C. 정산·공유 | 데이터를 이야기로 반환 → 유저가 배급망이 됨 | **2단 본체** |
| D. 경쟁·지위 | 강력하나 임계질량 필요 + 어뷰징·소외·강박 구조적 비용 | **전면 금지** |
| E. 집단 산출·자생 | 개인 기록 총합 = 공공재, 파생 문화는 커뮤니티가 발명 | 3단 전용 |

도메인 정합성: "완식"은 게임 용어가 아니라 라멘 문화 내부의 실천 용어(스프까지 비움) — A가 게임이 아닌 기록으로 읽힘. 순회·원정 문화 = B의 순례 프레임. 갤러리 인증 문화 = C의 무료 배급망. 장르 택소노미 = B의 권위 목록 요건.

## 1단 (MVP) — 확정 스펙 6개

현 설계(완식·회색조 마커·카운트·localStorage·무로그인)는 실패 사례들의 여집합에 정확히 위치함이 확인됨. 추가 스펙:

1. **체크인 단위 고정: 완식 1杯 = 가게 1곳 방문 1회**, 재방문은 가게별 카운트 증가 (Untappd 1잔·ramendb 1杯 — 단위가 명확해야 누적이 권위가 됨)
2. **완식 기록에 날짜 저장** (UI 미노출이어도) — 2단 연말 정산의 원료 (Letterboxd 다이어리). 별점·메모는 MVP 배제 (마찰 최소화)
3. **상태 2가지: 완식 / 가고 싶다.** 부정 상태 없음 (Discogs Collection/Wantlist 이중 구조 — 위시가 다음 방문 동기)
4. ~~온보딩: "가본 집 먼저 찍어보세요"~~ — **폐기 (2026-09-01 PO 결정)**: 첫 진입은 바로 지도. 소급 기록 유도는 강제 화면 없이 /me 빈 상태 문구 수준으로만. 부여된 진전 근거는 완식 인증·진행률 도입 시 재검토
5. **장르×지역 소목록 진행률: "서울 이에케 4/7"** — 목록은 10곳 내외 달성 가능 크기 (Kivetz 목표 구배·BAC 명산100·일본 랠리 / 포켓몬GO 반면교사: 전국 전체를 유일 목표로 걸면 지방 유저 좌절)
6. **localStorage 내보내기/복원(JSON)을 MVP 포함** — 기록 소실은 최대의 배신 (Beanconqueror의 유일 약점)

## 2단 (SHOULD) — 공유 이미지 설계

- **단일 이미지 최적화** — 갤러리는 스토리형이 아닌 "짤 한 장" 문화. Wrapped식 멀티 장면 아님
- 구성: **완식 총수(구체 숫자 — 2024 Wrapped 반발 교훈: 기발함이 숫자를 대체하면 실패) + 내 라멘 지도(잔디의 공간 버전) + 장르 분포·최다 장르("최다 방문: 이에케" — 택소노미가 정체성 언어로 작동) + 내 인생 라멘 3~4곳(Letterboxd Four Favorites)**
- **소목록 완주 시 "인정증" 특별판** — 일본 라멘랠리 완주 인정증 양식에서 경품·제휴만 뗀 자동화 버전. 갤러리와 경쟁하지 않고 인증 "소재를 공급" (와시노미야 성지순례 모델)
- **상시 내보내기 + 연말 "Year in 라멘" 이중 구조** (Untappd Year in Beer)
- 비교는 유저가 선택한 반출 순간에만 — 상시 비교 피드 금지 (Strava 강박 연구)
- **정산·공유는 영원히 무료** (Strava 2025 유료화 반발 — 정산은 배급망, 유료화는 배급망 절단)

## 3단 (3막) — 봉인 설계

1. 집계는 점수 랭킹이 아닌 **완식 횟수 집계** (ramendb 가중 포인트의 산출식 튜닝·논쟁 부담 회피 — 횟수는 논쟁 자체가 없음)
2. 어워드는 유저 순위가 아니라 **가게에 주는 집단 산출물** — 개별 보상 없음, 가중치 비공개 (Foursquare: 보상이 걸리는 순간 허위 체크인 폭발)
3. 리뷰는 별점 집계가 아닌 **완식 기록 부속 개인 코멘트의 선택적 공개** (The Shed at Dulwich — 가짜 리뷰로 런던 1위. 협찬 오염의 대안이라는 존재 이유와 자기모순 금지)
4. 로그인은 **"열람 완전 개방, 기여만 계정"** 패턴 (ramendb·Whiskybase 공통, 월 200만 비로그인 열람) + **기존 localStorage 기록을 지키는 수단으로 제시**, 이관 필수 제공
   - **갱신 (2026-08-26):** 방식은 **카카오 소셜 로그인(Supabase Auth)** 확정. 시점은 "3막 봉인"에서 완화 — **개발 순서상 맨 마지막**, 트리거(동기화 문의 발생 또는 집단 참여 개방) 시 즉시 도입. 이를 위한 모듈화 이음새는 09.기술타당성 참조
5. **H-index류 파생 지표는 만들지 않고 집계 데이터 공개로 갤러리가 자생시키게** (BGG — 10x10 챌린지 전부 유저 발명)
6. 재검토 후보 기록: Beli식 pairwise 서열(로그인 후), Sakenowa식 텍스트→시각화(대량 축적 후), 가게 N회 완식 자동 표시
7. **메타 원칙: 완식 기록 체계는 3단까지 형태 불변, 그 위에 쌓기만.** 신규 장치는 "10년 유지 가능한가 + 나중에 뗄 수 있는가" 통과 필수 (Foursquare/Swarm — 정체성이 된 장치의 제거는 3위→146위 추락)

## 금지 목록 (전 단계)

1. **스트릭·연속 방문·주간 목표** — GitHub이 스스로 제거, ICSE 2021 행동 왜곡 실증. 라멘은 매일 먹는 음식이 아니며, 성립시키면 과식 조장 프레임
2. **공개 유저 리더보드·자리 경쟁** — Strava 디지털 도핑(10년 못 잡은 군비경쟁), Foursquare 메이어십 공식 폐기 사유("불특정 다수와 경쟁하고 싶어하지 않는다")
3. **배지·레벨·칭호** — 배지 인플레(Foursquare 폐기 사유, Untappd "배지의 바다"). 결정적으로 디시 진성 덕후는 PBL 알레르기 최강 세그먼트 — "레벨 5 라멘 마스터"는 즉시 조롱거리. 유일 예외: 2단 완주 인정증(문화 내부 양식 차용)
4. **자기 설정 수치 목표 + 뒤처짐 표시** (Goodreads Challenge의 문서화된 죄책감·게이밍 부작용)
5. **별점 집계 리뷰** (조작 취약 + 존재 이유 자기모순)
6. **물리 경품·점포 제휴·조건부 보상** — 스탬프랠리 사무국 부담(JStage 논문) + Deci 메타분석 128건: 조건부 외적 보상은 내재 동기 훼손. 라멘 순례는 이미 강한 내재 동기 활동
7. **타인 기록 상시 노출 피드·프로필 비교** (Strava 강박 실증 + 게시판 금지 제약)
8. **초대제·가치 경험 전 계정 요구** ($300M 버튼, Baymard 18% 이탈)
9. **전국 전체 도감을 유일 목표로** (달성 불가 목표는 좌절 레시피)
10. **정착한 기록 체계의 철거·개편** (Foursquare/Swarm 이중 교훈)

## 08.MVP기능정의 반영 사항

- MUST 추가 없음 (완식·위시는 기존 저장 기능의 스펙 확정)
- SHOULD 갱신: 저장 → **완식/가고싶다 2상태 + 날짜 저장 + 온보딩 미리 찍기 + 소목록 진행률 + 내보내기/복원** / 공유 이미지(단일 짤 + 인정증 + 연말 정산)
