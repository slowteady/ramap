# 11. 커뮤니티 공략 — DC 라멘 미니갤러리 정찰 및 전략

정찰 일시: 2026-08-25 (브라우저 직접 확인)

## 정찰 결과

### 갤러리 활동량 — 충분히 살아있음
- 누적 글 11.6만+, 당일 실시간 게시 확인
- 말머리 구조: 일반 / 후기 / **영업정보** / 일본후기 / **부산후기**
  - "영업정보"가 독립 말머리 = 커뮤니티가 영업 변동을 수동 추적 중 (정보 수요 실증)
  - "부산후기" 독립 = 수도권 외 부산 라멘 씬 존재 (MVP 지역 확장 순서 참고)

### 결정적 발견: "라멘 투데이" (ramentoday.xyz)
- 갤러리 유저가 2026-03 개설, **파딱(운영진) 허락받고 공지 고정** (조회 8,922 / 추천 31 / 댓글 45)
- 기능: 오늘의 이벤트 / 영업 변동(조기마감·긴급휴무) / 예정 이벤트 / 캘린더 / 제보
- 라이브 확인: 당일 이벤트 갱신 중 — **제보 루프가 실제로 작동하는 활성 서비스**
- 운영 방침: 광고 없음, 제보는 가게명/링크만(마찰 최소화), 관리자 검수 후 게재

## 시사점

### 1. H1(덕후의 불편 실재) — 사실상 검증 완료
자작 지도(기존 확인) + 자작 영업변동 사이트가 공지에 고정되고 제보가 실제로 돌고 있음. "커뮤니티가 자발적으로 도구를 만들고 유지하는가"라는 질문에 이보다 강한 답은 없음. 파트너의 Mom Test 인터뷰는 H2(불편의 구체 형태) 확인용으로 축소 가능.

### 2. 라멘 투데이는 경쟁자가 아니라 보완재
- 축이 다름: 라멘 투데이 = **실시간 변동 게시판** / 라맵 = **정적 장르 DB + 지도 + SEO**
- 겹치지 않는 것: 장르 필터, 지도, 매장 페이지, 검색 유입
- 겹칠 수 있는 것: 신규 오픈·영업 정보 축 (우리 SHOULD 1순위)
- **관계 전략: 경쟁 금지, 제휴 우선.** 라맵 매장 페이지에서 라멘 투데이 링크/연동 제안 가능. 커뮤니티는 자기들 도구를 밀어낸 신참을 용서하지 않음 — 라멘 투데이를 존중하는 포지션이 필수
- 리스크: 운영자가 DB·지도로 확장할 가능성. 5개월째 좁은 스코프 유지 + 겸손 운영이라 가능성 낮게 평가하나 모니터링

### 3. 공략 플레이북이 검증돼 있음 (라멘 투데이가 증명)
갤러리 침투의 성공 공식이 공지에 그대로 박제돼 있다:

1. **파딱 사전 허락** — 무허가 홍보는 사망. "(파딱허락o)" 제목 표기가 관행
2. **세줄요약 + 겸손한 톤** — "만들어봤습니다", 광고 없음 선언, 서버비 언급
3. **제보 마찰 최소화** — 가게명/링크만 받고 나머지는 운영자가 정리
4. **피드백 채널 개방** — 댓글로 받고 주기적 반영 약속

### 4. 실행 순서 (라맵 버전)

1. **지금부터:** 파트너가 갤러리에서 눈팅+후기 기여로 계정 신뢰 축적 (뉴비 계정으로 사이트 던지면 죽음)
2. **출시 준비:** 데이터 300곳 태깅 완료 상태로 준비 — 갤러리 공개 시점에 "빈 껍데기"면 한 방에 끝
3. **공개:** 파딱 허락 → "(파딱허락o) 장르별로 라멘집 찾는 지도 만들어봤습니다" — 라멘 투데이 포맷 그대로. 광고 없음 명시, 제보 폼 안내
4. **직후:** 댓글 피드백 즉시 반영을 며칠간 보여주기 — 초기 신뢰의 승부처
5. **제휴:** 라멘 투데이 운영자에게 상호 링크 제안 (갤러리 공개 후, 신뢰 확보 상태에서)
