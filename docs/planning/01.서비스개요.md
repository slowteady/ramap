# 라맵 (Ramap) — 서비스 개요

## 한 문장 정의

**"한국 라멘을 장르로 찾는 지도"** — 돈코츠·쇼유·이에케이·지로계·츠케멘 등 라멘 덕후가 실제로 고르는 기준으로 전국 라멘집을 필터하는, 검증된 라멘 전문 DB.

## 프로젝트 목표 (수익 아님)

1. **트래픽 경험** — SEO 기반 오가닉 유입을 만들고 성장시켜보는 것
2. **자아실현 / 완주** — 실제로 사람들이 쓰는 것을 만들어 운영하는 경험
3. **포트폴리오** — 실유저·실트래픽·데이터 파이프라인·의사결정 기록을 갖춘 운영 프로젝트

## 팀

- 빌더 1명 (개발 전반, 라이트 라멘 소비자 관점)
- 도메인 파트너 1명 (라오타 — 택소노미 설계·장르 태깅·커뮤니티 침투 책임, 공동 제작자로 합의됨)

## 네이밍·도메인

- 서비스명: **라맵** / 도메인: **ramap.kr** (2026-08-25 미등록 확인, 등록 예정)
- 브랜드는 라멘 전용, 아키텍처(DB 스키마)는 다중 버티컬 — 확장 시 리브랜딩은 싸고 스키마 마이그레이션은 비싸다는 원칙
- 후보 비교 결과 (2026-08-25 확정): **라맵** 채택 — 라오타에게 "내 것"으로 읽히는 비치헤드 정합성이 결정 근거. **누들맵** 탈락 — 종합 포털로 읽혀 1막 정체성 희석 + 한국인은 "누들"로 검색하지 않음. **누들로그** 탈락 — "로그"는 기록·리뷰를 약속하는 이름인데 MVP에 리뷰·기록 없음 (이름-제품 불일치)
- 보험: noodlemap.kr 미등록 확인 — 2막 대비 병행 등록 (연 2만 원 옵션)

## 선정 근거 (탐색 이력)

- 2개 라운드 멀티에이전트 조사로 **63개 대안 아이디어를 발굴·검증**한 결과 채택 (docs/research/2026-08-25 문서 2건 참조)
- 경쟁 구도가 가장 깨끗한 도메인: 죽은 선행자 1개(라멘GPS — 월 방문 수천 이하, 체류 21초, 커뮤니티 언급 0)
- 재미(완주 동기) + 도메인 파트너 + 지표를 동시에 통과한 유일 후보
- 일본에 30년 검증된 원형 존재: 라멘데이터뱅크(1996→2005 법인화), ramendb.supleks.jp — 타임머신 모델

## 확장 로드맵 (빌드하지 않고 기록만)

- **1막:** 라멘 (수도권 → 전국)
- **2막:** 면 왕국 — 평양냉면(면스플레인 덕후 문화·깊은 분류 축), 우동·소바. 스키마만 선반영
- **3막:** 리뷰·어워드("백명점" 모델), 인접 문화권(사케·이자카야 — 2라운드 조사 1위 후보였음)

## 핵심 판별 규칙 (이 프로젝트가 통과한 기준)

1. 공백은 수요 축(상황·목적)이 아니라 **공급 축의 깊이**(고유 분류 체계)에 있다
2. 데이터 3층 구조: 공공데이터 시딩 + 팀이 감당할 고유 속성 구축 + 유지해줄 덕후 커뮤니티
3. "없는 것 같다"는 믿지 않는다 — 반드시 검증 검색 (조사에서 3회 반증됨)
