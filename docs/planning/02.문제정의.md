# 02. 문제 정의

## 문제 (재정의 완료)

> 라멘 소비자가 **장르·속성(돈코츠/쇼유/이에케이/지로계, 면 굵기, 스프 농도, 주문 방식 등) 기준으로 라멘집을 찾을 수단이 없다.** 네이버/카카오는 이 축을 제공하지 않고, 정보는 커뮤니티·블로그·인스타에 파편화돼 있다.

### 중요: "라멘 맵이 없다"가 아니다

초기 발상은 "라멘집만 보는 지도가 없다"였으나 이는 사실이 아님 (네이버 지도에서 "라멘" 검색 가능). 문제를 "맵 부재"로 잡으면 만들 것이 지도 UI가 되어 네이버와 정면 대결하게 됨. **"분류 체계 부재"로 잡아야 만들 것이 택소노미와 데이터가 되고, 이건 네이버가 만들 이유가 없는 축이라 이길 수 있음.**

## 문제의 실재 증거 (검증된 사실)

- DC 라멘 미니갤러리에서 유저가 자작 지도를 만들어 공유 (「라멘 뉴비가 서울 라멘 지도 만들었어!」) — **유저가 스스로 제품을 만들고 있음 = 최상급 페인 증거**
- 장르별 라멘 연말결산 블로그 존재 — 돈코츠/쇼유/시오/츠케멘 분류가 이미 커뮤니티 표준어
- 타베로그 도쿄 라멘 1위 '라멘야 시마' 서울 진출 — 시장 성숙 신호

## 진짜 경쟁자 (라멘GPS가 아님)

네이버 지도 저장 리스트 + 구글 마이맵 + 인스타 해시태그 + 갤러리 스크랩. 무료 대체재가 절반쯤 해결 중이므로, 대체재가 구조적으로 못 하는 것(정규화된 장르 필터, 크로스 리스트 통합, 신규 오픈 추적)을 제공해야 함.

## Vitamin / Painkiller 판정

Vitamin~Painkiller 사이. 일반 소비자에겐 Vitamin이나, **코어 덕후에겐 반복 발생하는 실제 불편** — 그래서 초기 타겟은 덕후 한정 (03.타겟고객 참조).

## 미검증 가설 (Phase 0에서 확인)

- H1: 코어 덕후는 현재 수단에 실질적 불편을 느낀다 → 갤러리 자작 지도 글 반응 확인 + 덕후 5~7명 Mom Test 대화 (04.고객발견 참조)
- 타이밍 가설: 한국이 일본 30년 곡선의 초입이다 → 네이버 데이터랩 "라멘 맛집"·"츠케멘" 등 검색량 추이 확인
