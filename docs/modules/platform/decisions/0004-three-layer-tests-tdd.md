# 테스트 3계층과 TDD

## 맥락

2026-09-02 시점에 순수 함수 단위 테스트(29파일 182케이스)만 있고 훅·컴포넌트·사용자 여정 테스트가 없었다. PO 지시: "이제라도 테스트 다시 다 작성해 — 단위, 렌더링, 시나리오 전부".

## 결정

- 단위(Vitest, `*.test.ts`) · 렌더링(Testing Library, `*.test.tsx`) · 시나리오(Playwright, `e2e/*.spec.ts`) 3계층으로 둔다.
- 테스트는 대상 파일 옆에 둔다(co-location).
- 이후 신규 기능은 테스트를 먼저 쓴다(TDD).
- 시나리오는 비로그인 여정만 자동화한다. 로그인 여정은 카카오 OAuth라 자동화하지 않는다.
- 시나리오 브라우저는 chromium 하나 — 카카오맵 SDK가 WebKit 헤드리스에서 불안정했다.

## 근거

- 구축 직후 단위+렌더링 225케이스, 시나리오 11케이스가 모두 통과했다(2026-09-02).
