# 카카오맵 선택과 지도 어댑터

## 맥락

무료로 운영하면서 지도가 주인공인 서비스를 만들어야 한다. 네이버(2025-07)·카카오(2026-07) 모두 최근 무료 범위를 줄인 전력이 있다.

## 결정

- 지도는 카카오맵 JS SDK를 쓴다.
- 화면은 SDK를 직접 부르지 않고 `MapAdapter` 인터페이스 뒤에서만 쓴다.
- 좌표는 자체 보유한다(공공데이터·수동 핀). 그래서 지도 SDK를 바꿔도 데이터는 그대로 옮긴다.
- 교체 경로: B-1 네이버 지도 → B-2 MapLibre GL + OpenFreeMap. 트리거는 일 로드 70% 2주 연속(B-1 검토), 무료 정책 변경 공지(30일 내 B-2 프로토타입), 분기 1회 약관 점검.

## 근거

- 카카오맵: 일 30만 로드 무료(월 50만 PV 시나리오의 6%). 카드 미등록 시 초과분은 429로 차단돼 **요금 폭탄이 구조적으로 불가능**하다.
- 카카오 운영진 답변: 자체 확보 좌표를 카카오 지도에 마커로 표시하는 것, 장소 ID·place_url 저장은 허용.
- 상세 근거: [지도 API 무료 사용 타당성 조사](../research/2026-08-25-map-api-free-tier-feasibility.md)

## 버린 안

- 네이버 지도 1순위: 월 600만 무료지만 카드 등록이 필수라 초과 과금 위험이 있다 → B-1로 둔다.
- 처음부터 MapLibre: SLA가 없고 한국 지도 품질이 떨어진다 → B-2로 둔다.
