# 이용 통계는 PostHog

## 맥락

초기 계획은 GA4 + Search Console + 네이버 서치어드바이저였다. 실제로는 페이지 유형·유입·클릭·히트맵·오류·웹바이탈과 기능별 행동(완식·제보·필터 등)을 한곳에서 보고 싶었다.

## 결정

- 이용 통계는 PostHog로 한다(GA4는 넣지 않는다). 검색어는 Search Console·서치어드바이저로 본다.
- 무료 플랜은 조직당 프로젝트 1개라 Keeper와 조직을 분리한다.
- 광고 차단기를 피하려고 `/ingest` 리버스 프록시로 보낸다.
- 토큰은 Vercel Production에만 둬서 로컬·프리뷰 데이터가 섞이지 않게 한다. 운영자 계정은 수집에서 뺀다.
- 세션 녹화는 끈다(필요하면 옵션 해제 + 처리방침 고지).
- 개인정보처리방침 2026-10-27판에 자동 수집 항목, 목적, 1년 보관, PostHog(미국) 위탁·국외 이전, 쿠키 거부 방법을 고지했다.

## 버린 안

- GA4: 기능별 커스텀 이벤트·히트맵을 한 도구에서 보기 어렵다.
