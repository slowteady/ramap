# 로그인은 나중에, 이음새 4개는 처음부터

## 맥락

v1은 로그인 없이 출시하되, 동기화 요청이 생기거나 참여 기능을 열 때 카카오 로그인(Supabase Auth)을 바로 붙일 수 있어야 했다.

## 결정

처음부터 4개의 이음새를 분리한다.

1. 기록 저장소 추상화 — 화면은 `RecordStore` 인터페이스만 호출. 비로그인은 localStorage, 로그인은 Supabase 구현체로 교체하고 기존 기록을 이관한다
2. 사용자 식별 추상화 — "현재 사용자"는 null에서 시작해 카카오 세션으로 채운다
3. 제보 제출 계층 분리 — 제보는 로그인 도입 후에도 로그인 없이 받는다
4. 지도 어댑터

기록 스키마는 계약이다: JSON 내보내기 포맷 = localStorage 저장 형태 = Supabase 테이블 형태. 이관이 변환 없는 업로드가 된다.

## 근거

- 2026-08-27 카카오 로그인 도입 때 화면 수정 없이 저장소 구현체만 바꿔 붙였다.
- 로그인 도입과 함께 개인정보처리방침과 최소 수집(카카오 식별자만) 숙제가 생긴다는 점을 미리 기록했다.
