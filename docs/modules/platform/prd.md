# platform 기획서

라맵의 기술 기반(스택·아키텍처·지도 SDK·백엔드·테스트·이용 통계)이 지켜야 할 조건을 정한다. 운영 비용, 약관·법, 품질의 세 갈래로 나눈다.
설계는 [design.md](design.md), 바뀐 기록은 이 파일의 GitHub 커밋 기록에 있다.

## 1. 왜 만드나

라맵은 무료로 운영하고, 지도 SDK의 무료 정책이 바뀌어도 서비스가 멈추지 않아야 한다. 약관과 법을 지키고, 지도 SDK가 실패해도 화면이 살아 있어야 한다.

## 2. 범위

### 이번에 하는 것

- 스택과 아키텍처
- 지도 SDK
- 백엔드
- 테스트
- 이용 통계

## 4. 규칙

| ID | 상황 | 규칙 | 예외 |
|---|---|---|---|
