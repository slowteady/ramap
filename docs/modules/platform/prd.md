# platform 요구사항

기술 기반(스택·아키텍처·지도 SDK·백엔드·테스트·이용 통계)이 지켜야 할 조건.

## 운영 비용

- 무료로 운영한다. 지도·호스팅·백엔드·분석 모두 무료 티어 안에서 돌고, 사용량이 늘어도 **요금이 자동으로 청구되는 구조를 두지 않는다**(카드 미등록 상태에서 초과 시 차단되는 서비스를 고른다).
- 무료 정책이 바뀌어도 서비스가 멈추지 않게 지도 SDK는 교체 가능해야 한다. 좌표는 자체 보유하므로 데이터는 어디로든 옮길 수 있어야 한다 → [지도 SDK와 어댑터](decisions/0001-kakao-map-adapter.md)

## 약관·법

- 지도사 지오코딩 결과를 저장하지 않는다. 좌표는 공공데이터와 운영자가 확정한 수동 핀만 쓴다 → [타사 플랫폼 데이터 경계](../../decisions/0002-third-party-data-boundary.md)
- 지도 SDK의 로고·표기를 지우지 않는다. 정적 지도 이미지를 미리 만들거나 캐싱하지 않는다.
- 개인정보는 최소로 모은다. 로그인은 카카오 식별자만 쓰고, 이용 통계에는 사용자 ID만 보낸다(이메일·닉네임 미전송). 수집 항목·보관 기간·국외 이전은 개인정보처리방침에 고지한다.

## 품질

- 지도 SDK가 실패해도 화면은 살아 있어야 한다 — 폴백 리스트와 안내 배너(지도 결함은 치명 결함).
- 새 로직은 테스트를 먼저 쓴다. 테스트는 단위·렌더링·시나리오 3계층으로 둔다 — PO 지시. 시나리오는 비로그인 여정만(카카오 OAuth는 자동화 불가)
- 운영 데이터 오염을 막기 위해 이용 통계는 프로덕션에서만 수집하고, 운영자 계정은 수집에서 뺀다.

## 확인 안 된 전제

- juso.go.kr 좌표제공 API 이용조건 원문
- LOCALDATA·상가업소 데이터 이용조건 원문
- 네이버·앱스토어 "라맵" 동명 서비스·상표
