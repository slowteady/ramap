# 마커 스프 색 인코딩 폐기

## 맥락

원안(2026-08-26)은 "마커 = 미니 데이터 카드"로, 1차 결정 변수인 스프 계열을 마커 색으로 인코딩하고 범례를 필터 칩과 공유하는 것이었다(Airbnb 가격 핀, 호갱노노 "41평 35억" 라벨 참고). 지도 위 구분 가능한 색은 5~7개가 한계인데 스프는 8값 이상이라 미결로 남아 있었고, 구현은 임시 6색 팔레트로 시작했다.

## 결정

- 마커는 스프와 무관하게 **라멘 레드 단색**이다. 마커가 드러내는 정보는 상호 라벨과 상태(선택·신규·저장·완식)다.
- 스프는 필터와 목록·카드의 장르 칩으로 전달한다.

## 근거

- 미결 1번(스프 8값 색 인코딩 가독성) 해소(2026-08-27).
- 9값은 색 구분 한계를 넘고, 색약에서 병합되며, 사용자가 학습할 수 없다(2026-08-28 태그 칩 색 조사 — 태그 칩 유채도 1차 축에만, 값별 다색 금지).
- 유채색 1색 예산과 정합 — [ui design](../../ui/design.md).

## 버린 안

- 스프 계열별 마커 색(상위 4~5값 고유색 + 묶음색, 또는 색 + 약자).
