# 지도 이동 시 목록 자동 갱신

## 맥락

한국 지도 서비스(네이버·카카오·캐치테이블)는 지도를 옮기면 "이 지역 재검색" 버튼을 띄우고, 눌러야 결과를 갱신한다. 원안도 이 컨벤션을 따랐다.

## 결정

- "이 지역 재검색" 버튼을 두지 않는다. 지도 이동이 멈추면 마커와 목록 시트("이 지역 매장 N곳")가 바로 갱신된다.
- 전체 매장 데이터는 빌드 시 정적으로 내려와 있어 서버 재조회가 없다.

## 근거

- 매장 데이터를 SSG로 전량 로드하므로 재검색 개념이 없다 — 재검색 버튼은 서버 조회 비용을 아끼려는 장치다(Plan 3, 2026-08-26).

## 버린 안

- "이 지역 재검색" 버튼(네이버·카카오·캐치테이블 컨벤션). 지도 뷰포트 런타임 API로 전환하면 재검토.
