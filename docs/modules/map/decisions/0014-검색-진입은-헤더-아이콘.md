# 검색 진입은 헤더 아이콘

## 맥락

실측한 지도 서비스 4곳은 모두 상단 고정 풀폭 검색바를 쓴다. 설계안도 캐치테이블 문법([라맵][검색바][프로필])으로 헤더 빈 공간을 검색바로 채우는 것이었다.

## 결정

- 홈 헤더의 검색 진입은 **아이콘 버튼**이다: [라맵 로고][검색 아이콘][프로필].
- 아이콘 탭 → 풀스크린 검색 오버레이.

## 근거

- 라맵에서 검색은 보조 동선이고, 1차 탐색은 장르 필터다 — 필터 탐색 우선 위계 반영(2026-09-01).
- 보조 동선 아이콘 진입은 당근 문법.

## 버린 안

- 상단 풀폭 검색바(카카오맵·캐치테이블·네이버지도 표준) — 필터 칩 행보다 검색이 앞서 보인다.
