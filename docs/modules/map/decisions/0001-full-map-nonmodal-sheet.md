# 풀맵과 논모달 상시 바텀시트

## 맥락

모바일 지도 홈의 기본 구조를 정해야 했다. 2026-08-26 원안은 "마커 탭 → peek 카드 → half"로 마커를 눌러야만 시트가 뜨는 구조였다.

## 결정

- **모바일: 풀맵 + 논모달 바텀시트.** 지도는 뷰포트 높이 거의 전부. 홈은 `100dvh` 고정, 페이지 스크롤 없음.
- 바텀시트는 **상시** 떠 있고 두 모드를 오간다: 목록 모드(현재 지도 범위 매장) ↔ 매장 모드(선택 매장 카드). 마커·목록 탭이면 같은 시트가 매장 카드로 전환된다.
- 시트가 떠 있어도 지도 조작 가능(논모달). 그랩 핸들과 닫기(목록으로) 버튼 병행, 뒤로가기로 카드 닫힘.
- 시트 제스처 규율은 `ramap-ui` 스킬의 "바텀시트 제스처 규율"을 따른다(지속형 시트 = 비모달 + `dismissible=false` + vaul `Handle`).

## 근거

- 스크롤 페이지 중간의 임베디드 지도는 제스처 충돌(scroll trap)로 금지 문헌 명시. 카카오맵은 cooperative 제스처 옵션이 없어 더 치명적(2026-08-26 BP 딥다이브).
- 상시 시트 목록↔매장 모드 전환은 카카오맵 레퍼런스(2026-08-27 변경, 2026-08-28 구현 — 딥다이브 조사 반영).
- 논모달·그랩 핸들 + X 병행·history 연동은 모바일 지도 BP(2026-08-26).

## 버린 안

- 마커 탭 시에만 뜨는 peek → half 시트(2026-08-26 원안) — 목록 탐색 동선이 없다.
- 스크롤 페이지 안 임베디드 지도 — scroll trap.
- 모달 시트로 지도 차단, 시트 중첩.
