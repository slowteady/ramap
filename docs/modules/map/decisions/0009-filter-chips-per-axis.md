# 필터는 축 단위 칩

## 맥락

택소노미는 3축(종류·국물·스타일)에 값이 15개 이상이다. 검토안은 "스프 칩들 + 츠케멘·이에케 승격"을 한 줄에 섞은 6칩 혼합안이었다.

## 결정

- **축 단위 칩 3개(종류·국물·스타일).** 칩 탭 → 해당 축의 값 선택 시트(트레이 패턴: 결과 수 상시 표시).
- 선택 상태는 칩에 반영하고, 개별 해제와 전체 초기화를 둔다.
- 스타일(계보) 값은 전문용어라 시트에서 한 줄 설명을 볼 수 있어야 한다.
- 값 칩 승격 재도입 조건: 출시 후 필터 로그에서 특정 값 사용이 압도적이면 "축 칩 3 + 인기 값 칩 1~2" 형태로, 전체 필터 시트에 중복 유지하며 추가.
- 계보 데이터가 희소하면 필터가 아니라 지도 레이어/렌즈(호갱노노 테마 방식)로 전환을 검토한다.

## 근거

- 축 혼합은 NN/g 예측가능성 원칙 위반 — 특히 이에케(계보)는 스프가 사실상 돈코츠쇼유라 "돈코츠 칩과 이에케 칩이 배타인가 포함인가"의 선택 시맨틱이 정의 불가.
- Material ChipGroup 모델 위반(한 그룹 = 한 도메인).
- 승격은 사용 데이터가 있을 때만 정당(Baymard) — 출시 전엔 근거 없음.

## 버린 안

- 6칩 혼합안(스프 칩들 + 츠케멘·이에케 승격).
- 값 칩 15+ 평면 나열.
