# MapAdapter 이음새

## 맥락

지도 SDK(카카오맵)는 약관·쿼터·장애에 따라 바꿔야 할 수 있다. 지도 코드가 SDK에 직접 묶이면 교체 비용이 크다.

## 결정

- 지도 렌더는 `MapAdapter` 인터페이스 뒤에 둔다. 현재 구현은 `KakaoMapAdapter` 하나.
- 마커·클러스터·필터·선택 계산은 SDK와 무관한 순수 함수로 두고, 어댑터는 그리기·이벤트만 맡는다.
- SDK 로드 실패(키 없음 포함)는 어댑터 생성 실패로 드러나고, 호출부는 리스트 폴백으로 전환한다.

## 근거

- 지도사 교체(Plan B) 대비 이음새(Plan 3, 2026-08-26).
- 지도 결함은 치명 결함이라 SDK 실패를 한 지점에서 잡아 폴백해야 한다 — [ui design](../../ui/design.md).

## 버린 안

- 뷰 컴포넌트에서 카카오 SDK 직접 호출.
