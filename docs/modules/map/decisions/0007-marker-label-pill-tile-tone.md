# 마커 가독성 — 라벨 흰 pill과 타일 톤다운

## 맥락

카카오맵 타일의 POI·도로색과 텍스트가 마커 라벨과 간섭해 읽기 어려웠다. 마커 점의 시각 무게도 부족했다.

## 결정

- 마커 점은 레드 링 + 흰 심의 **도넛**(22px, 선택 28px, 흰 테두리 3px, 그림자 강화).
- 상호 라벨은 텍스트 할로 대신 **불투명 흰 pill 칩**(굵기 800).
- 지도 타일에 저채도 필터를 걸어 POI·도로색을 가라앉힌다(`.map-tone`).

## 근거

- 도넛은 캐치테이블 문법. 솔리드 채움을 시도했다가(2026-09-02) 도넛으로 복원하며 라벨 굵기를 800으로 올렸다.
- 흰 pill 라벨은 구글 트래블·에어비앤비 실측 — 타일 텍스트 간섭 차단(2026-09-03).
- 타일 톤다운은 호갱노노 문법(2026-09-03 실측). SDK가 만드는 타일 `img`라 유틸 클래스를 붙일 수 없어 컨테이너 스코프 CSS 규칙이 유일한 수단.

## 버린 안

- 텍스트 그림자 할로 라벨.
- 솔리드 채움 점 — 흰 심 도넛 복원.
