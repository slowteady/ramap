# 홈 하단 SSR 섹션 폐기

## 맥락

원안은 지도 아래 스크롤 경계 너머에 SSR 관문 섹션(동네 바로가기 링크 등)을 두고, 하단에 스크롤 어포던스를 주는 구조였다. 크롤러가 홈에서 랜딩 페이지를 발견하게 하려는 목적이었다. 2026-08-27 홈을 `100dvh`로 고정하며 관문 섹션을 `/new`로 옮겼고, `/new`도 2026-09-01 폐기됐다.

## 결정

- 홈은 순수 지도 앱으로 유지한다. 홈 아래 스크롤 콘텐츠 섹션은 두지 않는다(2026-09-05 PO).
- 크롤러의 랜딩 발견은 `sitemap.xml`·`robots.txt`가 담당한다.
- SEO 랜딩(`/area`·`/guide`·`/style`)은 상호 크로스링크로 링크 그래프를 만든다.

## 근거

- 몰입형 지도 홈에 스크롤 푸터는 관례 위반.
- 풀맵이 아래 스크롤 가능성을 가려 발견성이 낮다(미결로 남아 있던 문제).

## 버린 안

- 지도 아래 SSR 관문 섹션 + 스크롤 어포던스(2026-08-26 원안).
- 관문 섹션을 신규 오픈 페이지 `/new`로 이동(2026-08-27) — `/new` 폐기로 소멸.
