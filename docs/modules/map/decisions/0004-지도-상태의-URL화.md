# 지도 상태의 URL화

## 맥락

필터·선택 매장·열린 화면(검색·등록)을 어디에 저장할지 정해야 했다.

## 결정

- 공유할 가치가 있는 지도 상태의 원천은 **URL 쿼리**다: 필터, 선택 매장, 검색 오버레이, 등록 시트.
- 선택·오버레이 열기는 history push(뒤로가기로 닫힘), 해제·필터 변경은 replace(히스토리 스팸 방지).
- **예외:** 검색어 자체는 URL에 싣지 않는다(2026-09-01). 선택 즉시 닫히는 내비게이터라 공유 가치가 없다.

## 근거

- 캐치테이블 실증(2026-08-26) — 뒤로가기·공유·SEO를 동시에 해결.
- 갤러리에 "니보시만 켠 지도" 링크를 공유하는 것이 곧 유통.

## 버린 안

- 컴포넌트 상태만으로 관리 — 공유·뒤로가기가 안 된다.
- 검색어 URL 반영(`?q=`) — 결과 리스트 화면이 생기는 규모가 되면 재검토.
