# "지금 영업중" 필터 기각

## 맥락

지도·상세 리서치 M1 항목: 필터에 영업중 토글을 두고 시간 파싱으로 지금 영업 중인 매장만 보여 주자는 제안. 근거로 카카오맵 검색 영업중 필터, jirolianmap 상태 색 핀이 있었다.

## 결정

- "지금 영업중" 필터를 두지 않는다.
- 목록·카드는 실시간 영업 판정 없이 등록된 영업시간 정보만 보여 준다.

## 근거

- 실시간 영업 여부는 알 수 없다. 등록 영업시간 대비 현재 시각 추정일 뿐이고 임시 휴무·재료 소진 조기 마감·명절이 반영되지 않는다.
- 오안내는 헛걸음과 신뢰 손실로 이어진다.
- 2026-10-27 기준 영업시간 보유 69%, 최종확인일 0% — 틀린 "영업중"이 나올 위험.
- 기존 원칙(실시간 "영업중" 판정은 데이터 최신성이 보장되기 전까지 표시하지 않음) 유지.
- 상세: [조사](../../../research/2026-10-27-지도-상세-검수-조사.md) M1.

## 버린 안

- 시간 파싱 기반 영업중 토글. 재검토하려면 최신성 기준(예: 최근 N개월 내 확인된 매장만 판정)을 먼저 정해야 한다.
