# 저장·완식 마커와 라벨 우선순위

## 맥락

명세는 마커 상태를 "선택 > 저장 > 기본 > 방문함(회색조)"으로 정했지만 저장 상태는 구현이 누락돼 있었다. 완식(방문) 마커는 Airbnb viewed-grey를 따른 회색조였다. 2026-10-27 지도·상세 리서치 M2 항목으로 PO 검토.

## 결정

- **저장 마커 = 근흑 채움 + 흰 북마크**, **완식 마커 = 흰 원 + 빨간 테두리 + 빨간 체크.** 글리프는 각 기록 버튼과 같은 lucide 아이콘을 마커 안에 그린다.
- 상태 우선순위: 선택 > 저장 > 완식 > 기본(마커 상태). 라벨 우선순위: 선택 > 신규 > 저장 > 기본 > 완식.
- 라벨이 겹치면 하위 우선순위 라벨을 점으로 강등한다(위치 이동 없음). **라벨을 가리는 일반·완식 점은 그 축척에서 숨긴다.** 저장·신규 점은 남긴다.
- 라벨은 점 위에 그린다(점이 다른 매장 라벨을 가리지 않게).
- 칩 "저장한 곳"(저장 매장만 보기)을 추가한다.

## 근거

- 아이콘을 라벨이 아닌 마커에 넣는 것은 구글 별·카카오 폴더 별 관례.
- 회색조 완식 마커는 비활성처럼 읽힌다(2026-10-27 PO).
- 겹침 처리는 구글 지도 collision behavior(`OPTIONAL_AND_HIDES_LOWER_PRIORITY`).
- 저장 지도 토글은 네이버 저장리스트 지도 토글·타베로그 行った・行きたい地図·Corner 참고 — [조사](../../../research/2026-10-27-지도-상세-검수-조사.md) M2.
- 완식 마커 자체는 GitHub 잔디의 공간 버전 — 스트릭 부작용 없는 축적 시각화(2026-08-26 리텐션 리서치).

## 버린 안

- 회색조 완식 마커(Airbnb viewed-grey).
- 겹친 하위 마커를 점으로만 남기기 — 점이 상위 라벨을 가린다.
