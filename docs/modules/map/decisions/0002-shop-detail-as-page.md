# 매장 상세는 시트 확장 대신 페이지 이동

## 맥락

지도 위 매장 카드를 끝까지 끌어올리면 시트를 full로 확장해 상세를 보여 줄지, 별도 페이지로 보낼지 정해야 했다.

## 결정

- 매장 카드에서 상세로 갈 때는 시트를 full로 확장하지 않고 `/shop/{slug}`로 라우팅한다.
- 매장 카드의 시트 스냅은 접힘·카드 높이 두 단계뿐이다.

## 근거

- SEO상 매장마다 고유 URL이 필수 — 매장 상세가 SEO 단위(SSR 페이지)다.
- 지도 SPA는 SEO를 못 한다. 트래픽 엔진은 별도의 SSR 페이지망(Zillow·Yelp·Tripadvisor·Tabelog·Airbnb 공통, 2026-08-26 조사).

## 버린 안

- 시트 full 확장으로 상세 표시 — 고유 URL이 생기지 않는다.
