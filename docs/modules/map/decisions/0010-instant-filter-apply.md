# 필터 즉시 반영

## 맥락

필터 값을 누를 때마다 반영할지, Apply 버튼으로 모아 반영할지 정해야 했다.

## 결정

- **즉시 반영(interactive).** Apply 버튼 없음.
- 값 옆에 결과 수를 표시하고, **0건 값은 비활성**(사전 예방).
- 0건이 되면 안내 + 필터 칩 유지 + 완화 경로를 준다.
- **필터 적용 시 지도 뷰포트 자동 이동 금지.**

## 근거

- 탐색형 서비스 + 가벼운 데이터셋 — Apply 버튼의 근거가 없다(2026-08-26 필터 문헌 조사).
- 적용 필터 오버뷰가 없으면 "이 동네엔 없다"로 오판한다.

## 버린 안

- Apply 배치 필터.
- 필터 적용 시 결과 쪽으로 뷰포트 자동 이동.
