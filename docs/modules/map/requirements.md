# 지도 홈 요구사항

홈(`/`) — 지도·목록 바텀시트·매장 카드·필터·검색·마커가 해야 할 일.

## 사용자 요구

| 요구 | 내용 |
|---|---|
| 장르로 좁히기 | 종류·국물·스타일로 라멘집을 거른다. 자가제면·본토직영 같은 특성, 새로 오픈한 곳, 안 가본 집, 저장한 곳만 보기도 된다 |
| 지금 보는 지역 목록 | 지도를 옮기면 그 범위의 매장 목록과 개수가 바로 바뀐다. 화면 중심에서 가까운 순 |
| 빠른 확인 후 상세 | 마커나 목록 항목을 누르면 지도를 떠나지 않고 매장 카드(영업시간·장르·편의·대표 메뉴·내 기록 버튼)를 본다. 카드에서 상세 페이지로 간다 |
| 동네 감 잡기 | 넓은 축척에서는 동네·구·시도 이름과 매장 수로 묶여 보인다 |
| 내 주변 | 버튼을 누르면 내 위치로 이동하고 거리가 보인다 |
| 찾기 | 매장명·장르·동네를 1글자부터 찾는다. 초성·영타·한 글자 오타도 찾는다 |
| 공유·뒤로가기 | 필터를 켠 지도, 선택한 매장을 링크로 공유한다. 뒤로가기로 카드·검색이 닫힌다 |
| 내 기록이 보임 | 저장한 곳과 완식한 곳이 지도 마커로 구분된다 |
| 등록 진입 | 지도에 없는 라멘집을 홈 버튼이나 검색 빈 결과에서 등록 요청한다 |
| 지도 실패에도 사용 | 지도가 안 뜨면 동네별 목록과 안내 배너가 대신 나온다 |

## 범위

- 홈 화면 구조(헤더 아래 필터 행·풀맵·상시 바텀시트)
- 마커·클러스터·라벨 겹침 처리
- 필터(축 칩·값 시트·토글 칩)와 URL 동기화
- 목록 시트·매장 카드
- 현위치
- 검색 오버레이
- 지도 실패 폴백
- 지도 SDK 어댑터

## 제약

- 위치 권한은 현위치 버튼을 누를 때만 요청([결정](decisions/0011-위치-권한은-현위치-버튼에서만.md))
- 필터 적용 시 뷰포트 자동 이동 금지, 0건 값 비활성([결정](decisions/0010-필터-즉시-반영.md))
- 지도 상태는 URL이 원천([결정](decisions/0004-지도-상태의-URL화.md))
- 실시간 "영업중" 판정 표시 금지 — 등록된 영업시간 정보만([결정](decisions/0015-지금-영업중-필터-기각.md))
- 좌표는 공공데이터·수동 핀만. 지도사 지오코딩 결과 저장 금지([공통 결정](../../decisions/0002-타사-플랫폼-데이터-경계.md))
- 폐업·좌표 없는 매장은 지도에 올리지 않는다
- 홈은 스크롤 페이지가 아니다([결정](decisions/0003-홈-하단-SSR-섹션-폐기.md))
- 초기 소셜프루프("N명 보는중") 금지 — 데이터가 빈약할 때 빈약함만 드러난다
- 마커 터치 타깃 44px
- UI 규율은 [ui design](../ui/design.md)과 `ramap-ui` 스킬

## 명세에 있으나 아직 없는 것

과거 명세에 있었으나 현재 코드에 없다. 유지할지 백로그로 내릴지 PO 확인이 필요하다.

| 항목 | 원래 근거 |
|---|---|
| 매장 카드 좌우 스와이프 = 인접 매장 순회 + 핀 하이라이트 | Yelp가 효과 공식 보고 — 지도 맥락을 유지한 비교 탐색. 밀집 상권 최대 줌 겹침의 해법으로도 지정됨 |
| 0건 시 "가까운 N곳 보기" 완화 경로 | 필터 즉시 반영의 0건 처리 |
| 위치 권한 거부 시 동네 선택 대체 | 위치 권한 UX |
| 매장 카드 사진 스트립(대표 1 + 서브 2, 직접 촬영·허락분만) | 바텀 카드 벤치마크(오늘의집) |
| 매장 카드 대표 메뉴 1~3개 | 현재 1개만 표시 |

## 범위 밖

| 항목 | 재검토 조건 |
|---|---|
| "이 지역 재검색" 버튼 | 지도 뷰포트 런타임 API 전환 시([결정](decisions/0012-지도-이동-시-목록-자동-갱신.md)) |
| 값 칩 승격("축 칩 3 + 인기 값 칩 1~2") | 출시 후 필터 로그에서 특정 값 사용이 압도적일 때([결정](decisions/0009-필터는-축-단위-칩.md)) |
| 스타일 축을 지도 레이어/렌즈로 전환 | 계보 태그 분포가 희소할 때 |
| 검색어 URL 공유(`?q=`)·검색 결과 리스트 화면 | 결과 리스트가 필요한 규모가 될 때 |
| 데스크톱 스플릿 뷰 | 모바일 트래픽 비중 확인 후 |
| "지금 영업중" 필터, 실시간 대기 시간 | 기각 |
