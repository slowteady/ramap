# 라벨은 "라멘집 등록", 검수 안내는 완료 화면에만

## 맥락

1차 구현의 "제보하기" 라벨과 CTA 아래 "모든 제보는 검수 후 게재됩니다" 캡션이 PO 검수에서 지적됐다.

## 결정

- 홈 버튼 **라멘집 등록** / 시트 제목 **새 라멘집 등록** / CTA **등록하기**(하단 고정, 버튼 아래 캡션 없음).
- 리드는 해요체 1문장·행동 동사: "아직 라맵에 없는 라멘집을 알려주세요." 로그인·검수 같은 시스템 사정은 리드에 넣지 않는다.
- 검수 안내는 폼 안이 아니라 **완료 화면**에만: "등록 요청이 접수됐어요 / 라맵이 확인한 뒤 지도에 등록해 드려요." (주체+확인+등록 구조)
- 처리 기간은 명시하지 않는다.

## 근거

- "제보"는 카카오맵·포카맵·워시맵·Coffice에서 폐업·수정까지 뭉뚱그리는 말. 신규는 카카오맵·네이버 "신규 장소 등록", 다이닝코드 "식당 등록 요청".
- CTA: TDS BottomCTA·캐치테이블 하단 고정. 버튼 아래 설명 캡션은 HIG 금지, 5사 중 폼 안에 검수 안내를 두는 곳 없음(카카오·네이버·포카맵 관례).
- 기간을 약속하면 검수 리듬이 바뀔 때 문구 부채가 된다.

## 버린 안

- "제보하기" 라벨, CTA 아래 검수 캡션.
