# 홈에서 연 등록 폼은 지금 보는 지도 중심을 위치로 첨부한다

## 맥락

링크가 없는 가게도 위치를 받아야 했다. 좌표는 운영자가 확정한 수동 핀만 저장할 수 있다 → [타사 플랫폼 데이터 경계](../../../decisions/0002-third-party-data-boundary.md)

## 결정

- 홈에서 등록 시트를 열면 [지금 보는 지도 위치 첨부] 토글로 현재 뷰포트 중심을 수동 핀으로 첨부한다(`details.pin`).

## 근거

운영자 확정 수동 핀은 저장 허용. 별도 지도 UI 없이 바로 구현 가능.
