# 검수 처리는 확인 창 없이 즉시 실행 + 10초 되돌리기 토스트

## 맥락

검수자는 하루에 여러 건을 연달아 처리한다. 처리마다 확인 창을 띄우면 느리고, 습관적으로 눌러 실수를 막지도 못한다.

## 결정

- 처리(반영함·중복·반려, 사진 승인·반려)와 다시 열기 모두 확인 창 없이 즉시 실행한다.
- 실행 직후 10초 "되돌리기" 토스트를 띄운다. 제보는 이전 status로, 사진은 pending으로 되돌린다.

## 근거

NN/g 확인 창 남용 비판, Polaris 액션 토스트 ≥10초. 되돌릴 수 있는 상태 변경은 확인 창 대신 실행 취소.

## 버린 안

- 처리마다 확인 창.
