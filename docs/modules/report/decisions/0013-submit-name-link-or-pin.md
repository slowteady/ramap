# 등록 제출 조건은 가게 이름 + (링크 1개 이상 또는 핀)

## 맥락

링크가 없으면 핀 또는 사진으로 대체할 수 있게(사진만으로도 제출) 했더니 위치 정보가 0인 제보가 가능했다. 사진만으로는 어디 있는 가게인지 처리할 수 없다.

## 결정

- 제출 가능 = 가게 이름 + (형식이 맞는 링크 1개 이상 또는 지도 핀).
- 사진만으로는 제출할 수 없다. 사진은 계속 선택 입력이다.
- 링크의 필수 표시(`*`)는 핀이 지정되면 사라진다(둘 중 하나 요구를 정직하게 반영).

## 근거

사진만으로는 위치 정보가 0이라 처리 불가. 원문: `docs/plans/2026-09-03-backlog.md` §2.

## 버린 안

- 이름 + (링크 또는 핀 또는 사진)(2026-08-31, 네이버 영수증·전경 증빙과 카카오 "간판 확인되는 전경" 관례) — 사진만으로는 위치 정보가 0이라 처리 불가.
- 홈에서 연 등록 폼에 [지금 보는 지도 위치 첨부] 토글로 뷰포트 중심을 핀으로 첨부(2026-08-31) — 시트가 지도를 덮어 조준할 수 없었고 운영자가 그 좌표를 믿을 수 없었다. 지금은 중앙 십자선 핀 피커 → [report 설계](../design.md#핀-피커)
