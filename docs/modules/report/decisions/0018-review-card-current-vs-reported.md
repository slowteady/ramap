# 검수 카드는 현재 값 대비 제보 값으로, 같은 제보는 묶어서

## 맥락

제보 카드가 긴 네이버 지도 URL에 밀려 가게명이 한 글자씩 세로로 접히고, 유형 배지가 줄바꿈되며, 원시 JSON "상세 페이로드"가 노출됐다.

## 결정

- 카드 = 유형 배지 · 가게명(지점) · 접수 시각·#id / 유형별 본문 / 메시지 / 사진 / 액션.
- 신규: 링크는 원문 URL 대신 서비스 이름 칩(네이버 지도·카카오맵·인스타그램·도메인) + 핀 위치(카카오맵 아웃바운드).
- 수정: 대상 매장 주소(매장 페이지 링크) → 제보 메시지 → 항목별 **현재 값 → 제보 값**(제보 값이 있으면 현재 값 취소선).
- 같은 링크(신규) 또는 같은 매장(수정)의 대기 제보는 최신 1건 카드로 묶고 "같은 제보 N건 더". 처리하면 묶음 전체에 적용.
- 대기는 오래 기다린 순 + "N일 경과", 처리됨은 처리 시각 최신순 + 결과 배지 맨 앞.
- 넘침 처리: flex 자식 `min-w-0`, URL은 `wrap-anywhere`, 배지 `shrink-0 whitespace-nowrap`.

## 근거

- 수정 제안은 현재 값 대비 제안 값으로 판단 — Stack Overflow suggested edits, OSMCha 태그 비교, Wikipedia pending changes.
- URL 원문 대신 도메인 칩 — Baymard 말줄임 가이드.
- 대기 정렬·경과일 — Help Scout·Wikipedia. 처리됨 결과 배지 — Discourse.
