# 정보 수정은 항목 다중 체크 + 체크한 항목의 입력 필드

## 맥락

캐치테이블은 수정 제보를 자유 텍스트 하나로 받는다. 라맵은 구조화 데이터가 자산이다.

## 결정

- 수정 항목을 다중 체크: 폐업·휴업했어요 / 영업시간이 달라요 / 메뉴·가격이 달라요 / 장르가 달라요 / 편의 정보가 달라요 / 위치가 달라요 / 기타.
- 체크한 항목의 입력 필드만 아래에 노출. 폐업·휴업은 폐업/휴업 선택 + 근거 링크(선택).
- 상세 내용(선택, 500자) + 사진(선택).
- 매장은 진입한 상세 페이지로 프리필된다.

## 근거

구조화 데이터 = 자산. 폼 공통 구성(항목 다중 체크 + 자유 텍스트 + 사진)은 2026-08-31 5사 실측 → [진입점 결정](0004-entry-point-sets-type.md)

## 버린 안

- 자유 텍스트 하나(캐치테이블식).
