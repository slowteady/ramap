# 제보 사진은 확인용 — 출처 불문 접수, 게재 단계에서 거른다

## 맥락

등록 폼에 사진을 받으면서 "직접 촬영 동의 체크박스"를 둘지 정해야 했다. 타인 사진 게재는 금지다 → [타사 플랫폼 데이터 경계](../../../decisions/0002-third-party-data-boundary.md)

## 결정

- 제보 사진은 **확인용 자료**다. 캡처·SNS 이미지도 받는다.
- 안내 문구·동의 체크박스는 두지 않는다.
- 게재는 파트너가 직접 촬영 여부를 확인한 것만. 데이터 경계는 업로드가 아니라 게재 단계에서 지킨다.
- 업로드 전 클라이언트에서 리사이즈(1600px)·JPEG 재인코딩(EXIF 제거) → 비공개 버킷 `report-photos`(익명 업로드만, 일반 열람 불가).

## 근거

네이버 이용자 제보 3단계 관례("SNS 캡처 올려주세요"). 게재 동의가 필요한 건 완식 사진(records 모듈)뿐이다. PO 결정(2026-08-31 4차 조정).

## 버린 안

- 직접 촬영 동의 체크박스·안내 문구.
