# 새 라멘집 등록은 링크 우선 — 가게 이름과 링크만 받는다

## 맥락

1차 구현은 "필수 2개(이름·위치) + '아는 만큼만 알려주세요' 접힘 상세층(장르·편의·영업시간·메뉴)", 2차는 시트 컬럼 1:1 펼침이었다. 영업시간·메뉴·주소·좌석은 인스타·카카오맵·네이버 링크 하나면 파트너가 확인할 수 있는데, 사용자에게 재타이핑을 시키는 설계였다.

## 결정

- 받는 것: 가게 이름(필수) + 지점명(선택, 이름과 같은 행) + 링크(최대 3) + 지도 위치 핀 + 사진(최대 5, 확인용) + 자유 입력.
- 받지 않는 것: 장르·영업시간·메뉴·주소·좌석·편의. 장르 힌트는 자유 입력 한마디로 충분하다.
- 검수 = 운영자가 링크를 열어 매장 시트 컬럼을 채운다.
- 링크는 blur 시 형식 검증 + 힌트 한 줄 "인스타그램, 카카오맵, 네이버 지도 중 하나면 충분해요". 첫 행은 삭제 버튼 없음.
- 입력 예시 플레이스홀더는 두지 않는다.
- 접힘 토글은 없다(필드가 적어 필요 없음).

## 버린 안

- 필수 2개 + "아는 만큼만 알려주세요" 접힘 상세층(1차).
- 시트 컬럼 1:1 펼침(2차).
- 장르 칩(국물·종류·스타일) 선택.
