# "내 제보"는 하이브리드 — 익명 유지 + 로그인 제보만 귀속 (구현 보류)

## 맥락

제보자는 자기 제보가 반영됐는지 알 수 없다. 카카오·네이버·구글은 처리 결과를 메일·톡·상태 탭으로 알린다. 라맵에는 통지 채널이 없다.

## 결정

설계는 확정, 구현은 보류(2026-09-01):

- 익명 제보는 그대로 둔다. 로그인 상태의 제보에만 `user_id`를 자동 귀속한다.
- 마이에 "내 제보"(상태 배지: 접수/검수 중/반영).
- `reports`에 `user_id`(nullable) + RLS 본인 select.
- 완식 인증과 함께 "내 기여"(제보 반영 N + 인증 M)로 확장할 수 있다.
- 제보 폼에 "로그인하고 제보하면 반영 소식을 마이에서" 한 줄 — 로그인 유도 겸용.
- 결과 통지(이메일·카카오톡)는 로그인 사용자 한정, 개인정보 최소 수집 원칙과 함께 따로 검토한다.

## 근거

2026-08-31 4차 조사에서 3사 공통 관례로 확인(네이버 메일, 카카오 톡/장소 제안 탭, 구글 상태 업데이트). 카카오맵은 이메일 동의 시 처리 결과 발송. 익명 입구 원칙([익명 제보](0002-제보는-로그인-없이-익명.md))을 깨지 않는 하이브리드.
