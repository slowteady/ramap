# 제보는 로그인 없이 익명으로, 스팸은 속도 제한·허니팟으로

## 맥락

제보 문턱이 낮아야 제보가 들어온다. 익명을 허용하면 스팸 방어가 필요하다.

## 결정

- 제보는 로그인 없이 낼 수 있다. 익명 허용.
- 스팸 방어는 IP 속도 제한 + 허니팟 필드로 한다.
- 기기 핑거프린팅은 하지 않는다.
