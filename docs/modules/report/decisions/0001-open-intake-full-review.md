# 입구는 최대 개방, 출구는 전건 검수

## 맥락

매장 데이터를 사용자 제보로 넓히되, 잘못된 정보가 지도에 바로 오르면 신뢰가 무너진다.

## 결정

- 제보 입구는 최대한 연다(로그인 없음, 익명 허용).
- 모든 제보는 운영자가 확인한 뒤에만 반영한다.
- 검수·반영의 주 담당은 파트너(라오타)이고, 빌더는 파이프라인만 맡는다. 판정→반영 사이에 개발자 손이 끼면 안 된다.
- 제보는 입력이지 판결이 아니다. 장르 이견은 라오타가 최종 판정한다.
