# 제보 보상(포인트류)은 두지 않는다

## 맥락

대형 지도 3사는 제보에 포인트·리워드를 준다.

## 결정

- 제보 보상은 도입하지 않는다. 감사 문화로 갈음한다.
- 특정 제보자가 반복적으로 정확하면 신뢰 제보자 우대를 3막에 검토한다.

## 근거

라맵 규모에선 보상 운영 부담이 크고, 조건부 외적 보상은 내재 동기를 훼손한다(records 모듈 금지 목록 → [records 요구사항](../../records/requirements.md)). 감사 문화는 data 모듈의 데이터 전략 → [data 설계](../../data/design.md)
