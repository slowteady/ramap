# 사진·한줄평은 완식의 선택 부가물, 검수 승인분만 매장 페이지에 승격

## 맥락

완식에 사진·한줄평을 붙여 기록을 풍부하게 하고 매장 페이지 콘텐츠로도 쓰고 싶었다. 원안은 "사진+한줄평 = 완식의 필수 인증, 인증/무인증 마커 2색"이었다.

## 결정

| 항목 | 결정 |
|---|---|
| 사진+한줄평 | **선택 부가물** — 기록의 전제가 아니다 |
| 등급 표현 | **마커 불변.** 부가물 있는 완식만 매장 상세 콘텐츠로 승격(집계 게이트) |
| 섹션 이름 | **"완식 기록"** |
| 한줄평 | 선택, **30자** — 태그라인 인용구 한 줄 분량 |
| 공개 범위 | "매장 페이지에 소개돼도 좋아요" 동의(기본 on) + 운영자 선검수 승인분만 타인에게 노출 |
| 본인 노출 | 제출 즉시 본인에게 표시하되 **"검토 중" 라벨 필수** |
| 검수 | 하루 1회 일괄 수동 검수로 충분 |
| 저장 구조 | 단일 비공개 버킷 + RLS. 승인은 파일 이동 없이 status 변경만 |
| 약관 | 이용허락 조항(저작권 작성자 귀속, 서비스 노출 범위 내 무상·비독점 이용, 언제든 삭제·비공개 요청) |

공개 사진 가이드 3항: 라멘이 주인공 / 직접 찍은 사진 / 다른 사람 얼굴이 안 나오게 (구글 지도 UGC 정책 축약).

## 근거

2026-09-01 BP 딥다이브 3갈래:

1. **국내 실측** (네이버 플레이스·캐치테이블·배민·오늘의집): 전부 "인증은 필수, 콘텐츠(사진·텍스트)는 선택". 사진은 강제 대신 노출 우위·차등 보상으로 유도. 인증 표시는 배지가 아닌 메타 한 줄(`8.10.월 · 1번째 방문 · 영수증`). 매장 페이지는 사진 그리드 우선.
2. **해외 체크인 문헌** (Untappd·Letterboxd·Beli·Vivino·Swarm·ramendb): 기록(체크인)은 무조건 가볍게, 사진·평은 선택 — 예외 0. 인증의 하드 등급(마커 색) 전례 0, 표준은 "인증분만 장소 페이지 공용 콘텐츠로 승격". Foursquare 교훈: 기록을 막은 Gowalla는 실패, 기록 허용+보상만 검증 연동이 생존.
3. **검수 운영** (Bazaarvoice·구글 리뷰·Reddit): 리뷰 장르는 선검수가 표준(SLA 72h — 지연이 이탈 요인이 안 되는 기대치), "본인 즉시 노출 + 타인 검수 후"는 가시성 플래그로 검증된 패턴. 1인 운영이면 하루 1회 일괄 검수로 충분.

[참여 설계](../requirements.md#단계별-범위) 정합: 기록 체계 형태 불변, 배지·레벨 금지(보상은 "내 기록 풍부화"까지만), 별점 없음, 리뷰는 "완식 부속 코멘트의 선택적 공개"([3단 집단 산출](../requirements.md#3단-집단-산출)). 이용허락 문구는 국내 표준(당근 약관 계열).

## 버린 안

- 사진+한줄평 필수 인증 — 국내외 전례 모두 "기록은 가볍게".
- 인증/무인증 마커 2색(소급 '가봤어요' 회색조 포함) — 하드 등급 전례 0.
- 스토리지 승인 시 공개 버킷으로 파일 이동 — 운영 단계가 늘어난다.
