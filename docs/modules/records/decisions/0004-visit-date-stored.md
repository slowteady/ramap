# 완식 기록에 날짜를 저장한다

## 맥락

화면에 날짜를 보여주지 않더라도, 2단 연말 정산(Year in 라멘)의 원료가 필요하다.

## 결정

- 완식 기록마다 첫 완식일과 최근 완식일을 저장한다(UI 노출 여부와 무관).
- 별점은 받지 않는다.
