# 3단(집단 산출) 설계 — 횟수 집계·가게 어워드·코멘트 선택 공개

## 맥락

개인 기록의 총합을 공공재로 돌리는 3단을 미리 봉인 설계해 두지 않으면, 나중에 랭킹·보상으로 미끄러질 위험이 있다.

## 결정

1. 집계는 점수 랭킹이 아닌 **완식 횟수 집계**.
2. 어워드는 유저 순위가 아니라 **가게에 주는 집단 산출물** — 개별 보상 없음, 가중치 비공개.
3. 리뷰는 별점 집계가 아닌 **완식 기록 부속 개인 코멘트의 선택적 공개**. 완식 기록의 공개 동의 체크와 운영자 선검수로 구현했다 → [사진·한줄평 결정](0015-사진-한줄평은-선택-부가물-검수-승격.md)
4. H-index류 파생 지표는 만들지 않고 집계 데이터 공개로 갤러리가 자생시키게 한다.
5. 재검토 후보: Beli식 pairwise 서열(로그인 후), Sakenowa식 텍스트→시각화(대량 축적 후), 가게 N회 완식 자동 표시.

## 근거

1. ramendb 가중 포인트의 산출식 튜닝·논쟁 부담 회피 — 횟수는 논쟁 자체가 없음
2. Foursquare: 보상이 걸리는 순간 허위 체크인 폭발
3. The Shed at Dulwich — 가짜 리뷰로 런던 1위. 협찬 오염의 대안이라는 존재 이유와 자기모순 금지. 승격 게이트(인증분만 공용 콘텐츠)는 Untappd·Letterboxd·Foursquare 공통 패턴
4. BGG — 10x10 챌린지 전부 유저 발명
