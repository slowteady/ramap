# 기록 상태는 완식과 저장(구 가고 싶다) 둘, 부정 상태 없음

## 맥락

가게에 대해 사용자가 남길 수 있는 상태를 정해야 했다.

## 결정

- 상태는 **완식**과 **가고 싶다** 두 가지. "가고 싶다"의 현재 이름은 **저장**이다.
- "별로였다" 같은 부정 상태는 두지 않는다.
- 두 상태가 한 가게에 함께 있을 수 있는지는 [완식과 저장 공존](0019-완식과-저장-공존.md)에서 정했다.
