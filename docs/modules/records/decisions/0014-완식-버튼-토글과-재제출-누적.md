# 완식 버튼은 토글, 재방문 횟수는 완식 기록 재제출로만 +1

## 맥락

2026-08-28에 완식을 좋아요식 토글(가게당 1회, 재클릭은 해제, 횟수 누적 없음 — 어뷰징 차단)로 정했다. 그런데 기록 단위는 재방문 누적이라([1杯 1방문](0003-완식-1杯-1방문-단위.md)) 문서와 구현이 어긋났다. 완식 사진·한줄평을 도입하며 이를 정리했다.

## 결정

- 완식 버튼은 토글을 유지한다(on = 횟수 1, 다시 누르면 해제).
- 토글 off→on 직후 완식 기록 시트를 1회 띄운다.
- 이미 완식한 매장은 상세 "완식 기록" 섹션의 [남기기]로 재제출하고, 재제출마다 `records.count` +1 — "N번째 완식"의 원천.

## 근거

- 버튼을 누를 때마다 누적하면 취소와 재방문을 구분할 수 없어 토글 UX가 깨진다.
- 무인증 연타 누적을 다시 열게 된다.
- 사진 없는 재방문 체크인(풀 이벤트 로그)의 수요가 실증되지 않았다.

## 버린 안

- 버튼 누를 때마다 누적(풀 누적) — 위 근거로 기각.
