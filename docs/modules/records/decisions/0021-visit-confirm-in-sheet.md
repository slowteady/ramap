# 완식은 기록 시트에서 "기록하기"를 눌러야 +1, 되돌리기 없음

## 맥락

완식 버튼이 토글이라(2026-09-01 결정) 다시 누르면 확인 없이 기록이 지워져 횟수·첫 완식일이 사라지고 사진만 남는 결함이 있었다(2026-10-28 멘코지 실사용).

## 결정

- 완식 버튼은 토글이 아니다. **누르면 기록 시트가 열리고, 시트의 [기록하기]를 눌러야 +1.**
- 시트를 닫으면 아무것도 기록되지 않는다. 잘못 누름이 저절로 걸러지므로 되돌리기는 두지 않는다.
- 사진·한줄평은 선택, 한줄평은 사진과 함께.
- 버튼 문구·모양은 고정("✓ 완식", 채움). 횟수는 버튼 밖 상태 줄("완식 3회 · 최근 10.28" — 상세 상단·지도 카드).
- 서수는 시트 제목("4번째 완식", 첫 번째는 "첫 완식"). 확정 버튼은 구체 동사 "기록하기".
- 기록 직후 토스트는 없다.
- 완식 기록 삭제는 마이 → 기록 뷰어에서 확인을 거쳐서만.
- 상세 "완식 기록" 섹션의 [남기기]는 횟수를 바꾸지 않는 사진 추가.

## 근거

- Untappd·Swarm·Letterboxd: 버튼은 기록 화면을 열고 확인해야 기록된다.
- 상태 줄: Untappd "You"·Google 지도 "You visited" 문법.
- 버튼 라벨 BP: 일반어(확인·완료) 대신 구체 동사.
- 토스트 BP: 결과가 화면에 보이면(상태 줄이 바로 바뀜) 확인 메시지는 중복.
- 첫 완식이 1탭→2탭이 되는 마찰은 정확한 횟수와 맞바꾼다.
- 이전 결정의 근거였던 무인증 연타는 [로그인 필수](0013-records-require-login.md)로 해소됐다.

## 버린 안

- 토글 유지 + 재제출로만 +1(on = 1회, 다시 누르면 해제, 이미 완식한 가게는 상세 [남기기] 재제출마다 +1. 2026-09-01 결정) — 다시 누르면 확인 없이 기록이 지워지는 실사용 결함.
- 토글 해제 후 되돌리기 토스트 — 닫기로 이미 걸러지므로 불필요.
