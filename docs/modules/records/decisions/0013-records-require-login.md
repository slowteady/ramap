# 서버 저장 환경에서 기록은 로그인 필수

## 맥락

비로그인 localStorage 기록과 로그인 서버 기록이 공존하면, 무인증 연타로 횟수를 부풀릴 수 있고 기기 간 기록이 갈린다.

## 결정

- Supabase가 설정된 환경에서는 완식·저장을 누를 때 로그인이 필요하다. 비로그인이면 카카오 로그인 시트를 띄운다.
- 열람은 계속 로그인 없이 가능하다 → [열람 개방](0011-kakao-login-open-browsing.md)
