# 소목록 진행률 노출 보류 — 계보 페이지 진행 막대를 내린다

## 맥락

진행률은 장르×지역 소목록 단위("서울 이에케 4/7")로, 10곳 내외의 달성 가능한 크기로 두고, 전국 전체를 유일 목표로 걸지 않기로 했었다(2026-08-26, Kivetz 목표 구배·BAC 명산100·일본 랠리. 포켓몬GO 반면교사: 전국 전체만 목표면 지방 유저가 좌절). 이것을 계보 랜딩에 진행 막대로 배포했지만, 소목록 자체가 정제되지 않았다.

## 결정

- 계보 페이지 진행 막대를 내리고 진행률 노출을 보류한다.
- 재개 시 정할 것: 목록 단위·노출 위치·인정증.
- 재개해도 단위 원칙은 그대로다: 장르×지역 소목록, 10곳 내외, 전국 전체를 유일 목표로 걸지 않는다.
