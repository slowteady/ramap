# 첫 방문 온보딩에서 가본 집을 먼저 찍게 한다

## 맥락

0에서 출발하는 기록은 동기가 약하다(B 계열 "0에서 출발 금지"). 이미 가본 집을 소급 기록하게 하면 시작부터 진전이 생긴다.

## 결정

- 첫 방문 1회 전체 오버레이: "가본 라멘집을 먼저 찍어보세요" + 이름 검색 + 매장 체크 그리드 + "지금까지 N곳 완식" + "내 라멘 지도 시작하기", 건너뛰기 가능.
- 완료·건너뛰기 후 다시 노출하지 않는다.

## 근거

부여된 진전(endowed progress) 효과 — 0에서 출발하지 않게. 출처: [딥리서치 보고서](../research/2026-08-26-engagement-retention-research.md)
