# 로그인은 카카오 소셜 로그인, 열람은 완전 개방·기여만 계정

## 맥락

기록을 기기 밖에 지키려면 계정이 필요하지만, 가치 경험 전 계정 요구는 금지다([금지 목록](0002-게임화-장치-금지-목록.md) 8).

## 결정

- **열람 완전 개방, 기여만 계정.** 지도·매장·가이드는 로그인 없이 본다.
- 방식은 **카카오 소셜 로그인(Supabase Auth)**.
- 로그인은 기존 로컬 기록을 지키는 수단으로 제시하고, 로컬 기록 이관을 반드시 제공한다.
- 시점은 개발 순서상 맨 마지막, 트리거(동기화 문의 또는 집단 참여 개방) 시 도입 — 2026-08-27에 도입됐다 → [서버 저장 결정](0012-기록-서버-저장과-로그인-병합.md)
- 로그인을 나중에 붙여도 화면을 고치지 않도록 이음새를 둔다 → [platform 설계](../../platform/design.md)
