# 첫 진입 온보딩을 없애고 바로 지도로

## 맥락

첫 방문 온보딩([소급 기록 온보딩](0009-첫-방문-온보딩-소급-기록.md))이 첫 진입을 가로막았다. 기록은 로그인 필수가 되어 비로그인 첫 방문자에게 소급 체크를 받을 수도 없다.

## 결정

- 첫 진입은 바로 지도다. 온보딩 화면을 두지 않는다.
- 소급 기록 유도는 강제 화면 없이 /me 빈 상태 문구 수준으로만 한다.
- "부여된 진전" 근거는 완식 인증·진행률 도입 시 재검토한다.
