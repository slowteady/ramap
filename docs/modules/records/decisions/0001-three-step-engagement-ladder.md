# 참여 설계는 3단 사다리, 기록이 1단 본체

## 맥락

완식 기록을 어떤 참여 장치 위에 세울지 정해야 했다. 글로벌 덕후 서비스 30여 개 메커니즘을 멀티에이전트 딥리서치로 조사했다 → [보고서](../research/2026-08-26-engagement-retention-research.md)

## 결정

메커니즘을 5계열로 나누고 3단 사다리에 배치한다.

| 계열 | 원리 | 배치 |
|---|---|---|
| A. 기록·축적 (자기완결) | 이미 하는 행위의 외화 → 축적의 단일 시각화. 규모 무관 작동 | 1단 본체 |
| B. 진행·목표 | 유한·권위 목록 + 보이는 빈칸 + 달성 가능 크기 + 0에서 출발 금지 | 1단·2단 |
| C. 정산·공유 | 데이터를 이야기로 반환 → 유저가 배급망이 됨 | 2단 본체 |
| D. 경쟁·지위 | 강력하나 임계질량 필요 + 어뷰징·소외·강박 구조적 비용 | 전면 금지 |
| E. 집단 산출·자생 | 개인 기록 총합 = 공공재, 파생 문화는 커뮤니티가 발명 | 3단 전용 |

메타 원칙: **완식 기록 체계는 3단까지 형태 불변, 그 위에 쌓기만 한다.** 신규 장치는 "10년 유지 가능한가 + 나중에 뗄 수 있는가"를 통과해야 한다.

## 근거

- 도메인 정합성: "완식"은 게임 용어가 아니라 라멘 문화 내부의 실천 용어(스프까지 비움) — A가 게임이 아닌 기록으로 읽힌다. 순회·원정 문화 = B의 순례 프레임. 갤러리 인증 문화 = C의 무료 배급망. 장르 택소노미 = B의 권위 목록 요건.
- 당시 설계(완식·카운트·무로그인 로컬 저장)는 실패 사례들의 여집합에 위치함이 확인됨.
- 메타 원칙: Foursquare/Swarm — 정체성이 된 장치의 제거는 3위→146위 추락.
