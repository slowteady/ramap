# 진행률은 장르×지역 소목록 단위 ("서울 이에케 4/7")

## 맥락

진행·목표(B 계열)를 넣는다면 목록 크기가 동기를 좌우한다.

## 결정

- 진행률은 장르×지역 소목록 단위로 보여준다. 예: "서울 이에케 4/7".
- 목록은 10곳 내외의 달성 가능한 크기로 둔다.
- 전국 전체를 유일 목표로 걸지 않는다.
- 노출은 현재 보류 상태다 → [진행률 노출 보류](0024-defer-progress-display.md)
