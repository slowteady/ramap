# 마이 완식 탭은 인스타형 3열 사진 그리드

## 맥락

완식 기록에 사진이 붙으면서 마이 완식 목록을 텍스트 리스트로 둘지 사진 중심으로 바꿀지 정해야 했다.

## 결정

- 완식 탭은 3열 정사각 사진 그리드. 사진 없는 기록은 라멘 아이콘 타일 + 상호.
- 그리드 탭 → 기록 뷰어(사진 가로 스와이프 + 도트). 매장 이동은 뷰어의 [매장 보기]로 한 단계 뒤.
- 저장 탭은 리스트를 유지한다.

## 근거

PO 결정(2026-09-03). 인스타그램 프로필 그리드 문법.
