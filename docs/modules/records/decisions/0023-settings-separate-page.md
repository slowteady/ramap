# 설정성 메뉴는 마이 헤더 ⚙ → /settings 전용 페이지

## 맥락

마이 하단에 메뉴(약관·로그아웃·탈퇴·라멘집 등록 등)가 쌓여 기록 목록과 섞였다.

## 결정

- 마이 헤더 우상단 설정(⚙) → `/settings` 전용 페이지(시트 아님).
- 설정에는 설정성 항목만: 약관 및 정책(이용약관·개인정보 처리방침·문의하기) / 계정(로그아웃·회원탈퇴, 로그인 시만).
- 장르 가이드는 마이 프로필 카운트 줄 우측 링크로 둔다. 라멘집 등록은 홈 두 곳과 중복이라 마이에서 뺀다.
- 기록 목록이 마이 페이지의 마지막 요소가 된다.

## 근거

네이버 MY플레이스 ⚙ 문법. 목록이 마지막이면 길어져도 밀리는 요소가 없다.

## 버린 안

- 설정 시트 — 페이지가 맞다(PO 2026-09-03).
- 마이 하단 메뉴 리스트.
