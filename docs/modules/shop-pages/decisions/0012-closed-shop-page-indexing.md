# 폐업 매장 페이지 — 검증된 것만 공개하고 색인한다

## 맥락

시트에서 폐업으로 표시된 매장 중 일부는 실제로 영업 중이었다(2026-10-19 기존 폐업 50곳 재검증: 확정 폐업 8 · 이전 3 · 영업 중 오판 4 · 미확정 35). 한편 "○○ 폐업했나?"는 실제 검색 수요다.

## 결정

- 폐업·이전 페이지는 검증 장부(`data/closure-verification.json`)에 판정이 있는 매장만 공개한다. 제목·본문에 `[폐업]`/`[이전]`을 밝힌다(타베로그 【閉店】 방식)
- 장부에 없는 폐업 매장은 페이지 자체를 내린다: 정적 생성 안 함 → 404, 사이트맵 제외
- 공개된 폐업·이전 페이지도 색인한다. 색인 제외 기준은 정보 부족(얇은 페이지)뿐이다
- 판정은 `closure-verification` 스킬 기준을 통과한 것만 장부에 오른다 → [data 설계](../../data/design.md)

## 근거

- 2026-10-19 PO 확정
- 확인되지 않은 폐업 표시는 영업 방해·명예훼손 소지
- 타베로그는 폐업 매장 페이지를 【閉店】으로 남겨 "폐업했나?" 검색에 답한다

## 버린 안

- 폐업 매장 전부 noindex — 폐업 여부 검색에 답하지 못한다
- 시트 상태만으로 폐업 공개 — 오판(영업 중 4곳) 위험
