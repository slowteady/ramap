# 지역×장르 페이지 생성 기준 — 매장 3곳 이상 조합만, 빈 조합은 404

## 맥락

지역 × 장르(국물·계보 slug) 조합을 순열로 늘리면 매장 0~2곳짜리 빈 페이지가 대량으로 생긴다. 얇은 페이지 대량 색인은 검색엔진 품질 평가를 깎는다.

## 결정

- 지역×장르 정식 URL은 **영업 매장 3곳 이상** 조합만 `generateStaticParams`로 생성한다(`listAreaGenrePages(shops, min = 3)`)
- 미달 조합은 페이지를 만들지 않는다(요청 시 404). 그 조합은 홈 지도의 필터 쿼리로만 보고, 홈 canonical(`/`)이 쿼리 변형을 흡수한다
- 조합 확장의 정식 게이트는 "매장 3곳 이상 + 검색 수요 실재". 검색 수요는 실측 전이라 현재는 3곳 규칙만 적용한다. 검색 순열 커버리지식 확장은 하지 않는다

## 근거

- 13번 UI 설계원칙 E절(2026-08-26): 조합 폭발 관리 — 매장 3곳+ & 검색 수요 있는 조합만 정식 URL·색인, 나머지는 지도 쿼리 상태 + canonical 상위 정규화
- Plan 4(2026-08-26) 글로벌 제약: 3곳 이상 조합만 생성, 미달 조합은 생성하지 않음
- 2026-09-05 SEO 딥리서치: 구글 faceted-navigation 공식 문서 "no results → 404" — 미생성 = 404 구조가 이미 부합. scaled content 판정 기준은 목적·가치·탐색 계층이라 순열식 확장은 위험
- 15번 태깅 시트 스키마의 `노출` 컬럼도 "매장 3곳 미만 조합은 공개 금지(SEO 씬 페이지 방지)"로 같은 기준

## 버린 안

- 모든 조합 생성 + noindex — 크롤 표면만 늘고 사이트맵·내부 링크 정합이 깨진다
