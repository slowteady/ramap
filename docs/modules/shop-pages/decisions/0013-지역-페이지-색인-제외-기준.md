# 지역 페이지 색인 제외 기준 — 3곳 미만 지역·기타 장르

## 맥락

구글 서치콘솔에 "크롤링됨 - 현재 색인이 생성되지 않음" 520건이 쌓였다. 매장 1~2곳 지역 페이지는 매장 페이지와 내용이 겹친다.

## 결정

- 지역 단독 페이지 `/area/{지역}`는 매장 3곳 미만이면 noindex + 사이트맵 제외(`shouldNoindexArea`). 페이지와 내부 링크는 유지
- 지역×장르 중 `etc-soup`(기타)는 noindex + 사이트맵 제외(`shouldNoindexAreaGenre`)
