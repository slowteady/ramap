# 신규 오픈 전용 페이지 폐기 — 배지·필터로 노출

## 맥락

Plan 4(2026-08-26)에서 `/new`(월별 신규 오픈 목록 + 빈 상태 + 제보 유도 배너)를 만들고 홈 헤더·마이 메뉴에서 링크했다.

## 결정

- `/new` 페이지와 마이 메뉴 항목을 삭제한다
- 신규 오픈은 4곳에서 같은 기준으로 표시한다
  - 기준: 오픈일(인허가일) 기준 **90일**, `isNewOpen` — 빌드 시점 계산
  - 지도 마커: 라벨 앞 레드 "NEW" 칩, 라벨 충돌 시 신규는 점으로 강등되지 않음(선택 > 신규 > 일반 > 완식)
  - 홈 목록 행: 상호 앞 NEW 칩 + 메타 "9/1 오픈"(절대일)
  - 매장 카드·상세: 상호 옆 NEW 칩, 상세 정보 표에 "오픈 YYYY.M" 행
  - 홈 필터 행 "새로 오픈" 토글 칩 — 90일 내 오픈 매장이 1곳 이상일 때만 노출(0건 칩 금지), URL `?new=1`

## 근거

- 네이버 '새로오픈'·배민 '신규'·Google 'Recently opened'·타베로그·ramendb 전부 홈·검색 결과 안의 **배지·필터**로 노출한다. 전용 페이지를 둔 곳이 없다
- 라맵 시드 규모(월 1~2회 인허가 diff)에선 전용 페이지가 대부분 빈 상태
- 90일은 네이버·배민·Google 동일 기준
- 오픈일 표기는 절대일 — 상대 표기("3일 전")는 전 서비스에서 확인되지 않음

## 버린 안

- `/new` 월별 그룹 목록 페이지(`groupByOpenedMonth`)
