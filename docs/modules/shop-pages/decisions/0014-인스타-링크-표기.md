# 상세 SNS 행 — "인스타그램 ↗" 텍스트 아웃링크

## 맥락

인스타 링크를 전수 검수하면서(링크 510 → 682곳) 지점 계정과 체인 브랜드 계정이 섞여 있고, 한 브랜드 계정을 여러 지점이 함께 쓰는 경우가 확인됐다.

## 결정

- 상세 정보 표에 "SNS" 행, 값은 "인스타그램 ↗" 텍스트 새 탭 아웃링크. 행 높이 44px 터치
- 계정명·로고를 쓰지 않는다. "인스타그램"을 축약하지 않는다
- 지점 계정·브랜드 계정을 구분해 표기하지 않는다
- 여러 지점이 공용으로 쓰는 계정은 JSON-LD `sameAs`에서 뺀다 — 이 매장과 같은 실체가 아니다

## 근거

- 2026-10-27 6개 서비스 실측: 네이버 플레이스 관례(텍스트 링크)
- 타사 로고 금지 → [공통 결정](../../../decisions/0002-타사-플랫폼-데이터-경계.md)
- Meta 상표 표기 규칙: "Instagram" 축약 금지
- `sameAs`는 "같은 실체"를 검색엔진에 알리는 속성 — 공용 계정은 해당하지 않음
