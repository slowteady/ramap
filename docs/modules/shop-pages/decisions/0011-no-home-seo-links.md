# 홈에 SEO 링크 섹션을 두지 않는다

## 맥락

SEO 점검(2026-09-05)에서 홈 → 랜딩(`/area/*`·`/style/*`·`/guide/*`)으로 가는 크롤러블 앵커가 0개였다. 홈 하단에 SSR 링크 섹션을 넣는 안을 구현해 봤다.

## 결정

- 홈은 순수 지도 앱으로 둔다. SSR 링크 섹션·스크롤 푸터를 넣지 않는다(2026-09-05 PO 기각)
- 랜딩 발견은 sitemap·robots가 담당하고, 링크 그래프는 랜딩 간 교차 링크(지역 페이지의 상위·인근 지역·하위 장르)가 대신한다
- 홈의 링크 주스는 포기한다

## 근거

- 몰입형 지도 홈에 스크롤 푸터는 UX 위반
- 12번 정보구조 문서도 같은 방향으로 갱신됨
- Airbnb 지역 페이지 62앵커 실측 — 랜딩 간 링크 메시가 링크 그래프 역할

## 버린 안

- 홈 SSR 링크 섹션 — 구현 후 PO 기각
