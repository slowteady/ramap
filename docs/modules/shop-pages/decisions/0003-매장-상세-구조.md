# 매장 상세 구조 — 11개 서비스 실측 관례

## 맥락

Plan 4(2026-08-26)의 상세는 "폴리싱 미룸" 골격이었다: 회색 placeholder 히어로, 상호 옆 대표 스프 배지·장르 칩, 가이드 배너, "지도에서 보기" 링크. 사진 데이터가 0장인 상태가 출시 기본값이었다.

## 결정

위→아래: 사진 캐러셀(0장이면 블록 없음) / 뒤로가기 / 상호 / 텍스트 메타(동네 · 장르) / 영업 줄 / 액션 행 `지도 · 길찾기 · 공유` / 한줄소개 / 정보 표(dl) / 대표 메뉴 / 오시는 길(주소 + 복사) / "잘못된 정보가 있나요?" 일급 행 / 근처 라멘집 3곳 / 하단 고정 CTA [저장][완식]

- 상세 헤더의 장르는 칩이 아니라 **텍스트 한 줄**. 3축 구조는 정보 표 행(국물·종류·스타일)으로 보존
- 사진 0장이면 히어로를 없애고 상호 블록이 첫 화면. 회색 placeholder 금지
- 액션은 3개. 전화 없음, 저장은 하단 CTA에 있으므로 중복하지 않음
- 정보 표에 영업시간·브레이크·휴무·좌석·오픈일·정보 확인일 행
- 오시는 길은 회색 지도 박스 대신 주소 행 + 복사 + 길찾기 선택 시트(카카오맵·네이버 지도·티맵)
- 수정 제안은 정보 블록 아래 일급 행, 폐업 신고 포함
- 근처 라멘집 교차 링크 + BreadcrumbList·FAQPage(영업시간) JSON-LD. 메뉴 탭 없음
- 길찾기 → 선택 시트(캐치테이블 관례), 공유 → `navigator.share`, 폴백 클립보드 + 토스트, 주소 복사 → 클립보드 + 토스트
- (2026-09-01 보완) 텍스트 메타의 장르는 최대 2개 — 실측 상한: 지도사 1, 다이닝코드 2, 3개 이상인 서비스 없음

## 근거

2026-08-31 모바일 실측(Playwright 390×844 접근성 트리 + 공식 도움말): 네이버 플레이스·카카오맵·구글 지도·캐치테이블·다이닝코드·식신·당근 동네업체·타베로그·ramendb·망고플레이트(아카이브)·Yelp. 트립어드바이저는 403으로 미확인.

| 발견 | 서비스 | 라맵 판정 |
|---|---|---|
| 상세 헤더의 카테고리는 텍스트 한 줄(칩 없음) | 캐치 `논현 • 라멘`, 네이버 `일본식라면`, 다이닝코드 `합정 라멘, 시오라멘` | 장르 칩 → 상호 아래 텍스트 메타. 3축은 정보 표 행(타베로그·ramendb 표 형식) |
| 영업 상태 한 줄이 상호 직하단 | 네이버 `영업 종료 · 10:30에 영업 시작`, 카카오 `영업 마감 · 내일 11:00 오픈`, 구글·다이닝코드·식신·Yelp | 상호 아래 영업 줄(표기 방식은 [0007](0007-실시간-영업-상태-미표시.md)) |
| 상호 아래 액션 아이콘 행 | 네이버 `길찾기 공유 전화 알림받기`, 카카오 `로드뷰 공유 지도 즐겨찾기`, 구글 5개, Yelp 4개 | `지도 · 길찾기 · 공유` 3개 |
| 하단 고정 CTA = 보조 아이콘 + 주 버튼 | 캐치 `♥ 1,935`·`전화` + 주 버튼 | `[저장][완식]` 유지 |
| 사진 0장에 회색 placeholder 히어로를 쓰는 곳 없음 | 식신: 빈 상태 카드 + 등록 유도, 다이닝코드: 미니맵 | 0장이면 히어로 제거 |
| 영업시간 + 정보 확인일 표기 | 캐치 요일 리스트, 카카오 `업데이트 2026.08.31.`, Yelp `Updated 2 months ago`, 타베로그 편집 이력·주의문 | 정보 표에 영업시간·브레이크·휴무 + 정보 확인(`lastVerifiedAt`) |
| 오시는 길 = 주소 복사 + 역 거리 + 길찾기 선택 시트 | 캐치 `/info`, 카카오 `복사`, 구글 `주소 복사` | 주소 행 + 복사 + 길찾기 시트. 정적 지도 이미지는 09 약관으로 제외 |
| 수정 제안은 정보 블록 직하단 일급 행 | 9개 서비스 공통, 캐치 원문 = 라맵 문구 | 유지, 폐업 신고 포함 |
| 근처 매장 교차 링크 + Breadcrumb·FAQ JSON-LD | 타베로그 `周辺のお店`·FAQPage, ramendb `近くのお店`, Yelp `More like` | 근처 라멘집 3곳 + BreadcrumbList + FAQPage |
| 라멘 특화 표 항목 | ramendb·타베로그 `オープン日`, `席数`, 역 거리 | 오픈일·좌석 행 추가. 역 거리는 데이터 없음 |

카카오맵 길찾기 URL은 공식 URL 스킴(`map.kakao.com/link/to/{name},{lat},{lng}`).
