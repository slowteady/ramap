# 네이버 길찾기는 이름 검색을 유지한다

## 맥락

상세 길찾기 시트의 네이버 지도는 이름 검색(`map.naver.com/p/search/{상호}`)이라 동명 지점이 섞인다. 좌표 경로 URL로 바꾸는 안(지도·상세 리서치 D3)이 나왔다.

## 결정

- 네이버 지도는 `naverPlace` URL이 있으면 그것, 없으면 이름 검색 웹 URL을 유지한다
- 좌표가 있으면 검색 URL에 지도 중심(`c=` Web Mercator 좌표, 줌 15)을 매장 좌표로 붙여 동명 지점이 가까운 순으로 정렬되게 한다. 비공식 파라미터라 무시돼도 기존 이름 검색과 같다
- 카카오맵(공식 URL 스킴)·티맵(`tmap://route`)은 좌표가 있을 때만 보인다

## 근거

- 공식 스킴 `nmap://route/public?dlat=..&dlng=..&dname=..&appname=ramap.kr`은 앱 전용이고 공식 웹 폴백이 없다(NCloud URL Scheme 문서) → 앱 미설치 폰·PC에서 열리지 않는다. 도착지 정확도보다 도달성이 우선
- `c=` 파라미터 정렬 효과는 2026-10-27 실측
- 공공데이터 좌표를 외부로 넘기는 링크라 약관과 무관

## 버린 안

- `nmap://` 좌표 길찾기(백로그 P-21 기각)
