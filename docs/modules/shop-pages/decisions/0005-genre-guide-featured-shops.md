# 장르 가이드 범위와 대표 매장 순위

## 맥락

장르 가이드는 라이트층 교육 + SEO 보조 표면이고, 상세·필터에서 컨텍스트 링크로 들어온다. 초기 가이드는 비교 카드·다른 계열·하단 CTA·감수 문구가 있었고, 어떤 매장을 대표로 보일지 기준이 없었다.

## 결정

- 대상은 **국물 8 + taste 계보 2(이에케·지로계)**만. 자가제면·본토직영은 특성 태그라 가이드 대상이 아니다
- 구성: 뒤로가기 + 헤더 우측 "지도로 보기"(장르 필터 프리셋) / 계열명·한자 / 본문 2~3문단(경계 설명 포함) / 한눈에(맛·농도·기원) / 대표 {장르} 매장 최대 5 + 초과 시 "지도에서 N곳 모두 보기" / 참고(출처 링크 2~3)
- 비교 카드·다른 계열·하단 CTA·감수 문구는 삭제
- 본문은 출처(ramendb·新横浜ラーメン博物館 등) 근거로 재작성 + 하단 출처 표기. "초안·감수" 류 문구 금지. 톤은 에디토리얼
- 대표 매장 순위: 대표 국물 일치 > 운영자 확인 > 한줄소개 > 최근 확인일. 완식 집계가 쌓이면 집계 기준으로 전환한다(14번 문서: 랭킹은 완식 횟수)
- 파트너가 수동으로 붙이는 `대표` 플래그는 도입하지 않는다(2026-09-01 PO)

## 근거

- 17번 페이지명세 §6 (2026-09-01 개편)
- 2026-09-05 SEO 딥리서치: 장르 쿼리("니보시 라멘"·"라멘 종류")는 위키·커뮤니티 글뿐이고 매장과 연결된 디렉토리가 없다. "정의(위키가 이기는 부분) + 실매장 리스트(아무도 없는 부분)" 결합이 공백 공략의 핵심

## 버린 안

- 파트너 수동 `대표` 플래그 — 운영 부담, 기준 불투명
- 자가제면·본토직영 가이드 — 맛 계열이 아니라 특성
