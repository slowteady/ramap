# 유저 기여 라벨 "라멘집 등록"

## 맥락

새 라멘집을 알려 주는 진입점의 라벨을 정해야 했다. 처음엔 "제보하기"였다.

## 결정

| 위치 | 라벨 |
|---|---|
| 홈 버튼 | 라멘집 등록 |
| 시트 제목 | 새 라멘집 등록 |
| 시트 CTA | 등록하기 |
| 매장 상세의 수정 진입점 | "잘못된 정보가 있나요?" 일급 행 |
| 검색 결과 없음 화면 | 라멘집 등록하기 (등록 진입) |

## 근거

2026-08-31 재실측.

- 국내 1·2위 지도가 "신규 장소 등록"(카카오맵·네이버)으로 수렴. 음식점 앱은 "식당 등록 요청"(다이닝코드)·"식당추가 요청"(망고).
- **"제보"는 카카오·포카맵·워시맵·Coffice에서 폐업·수정·가격 갱신까지 뭉뚱그리는 말**이라 신규 등록 전용 라벨로 부적합.
- 상세 수정 진입점 "잘못된 정보가 있나요?" 일급 행은 캐치테이블 관례.
- 검색 결과 없음 아래 등록 진입은 카카오·네이버·망고 표준 위치.

## 버린 안

- "제보하기" (홈 버튼) — 신규 등록 전용 라벨로 부적합.
- "정보 수정 제안" (매장 상세) — "잘못된 정보가 있나요?"로 대체.
