# 액센트 라멘 레드 `#E23C36`

## 맥락

유채색 1색 예산([0001](0001-tokens-only-color-budget.md))의 그 1색이 라멘 레드다. 구조·검색·카드 벤치마크인 캐치테이블([0005](0005-visual-benchmarks.md))의 `plate` 브랜드색이 `#FF3D00`(hue 14°)으로 실측됐다. 구조를 빌린 벤치마크와 액센트까지 겹치면 정체성 리스크가 생긴다.

## 결정

- 라멘 레드 = **`#E23C36`** (hue 2°·채도 75%·명도 55%). 캐치테이블과 hue 12° 분리.
- 틴트 2단: `ramen-050 #FDF0F0`(7.5%, 활성 칩 배경), `ramen-100 #FADEDD`(17%, 선택 칩 배경).

## 근거

- 캐치테이블 `plate` 브랜드색 `#FF3D00` 실측(2026-08-31).
- 틴트 배경 비율은 캐치테이블 5% 공식을 참고.

## 버린 안

- 구 라멘 레드 `#E8442E` — 캐치테이블 브랜드색과 hue가 가까워 폐기.
