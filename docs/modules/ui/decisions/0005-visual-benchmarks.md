# 시각 벤치마크 배정

## 맥락

레퍼런스 없는 화면은 AI티가 된다([0004](0004-anti-ai-look-gate.md)). 화면 영역마다 기준 서비스를 정해야 "출처를 댈 수 있는" 레이아웃이 된다.

## 결정

- **방침:** 구조·동작은 한국 컨벤션 차용, 시각 언어는 미려 레퍼런스 기준.
- 배정:

| 영역 | 벤치마크 |
|---|---|
| 앱 구조·검색·카드 | 캐치테이블 (도메인 최근접) |
| 지도 화면 | 호갱노노 |
| 바텀 카드·상세 탭 | 오늘의집 |
| 토큰 규율 | 토스 |
