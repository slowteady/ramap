# 내비게이션은 코어 뷰와 최소 메뉴

## 맥락

라맵의 메뉴 구성과 홈 화면을 정해야 했다.

## 결정

- **홈 = 지도.** 홈 헤더는 로고 · 검색 · 프로필(마이)뿐이고, 필터 행에 [라멘집 등록] 버튼.
- **필터는 메뉴가 아니라 코어 뷰(지도) 안의 컨트롤.**
- **유저 기여는 메뉴가 아니라 버튼.**
- 장르 가이드는 메뉴에서 제외 — 필터·매장 페이지에서 컨텍스트 링크로만 진입.
- SEO 착지 페이지(매장 상세·지역×장르·계보·가이드)는 내비에 없음 — 검색이 입구.
- 랭킹·어워드 메뉴는 3막(데이터 축적 후)에 추가.

## 근거

2026-08-26 동종 니치 버티컬 맵 7개 서비스 내비 실측(라멘GPS·라멘투데이·포카맵·워시맵·다이브인포·BlackRoad·ramendb).

1. 살아있는 서비스의 내비 공식: **코어 뷰 1 + 참여 1 + 차별화 콘텐츠 1~2** (3~4개가 스윗스팟).
2. 필터는 코어 뷰 안의 컨트롤 (워시맵 칩, 다이브인포 필터바).
3. 유저 기여는 버튼으로 승격 (라멘투데이 "제보하기", 워시맵 "➕등록"). 라벨은 [0007](0007-유저-기여-라벨-라멘집-등록.md).
4. 메뉴 수와 데이터 깊이는 반비례 (BlackRoad 19개 메뉴 = 전부 얕음, 반면교사).
5. 지도형 서비스는 홈 = 지도 (라멘GPS·포카맵·워시맵 공통). 랭킹·이벤트류 메뉴는 데이터 축적 후의 것 (ramendb 6개 메뉴는 30년 도착점).

## 버린 안

- 메뉴 다수 구성(BlackRoad형) — 얕은 메뉴만 늘어난다.
