# 토큰 외 값 금지와 색 예산

## 맥락

깔끔한 화면의 8할은 토큰 규율에서 나온다. 기본값으로 만든 화면은 "어느 서비스 것인지 가릴 수 없는" 무국적 화면이 된다.

## 결정

- **토큰 외 값 사용 금지가 원칙 그 자체**다. 값의 유일한 출처는 `src/app/globals.css`의 `@theme`.
- **색 예산:** 흰 배경 + 그레이 단계 + **유채색 정확히 1색**(액센트) + 시맨틱 그린(영업 정보). 상태 표현은 새 색이 아니라 반전·보더·명도 차로만.
- **색이 있는 곳 = 누를 수 있는 곳.**
- 텍스트는 근흑(`#1A1B1F` 계열), 순흑 금지.
- 폰트는 Pretendard, 스케일 5~6단 고정, **위계는 크기보다 굵기(400/600/700)와 그레이 단계로.**
- 카드 구획은 그림자·테두리 대신 여백으로.

## 근거

국내 상위 서비스 실측에서 공통 공식 확인 (2026-08-26, 멀티에이전트 딥다이브 — BP 6에이전트 + 심미 레퍼런스 2에이전트, 국내 8개·해외 7개 실서비스 관찰).

| 규칙 | 출처 |
|---|---|
| 토큰 외 값 금지 | 토스 TDS |
| 유채색 1색, 색 = 누를 수 있는 곳 | 컬리 |
| 위계는 굵기·그레이 단계 | 당근 SEED |
| 여백 구획 | 29CM |
| 근흑 텍스트 | 무신사 |
| Pretendard | 업계 표준 |
