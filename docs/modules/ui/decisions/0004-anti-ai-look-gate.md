# AI티 방지 게이트

## 맥락

AI티 = 레퍼런스 없이 기본값으로 생성된 흔적. 무국적 화면은 곧 슬롭이다.

## 결정

- 빌드 시 **모든 화면이 게이트(금지 시그니처 + 금지 구조 패턴)를 통과**해야 한다. 체크리스트는 [design.md](../design.md#ai티-방지-게이트).
- **대원칙:** 모든 레이아웃 패턴은 실측 레퍼런스 출처를 댈 수 있어야 한다. 출처를 못 대면 반사신경 = 제거 대상.
- **완성 판정:** "이 화면이 어느 서비스 것인지 가릴 수 있는가" — 가려지면 실패.
- shadcn 컴포넌트는 토큰 테마로 덮기 전 사용 금지. 테마 토큰 정의가 이 게이트의 기술적 실행이다.
- 게이트는 `ramap-ui` 스킬로 모든 UI 작업 세션에 자동 적용한다.

## 근거

- 방어 = 실측 기반 토큰([0001](0001-tokens-only-color-budget.md)) + 금지 시그니처.
- 대체 패턴의 실측 출처: 3열 특징 그리드 대신 에디토리얼 인라인(Culture Trip·Hitosara), 다크 헤더 인라인 통계(Hitosara 이원 톤), 답변 노출형 FAQ(Yelp·Tripadvisor).
- 목업 감사(2026-08-26)에서 게이트 위반을 실제로 잡았다: 장르 가이드 "특징 3칸 그리드" → 에디토리얼 프로즈+인라인 강조로 교체, 계보 랜딩 레터스페이싱 배지 → 한자 병기 헤드라인으로 교체, SEO 리스트 FAQ 아코디언 박스 → 답변 노출형 Q&A(콘텐츠가 HTML에 노출돼 SEO에도 유리). 목업 v3에 소급 적용 완료.
