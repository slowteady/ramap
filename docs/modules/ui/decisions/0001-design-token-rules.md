# 디자인 토큰 규율 — 토큰 외 값 금지, 색 예산, 라멘 레드, radius 4값

## 맥락

깔끔한 화면의 8할은 토큰 규율에서 나온다. 기본값으로 만든 화면은 "어느 서비스 것인지 가릴 수 없는" 무국적 화면이 된다. radius를 자유롭게 쓰면 `rounded-2xl` 남발 같은 AI티가 생기고, 컨트롤(누르는 것)과 콘텐츠(보는 것)가 같은 모양이면 구분이 흐려진다.

## 결정

### 토큰과 색 예산

- **토큰 외 값 사용 금지가 원칙 그 자체**다. 값의 유일한 출처는 `src/app/globals.css`의 `@theme`.
- **색 예산:** 흰 배경 + 그레이 단계 + **유채색 정확히 1색**(액센트) + 시맨틱 그린(영업 정보). 상태 표현은 새 색이 아니라 반전·보더·명도 차로만.
- **색이 있는 곳 = 누를 수 있는 곳.**
- 텍스트는 근흑(`#1A1B1F` 계열), 순흑 금지.
- 폰트는 Pretendard, 스케일 5~6단 고정, **위계는 크기보다 굵기(400/600/700)와 그레이 단계로.**
- 카드 구획은 그림자·테두리 대신 여백으로.

### 액센트 라멘 레드

- 라멘 레드 = **`#E23C36`** (hue 2°·채도 75%·명도 55%). 구조·검색·카드 벤치마크인 캐치테이블의 브랜드색과 hue 12° 분리.
- 틴트 2단: `ramen-050 #FDF0F0`(7.5%, 활성 칩 배경), `ramen-100 #FADEDD`(17%, 선택 칩 배경).

### radius 4값과 형태 문법

| 용도 | 값 | 토큰 |
|---|---|---|
| 카드(콘텐츠·사진 카드) | 8px / 12px | `rounded-card`, `rounded-card-lg` |
| 컨트롤(칩·버튼) | 완전 pill | `rounded-pill` |
| 태그 배지(장르·편의) | 5px | `rounded-chip` |

그 외 값은 금지. 형태 문법: 콘텐츠는 각지게, 컨트롤은 pill.

## 근거

국내 상위 서비스 실측에서 공통 공식 확인 (2026-08-26, 멀티에이전트 딥다이브 — BP 6에이전트 + 심미 레퍼런스 2에이전트, 국내 8개·해외 7개 실서비스 관찰).

| 규칙 | 출처 |
|---|---|
| 토큰 외 값 금지 | 토스 TDS |
| 유채색 1색, 색 = 누를 수 있는 곳 | 컬리 |
| 위계는 굵기·그레이 단계 | 당근 SEED |
| 여백 구획 | 29CM |
| 근흑 텍스트 | 무신사 |
| Pretendard | 업계 표준 |
| radius 3~4종 고정, 콘텐츠 각짐 / 컨트롤 pill | 무신사·캐치테이블 |

- 캐치테이블 `plate` 브랜드색 `#FF3D00`(hue 14°) 실측(2026-08-31). 구조를 빌린 벤치마크와 액센트까지 겹치면 정체성 리스크가 생긴다. 틴트 배경 비율은 캐치테이블 5% 공식을 참고.
- 태그 배지 5px는 빌드 중 확정된 4번째 값(2026-08-31) — 컨트롤(pill)과 콘텐츠 태그(각짐)의 형태 문법 분리, 무신사식.

## 버린 안

- shadcn 기본 팔레트(slate/zinc) 그대로 사용 — AI티의 대표 시그니처([AI티 방지 게이트](../design.md#ai티-방지-게이트)).
- 구 라멘 레드 `#E8442E` — 캐치테이블 브랜드색과 hue가 가까워 폐기.
- radius 3값 체계(카드·pill만) — 장르·편의 태그가 pill이면 누를 수 있는 칩처럼 읽힌다.
