# 신규 오픈 전용 페이지 폐기

## 맥락

라우트 맵에 신규 오픈 전용 페이지 `/new`와 마이 메뉴 항목이 있었다.

## 결정

- `/new` 라우트와 마이 메뉴의 신규 오픈 항목을 삭제한다.
- 신규 오픈은 전용 페이지·메뉴 없이 지도 NEW 마커·목록 NEW 칩·홈 "새로 오픈" 필터 칩·매장 카드·상세의 NEW 칩으로 흡수한다. 표시 규칙은 [map design](../../map/design.md).

## 근거

- 네이버 '새로오픈'·배민 '신규'·Google 'Recently opened'·타베로그·ramendb 전부 홈/검색 결과 안의 **배지·필터**로 노출한다(실측).
- 라맵 시드 규모(월 1~2회 인허가 diff)에선 전용 페이지가 대부분 빈 상태.

## 버린 안

- 신규 오픈 전용 페이지 `/new` + 마이 메뉴 항목.
