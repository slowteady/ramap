# 2뎁스 헤더는 뒤로가기와 보조 액션 1개

## 맥락

홈 외 페이지(가이드·지역·계보·마이·약관·상세)의 헤더 형태를 정해야 했다. 2026-09-01 PO 검수에서 결정.

## 결정

- 2뎁스 페이지 헤더 = **뒤로가기 + 우측 보조 액션 1개.**
- 로고·홈 링크 헤더 금지.
- 뒤로가기는 진입 이력이 있으면 back, 없으면(검색 착지처럼 첫 페이지) 홈으로.

## 근거

- 2026-09-01 PO 검수.
- 검색 착지 사용자는 이력 없이 들어오므로 back만 있으면 막다른 길이 된다 — 홈 폴백으로 해결.

## 버린 안

- 로고·홈 링크가 있는 헤더.
