# radius 4값과 형태 문법

## 맥락

radius를 자유롭게 쓰면 `rounded-2xl` 남발 같은 AI티가 생긴다. 컨트롤(누르는 것)과 콘텐츠(보는 것)가 같은 모양이면 구분이 흐려진다.

## 결정

radius는 아래 4값만 쓴다. 그 외 금지.

| 용도 | 값 | 토큰 |
|---|---|---|
| 카드(콘텐츠·사진 카드) | 8px / 12px | `rounded-card`, `rounded-card-lg` |
| 컨트롤(칩·버튼) | 완전 pill | `rounded-pill` |
| 태그 배지(장르·편의) | 5px | `rounded-chip` |

형태 문법: 콘텐츠는 각지게, 컨트롤은 pill.

## 근거

- radius 3~4종 고정, 콘텐츠 4~12px 각짐 / 컨트롤 pill 분리는 무신사·캐치테이블 실측(2026-08-26).
- 태그 배지 5px는 빌드 중 확정된 4번째 값(2026-08-31) — 컨트롤(pill)과 콘텐츠 태그(각짐)의 형태 문법 분리, 무신사식.

## 버린 안

- 3값 체계(카드·pill만) — 장르·편의 태그가 pill이면 누를 수 있는 칩처럼 읽힌다.
