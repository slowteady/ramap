# 모바일웹 퍼스트

## 맥락

라맵 화면을 어떤 플랫폼 기준으로 설계할지 정해야 했다.

## 결정

- **모바일웹 퍼스트.** 앱은 만들지 않는다.
- 데스크톱은 무붕괴 수준만 보장한다: 콘텐츠 페이지는 중앙 단일 컬럼.
- 데스크톱 스플릿 뷰(좌 리스트 + 우 지도)는 표준이지만 투자 후순위 — 모바일 트래픽 비중을 확인한 뒤.

## 근거

1. 사용 맥락: 이동 중 탐색.
2. 구글 모바일 퍼스트 인덱싱 — SEO 엔진 전략상 랭킹 판정 자체가 모바일 버전.
3. 벤치마크 전부 모바일 우선.

## 버린 안

- 데스크톱 스플릿 뷰 선투자 — 트래픽 비중 근거 없음.
- 데스크톱에 가로 스크롤 칩 이식 — 안티패턴.
