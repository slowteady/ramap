# ui 기획서

휴대폰 브라우저 사용자가 한 손으로 라멘집을 찾고 보며, 데스크톱에서도 깨지지 않는 화면을 쓴다. 이 문서는 디자인 시스템·정보 구조·공통 UI 규율이 지켜야 할 요구를 담는다.
디자인 토큰·정보 구조·공통 헤더·화면 품질 게이트의 현재 상태는 설계서에 있다. 설계는 [design.md](design.md), 바뀐 기록은 이 파일의 GitHub 커밋 기록에 있다.

## 1. 왜 만드나

라맵의 사용 맥락은 이동 중 탐색이라 모바일웹이 기준 화면이다. 구글도 모바일 버전으로 랭킹을 판정한다(모바일 퍼스트 인덱싱).

발견 서비스에서 지도 결함은 치명 결함이다(망고플레이트 사망 원인). 그래서 지도가 실패해도 화면을 쓸 수 있어야 한다.

화면에 기본값 티(AI티)가 없어야 사용자가 "라맵 화면"으로 알아보고 믿는다.

되면 달라지는 것: 휴대폰 브라우저에서 한 손으로 라멘집을 찾고, 어느 화면에서도 길을 잃지 않는다.

## 2. 범위

### 이번에 하는 것

- 디자인 토큰(색·radius·타이포·간격·폰트)과 사용 규율
- 정보 구조: 내비게이션·라우트 맵·헤더 형태
- 공통 라벨(유저 기여·수정 진입)
- 화면 품질 게이트(AI티 방지)와 안티패턴 목록
- UI 코드 작성 규율(`ramap-ui` 스킬)

### 하지 않는 것

| 하지 않는 것 | 이유 또는 맡은 곳 |
|---|---|
| 데스크톱 스플릿 뷰(좌 리스트 + 우 지도) | 표준 패턴이지만 선투자할 트래픽 근거가 없다. 모바일 트래픽 비중을 확인한 뒤 다시 본다 |
| 랭킹·어워드 메뉴 | 3막에서 데이터가 쌓인 뒤 다시 본다 |
| 네이티브 앱 | 만들지 않는다(앱 없음). 모바일웹이 기준 화면이다 |
| 메뉴 다수 구성 | 기각했다. 얕은 메뉴만 늘어난다(BlackRoad 19개 메뉴 반면교사) |
| 2뎁스 헤더의 로고·홈 링크 | 기각했다. 뒤로가기의 홈 폴백으로 충분하다 |
| 신규 등록 라벨 "제보하기" | 기각했다. 수정·폐업과 구분되지 않는다 |

## 3. 요구

마지막 번호: REQ-07

| ID | 요구 | 종류 | 요청 | 단계 | 확인 방법 |
|---|---|---|---|---|---|
| REQ-01 | 이동 중 탐색: 휴대폰 브라우저에서 한 손으로 라멘집을 찾고 본다 | 기능 | 없음 | 현재 | 없음 |
| REQ-02 | 데스크톱 무붕괴: 데스크톱에서도 화면이 깨지지 않는다 | 기능 | 없음 | 현재 | 없음 |
| REQ-03 | 길 잃지 않기: 메뉴가 적고, 어느 2뎁스 페이지에서든 뒤로가기 한 번으로 돌아간다. 이력 없이 검색으로 착지해도 홈으로 나갈 수 있다 | 기능 | 없음 | 현재 | 없음 |
| REQ-04 | 누를 곳이 보임: 누를 수 있는 곳이 화면에서 구분돼 보인다 | 기능 | 없음 | 현재 | 없음 |
| REQ-05 | 신뢰할 수 있는 화면: 기본값 티(AI티)가 없고 "라맵 화면"으로 식별된다 | 비기능 | 없음 | 현재 | 화면 품질 게이트(AI티 방지) → [AI티 방지 게이트](design.md#ai티-방지-게이트) |
| REQ-06 | 터치 가능: 누를 곳이 터치하기 충분히 크고, 상태를 색에만 의존하지 않는다(접근성) | 비기능 | 없음 | 현재 | 없음 |
| REQ-07 | 지도 실패에도 쓸 수 있음: 지도를 쓰는 화면은 지도 로드에 실패해도 라멘집을 볼 수 있다 | 기능 | 없음 | 현재 | 없음 |

## 4. 규칙

| ID | 상황 | 규칙 | 예외 |
|---|---|---|---|
| P-01 | 기준 화면을 정할 때 | 모바일웹이 기준 화면이다 | 없음 |
| P-02 | 데스크톱에서 콘텐츠 페이지를 보여 줄 때 | 콘텐츠 페이지는 중앙 단일 컬럼이다 | 없음 |
| P-03 | 누를 수 있는 곳과 상태를 표시할 때 | 색이 있는 곳 = 누를 수 있는 곳이다. 상태는 색이 아니라 반전·보더·명도로 구분한다 | 없음 |
| P-04 | 터치 타깃을 만들 때 | 터치 타깃은 44px 이상이다. 상태를 색에만 의존하지 않고 형태·크기를 병행한다 | 없음 |
| P-05 | 지도 로드에 실패했을 때 | 리스트 + "지도를 불러오지 못했어요" 배너로 대체한다 | 없음 |
| P-06 | 스타일 값을 쓸 때 | 토큰 외 값은 쓰지 않는다. Tailwind 임의값(`w-[13px]`)을 쓰지 않고 `@theme` 토큰 유틸만 쓰며 CSS 파일을 추가하지 않는다 → [결정](decisions/0001-design-token-rules.md) | 없음 |
| P-07 | 색을 고를 때 | 유채색은 라멘 레드 1색 + 시맨틱 그린뿐이다 → [결정](decisions/0001-design-token-rules.md) | 없음 |
| P-08 | 테마를 정할 때 | 라이트 모드 고정이고 `.dark` 블록은 금지다. 카카오맵에 다크 타일이 없어 지도가 주인공인 화면에서 UI만 어둡게 할 수 없다 | 없음 |
| P-09 | 로고를 넣을 때 | 타사 로고는 쓰지 않는다 → [공통 결정](../../decisions/0002-third-party-data-boundary.md) | 없음 |
| P-10 | 아이콘을 넣을 때 | 이모지 아이콘은 쓰지 않고 lucide 단일 세트만 쓴다 | 없음 |
