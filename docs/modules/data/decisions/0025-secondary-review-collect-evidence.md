# 갱신 라운드 2차 검수는 collect-evidence로 고정한다

## 맥락

대조 결과(신규 후보·폐업 전이)는 웹 근거로 다시 확인해야 한다. 사람·루틴 누가 해도 같은 결과가 나와야 한다.

## 결정

- 수집 수단은 `npm run collect-evidence` 하나로 고정한다: 항목당 Daum 통합검색 2회(상호+법정동, 상호+도로명)의 장소 카드 영업 표기와 후기 조각, 라멘 미니갤 최근 21일 키워드 검색 7종 + 사건성 제목 글 본문 최대 30건, 직전 라운드 판정, 같은 건물 영업 인허가.
- 판정 범주와 산출 형식을 고정한다([data 설계](../design.md#2차-검수)).
- 검색 원문은 플랫폼 데이터라 레포에 커밋하지 않는다(레포 밖 출력).
- 검수 소스에 접속하지 못하면(종료코드 2) 판정 없이 `[미검수]`로 남긴다.

## 근거

- 일반 웹 검색(WebSearch)은 한국 동네 매장을 거의 잡지 못한다.
- 커뮤니티(라멘 미니갤)가 오픈·폐업·이전 소식이 가장 빠르다.

## 열린 문제

Daum 검색 수집은 카카오 서비스 페이지 수집이라 "네이버·카카오 크롤링 금지"([공통 결정](../../../decisions/0002-third-party-data-boundary.md))와 충돌 소지가 있다. 공식 API(Google Places `businessStatus`) 전환을 검토 중이다.
