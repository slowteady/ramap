# 아부라소바는 마제소바와 별도 형태로 둔다

## 맥락

일본에서는 아부라소바를 마제소바와 같은 계열(국물 없는 면)로 묶는다. 조사 결과에는 아부라소바·아부라라멘이 세부값으로 흩어져 있었다.

## 결정

- 형태 값에 **아부라소바**를 추가한다.
- 세부값 `아부라소바`·`아부라라멘`·`아부라소바·파이탄`은 형태로 올리고 세부값에서는 뺀다(`scripts/lib/enrich.ts` `DETAIL_TO_FORM`). 메뉴명에 "아부라소바/아부라라멘/아부라멘"이 있으면 형태에 더한다(`promoteFromMenus`).

## 근거

- PO 결정: 지도 필터에서 아부라소바를 따로 찾게 한다.
- 세부값에 남겨 두면 상세 화면에 형태와 중복 노출된다.

## 버린 안

- 마제소바에 통합(일본식 분류): 사용자가 필터로 따로 찾지 못한다.
