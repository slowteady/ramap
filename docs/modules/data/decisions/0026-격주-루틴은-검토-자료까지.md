# 격주 갱신 루틴은 검토 자료까지만 만든다

## 맥락

LOCALDATA 대조·2차 검수를 매번 사람이 시작하면 갱신이 밀린다. 반대로 폐업·신규 반영을 자동으로 하면 오판이 그대로 공개된다.

## 결정

- 클라우드 루틴(claude.ai/code Routines)이 매월 1일·15일에 대조와 2차 검수를 돌려 **검토 자료만** `data/review/<날짜>/`에 커밋하고 `chore/data-refresh-<날짜>` 브랜치 PR로 올린다.
- `candidates.tsv`·enrichment 반영과 재생성은 사람이 [data 설계](../design.md#갱신-라운드) 절차로 한다. main 머지는 사람이 한다([공통 결정](../../../decisions/0005-이슈-기반-작업.md)).

## 근거

- 폐업·신규 판정에는 사람 확인이 필요하다([0024](0024-폐업은-직접-증거로만-확정.md)).
