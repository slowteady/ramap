# 검증상태 "운영자확인"은 사람이 검수했을 때만

## 맥락

조사 기반 자동 신뢰도와 사람의 검수 여부를 한 칸에 섞을지, 두 축으로 나눌지 논의했다.

## 결정

- `검증상태`=`운영자확인`은 **사람이 실제로 검수(제보 처리·현장 확인)했을 때만** 올린다. 파이프라인은 이 값을 건드리지 않는다.
- 조사 기반 자동 신뢰도는 `태깅확신도`(`확정`/`추정`)가 맡는다. 화면의 "확인됨" 칩은 태깅확신도로 표시한다.
- 태깅확신도 `확정` = 조사 항목이 매칭되고, 판정 표시(라멘집 아님·실존 미확인)가 없고, 스프(대표값 포함)와 형태가 채워진 매장(`scripts/lib/grade.ts`). 나머지는 `추정`.

## 근거

- PO 확정: 자동 산정 축 이원화 논의 끝에 태깅확신도로 통일.
- 업종 분류·상호 키워드로만 걸러진 매장은 장르를 실제로 확인한 것이 아니다.
