# 인스타 링크는 지점 계정 → 브랜드 공식 계정 → 비움

## 맥락

인스타 링크 오염이 확인됐다: 산쪼메 구의점 계정이 21곳에 번짐, 계단라멘 마곡점 계정이 목동·일산에, 멘야카오리 장안점 계정이 3지점에, 코이라멘 지점 계정이 체인 계정에 가려짐.

## 결정

- 우선순위: **그 지점 자체 계정 → 없으면 같은 체인의 브랜드 공식 계정 → 근거 없으면 비움.** 화면에 지점·브랜드 구분 표기는 하지 않는다.
- 근거는 검색엔진의 인스타 **프로필 결과**(URL `instagram.com/<계정>` 한 단계, 제목·소개글이 그 매장을 지칭)만. 게시물·위치 태그·블로그 속 @언급은 근거가 아니다. 인스타그램 직접 조회·스크래핑 금지([공통 결정](../../../decisions/0002-타사-플랫폼-데이터-경계.md)).
- 확실하지 않은 것은 반영하지 않고 다음 라운드에서 다시 본다.
- 검색 수단은 Tavily 검색(`include_domains: instagram.com`)을 쓴다.
- 규칙 전문은 [data-integrity 스킬](../../../../.claude/skills/data-integrity/SKILL.md) "인스타" 절.

## 근거

- PO 확정(2026-10-27). 틀린 링크가 빈 링크보다 나쁘다.
- 블로거·사진 출처 계정을 매장 계정으로 오인하는 사례가 게시물·@언급 근거에서 나왔다.
- 기본 웹 검색(WebSearch)은 한국 인스타 프로필이 거의 색인돼 있지 않다(2026-10-27 실측: 55곳 중 6곳, 공식 계정명 직접 검색도 0건) → [조사](../research/2026-10-27-인스타-링크-1차-검수.md)

## 버린 안

- 같은 이름 그룹의 브랜드 계정 자동 대입: 다른 업장(라라멘 49-13·마시타라멘 세종점)에 브랜드 계정이 붙었다.
