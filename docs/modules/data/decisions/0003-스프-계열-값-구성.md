# 스프 계열 값 구성 — 탄탄멘·돈코츠쇼유 유지, 소수 값은 기타로

## 맥락

ramendb 스프 값 12개를 한국 매장 규모에 맞게 줄여야 한다.

## 결정

| 값 | 처리 | 근거 |
|---|---|---|
| 탄탄멘 | 스프 계열에 둔다 | ramendb 동일 배치 + 한국에 탄탄멘 전문점 실존. 30년 설계를 이길 근거 없음 |
| 돈코츠쇼유 | 독립 값으로 둔다 | 이에케의 베이스 스프라 계보 축과의 정합에 필수(이에케 = 돈코츠쇼유 + 계보 태그) |
| 시오돈코츠·카레 | 화면에 노출하지 않고 `기타`로 흡수. 내부 세부값(`스프_세부`)으로만 보관 | 한국 매장 수가 필터 실효성(5곳) 미달 추정 |

세부값이 5곳을 넘으면 정식 값으로 승격한다(→ [0004](0004-니보시-교카이-병립.md), [0005](0005-토마토-스프-승격.md)).

## 근거
