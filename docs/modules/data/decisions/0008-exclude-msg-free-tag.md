# 무화조(無化調) 태그는 두지 않는다

## 맥락

ramendb 계보·특성 태그에는 무화조(화학조미료 무첨가)가 있다.

## 결정

계보·특성 태그에서 무화조를 뺀다. 수요가 확인되면 추가한다.

## 근거

- 화학조미료 담론은 일본 특유의 축이다. 한국 커뮤니티에서 매장 선택 기준으로 쓰는 관찰이 없다.
