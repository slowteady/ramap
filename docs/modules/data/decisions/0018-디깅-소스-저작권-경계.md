# 디깅 소스는 발굴 단서로만 쓴다

## 맥락

미디어 목록·갤러리 정리글은 매장 발굴에 유용하지만 남의 글이다.

## 결정

- 디깅 글은 가게 **존재를 아는 단서**로만 쓴다.
- 글의 서술·평가 문장을 복사하지 않는다.
- 특정 목록의 선정·배열을 통째로 옮기지 않는다.
- 태깅은 글을 참고한 운영자의 자체 판단으로 넣는다. 참고 출처는 내부 근거(`sourceNote`·`정보출처`)로만 남기고 게재하지 않는다.

## 근거

- 상호·주소·존재 같은 사실은 저작권 보호 대상이 아니다. 목록의 선정·배열은 편집저작물, 서술은 저작물이다.
