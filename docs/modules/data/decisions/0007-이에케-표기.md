# 계보 표기는 "이에케"

## 맥락

家系 라멘의 한국어 표기가 "이에케이"·"이에케"·"이에게"로 갈린다.

## 결정

- UI 라벨·본문·SEO 타이틀은 전부 **이에케**. 시트 값도 `이에케`.
- URL 슬러그는 로마자 `iekei`(한국어 검색과 무관).

## 근거

- 2026-08-26 구글 결과 수: "이에케" 라멘 약 50,400건 vs "이에케이" 약 4,240건 vs "이에게" 약 1,820건.
- 갤러리 최근 글: "이에케" 표기 다수("국내 이에케 추천좀", "지로이에케"), "이에케이" 0건.

## 버린 안

- 이에케이(일본어 원음에 가까운 표기): 실사용 빈도가 1/10 이하.
