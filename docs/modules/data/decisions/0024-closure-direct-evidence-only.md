# 폐업은 직접 증거로만 확정하고, 확정된 것만 공개한다

## 맥락

폐업이 아닌 가게를 "폐업"으로 공개하면 영업 방해·명예훼손 소지가 있다. 2026-10 라운드에서 "검색 흔적 없음"만으로 폐업 처리한 매장 중 4곳 이상이 영업 중이었다(모리라멘&돈카츠·호랭이라멘·993라멘 등).

## 결정

- 폐업은 **직접 증거**로만 확정한다. 흔적이 없다는 사실은 증거가 아니다. LOCALDATA 폐업 신고·유저 폐업 제보는 검증을 시작하는 트리거일 뿐이다.
- 판정(영업 중·이전·확정 폐업·미확정)과 증거 기준은 [closure-verification 스킬](../../../../.claude/skills/closure-verification/SKILL.md)이 원천이다.
- 확정 폐업·이전만 `data/closure-verification.json` 장부에 근거와 함께 기록한다.
- 공개는 코드로 강제한다: 장부에 있는 `상태=폐업` 매장만 `[폐업]`/`[이전]` 페이지가 열리고, 장부에 없는 폐업 매장은 페이지 404·사이트맵 제외(`closurePublicState`).
