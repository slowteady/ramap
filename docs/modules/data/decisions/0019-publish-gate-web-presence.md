# 게재 게이트 — 웹 실존 신호가 있는 매장만 게재한다

## 맥락

공공데이터 후보에는 이미 문 닫았거나 라멘집이 아닌 업소가 섞여 있다. 네이버·카카오에서 검색하면 나오는 수준의 실존성을 담보해야 한다.

## 결정

`enrich-candidates`가 후보마다 게재·보류·제외를 판정한다.

| 판정 | 조건 |
|---|---|
| 제외 | 조사 항목이 폐업(`closed`) 또는 `라멘집 아님` |
| 보류 | `실존 미확인`·`unverified`, 실존 신호 없음, 좌표 없음, 근거에 "주소 상이"(위치 불확실) |
| 게재 | 실존 신호 하나 이상: 조사된 스프·형태·계보, 인스타, 네이버플레이스, 또는 매칭된 디시·미디어 출처 |

## 근거

- PO 확정: 웹 실존 신호가 있는 매장만 시드에 넣는다. 확실하지 않으면 보류한다.
- 재검증에서 흔적을 다시 못 찾은 매장은 다른 신호가 있어도 보류로 내린다(옛 조사 신호가 남아 있어도 현재 실존을 보장하지 않는다).
