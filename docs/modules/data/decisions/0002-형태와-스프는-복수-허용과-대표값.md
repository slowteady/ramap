# 형태와 스프는 매장당 복수 허용, 대표 1개 지정

## 맥락

ramendb는 형태·스프를 단일 값(스프는 메뉴 단위)으로 둔다. 한국은 한 매장이 돈코츠·츠케멘·마제소바를 함께 파는 겸업이 흔하다.

## 결정

- 형태(`형태`)와 스프(`스프`)는 복수 값을 허용하고, 각각 대표값 1개(`형태_대표`·`스프_대표`)를 필수로 지정한다. 대표값은 반드시 복수 목록에 들어 있어야 한다.
- 대표값이 필터·정렬·SEO의 기준값이다.
- 히야시츄카는 형태에서 뺀다. 한국에선 매장 정체성이 아니라 여름 한정 메뉴라 편의 태그 `한정메뉴`로 흡수한다.

## 근거

- 단일 값을 강제하면 한국 겸업 매장에서 즉시 깨진다([0001](0001-택소노미-3축-직교와-한국화-원칙.md) 원칙 3).
- 히야시츄카 전문점은 한국에 사실상 없어 필터 실효성(5곳)을 못 넘는다.

## 버린 안

- ramendb식 단일 값: 겸업 구조와 충돌.
