# 같은 매장의 조사가 여럿이면 최신 조사일이 이긴다

## 맥락

한 매장에 여러 시기의 조사 항목이 쌓인다. 판정 표시·영업시간·인스타를 어느 조사에서 가져올지 정해야 했다. 파일 나열(알파벳) 순서로 고르던 때, 알파벳순 뒤의 9월 조사가 10월 판정과 10월 장소 카드 영업시간을 가렸다.

## 결정

- 조사일 = enrichment 파일명의 날짜(`YYYY-MM` 또는 `YYYY-MM-DD`). 월 단위 파일은 그 달 `00`일로 본다(`observedAt`).
- 최신 조사일 우선: 판정 표시(`라멘집 아님`·`실존 미확인`), 영업시간·브레이크·휴무·좌석·메뉴·네이버플레이스·오픈일, 인스타.
- 인스타 `""`(빈 문자열)은 "확인된 계정 없음"으로 이전 값과 체인 승계를 끊는다.
- 장르(스프·형태·세부)는 합집합, 동네라벨은 큐레이션 값이라 기존 순서를 유지한다.

## 근거

- 판정 표시를 합집합으로 두면 재검증으로 뒤집힌 보류가 되살아난다.
- 2026-10-27 결함 수정 결과: 칸키라멘 동작구청점·미친라멘(3회 재검증 실존 미확인) 보류, 멘야미코 게재. 메뉴 정보 없는 매장의 옛 영업시간이 최신 조사를 가리던 결함도 해소.
