# 택소노미 값 구성 — 형태·스프·계보 표기·특성·편의 태그

## 맥락

[0001](0001-taxonomy-axes-localization.md)의 한국화 원칙(필터 실효성 5곳·커뮤니티 용어·겸업 구조)을 값 하나하나에 적용한 결정들이다. 처음에는 값마다 따로 기록했다가 한 문서로 합쳤다. 절마다 정한 날짜를 적는다.

## 1. 형태·스프는 매장당 복수, 대표 1개 (2026-08-25)

**결정**

- 형태(`형태`)와 스프(`스프`)는 복수 값을 허용하고, 각각 대표값 1개(`형태_대표`·`스프_대표`)를 필수로 지정한다. 대표값은 반드시 복수 목록에 들어 있어야 한다.
- 대표값이 필터·정렬·SEO의 기준값이다.
- 히야시츄카는 형태에서 뺀다. 한국에선 매장 정체성이 아니라 여름 한정 메뉴라 편의 태그 `한정메뉴`로 흡수한다.

**근거**

- ramendb는 형태·스프를 단일 값(스프는 메뉴 단위)으로 두지만, 한국은 한 매장이 돈코츠·츠케멘·마제소바를 함께 파는 겸업이 흔해 단일 값을 강제하면 즉시 깨진다.
- 히야시츄카 전문점은 한국에 사실상 없어 필터 실효성(5곳)을 못 넘는다.

**버린 안:** ramendb식 단일 값 — 겸업 구조와 충돌.

## 2. 스프 계열 값 — 탄탄멘·돈코츠쇼유 유지, 소수 값은 기타로 (2026-08-25)

**결정** — ramendb 스프 값 12개를 한국 매장 규모에 맞게 줄인다.

| 값 | 처리 | 근거 |
|---|---|---|
| 탄탄멘 | 스프 계열에 둔다 | ramendb 동일 배치 + 한국에 탄탄멘 전문점 실존. 30년 설계를 이길 근거 없음 |
| 돈코츠쇼유 | 독립 값으로 둔다 | 이에케의 베이스 스프라 계보 축과의 정합에 필수(이에케 = 돈코츠쇼유 + 계보 태그) |
| 시오돈코츠·카레 | 화면에 노출하지 않고 `기타`로 흡수. 내부 세부값(`스프_세부`)으로만 보관 | 한국 매장 수가 필터 실효성(5곳) 미달 추정 |

세부값이 5곳을 넘으면 정식 값으로 승격한다(3·4절).

**근거:** 필터 실효성 원칙. 세부값 설계 덕분에 스키마 변경 없이 승격할 수 있다.

## 3. 니보시와 교카이를 각각 스프 값으로 (2026-09-02)

**결정**

- 스프 값 이름은 "어패계"가 아니라 **니보시**를 쓴다.
- 니보시(멸치·정어리 다시)와 **교카이**(가다랑어·어패 전반, 돈코츠교카이 포함)를 각각 스프 값으로 둔다. 니보시는 교카이의 부분집합이지만 전문점 문화가 뚜렷해 따로 유지한다.
- 조사 세부값 `교카이`는 파이프라인이 스프 값으로 승격한다(`scripts/lib/enrich.ts` `SOUP_PROMOTIONS`).

**근거**

- 2026-08-26 갤러리 실측: "니보시"는 합성어(농후니보시·니보시파이탄)까지 통용, "어패계" 용례는 사실상 0.
- 2026-08-26 구글: "니보시 라멘 서울" 약 28,600건 vs "어패계 라멘" 약 49건(약 580:1). 서울 니보시 매장 실재(멘야코노하·마이니치라멘 니보시·나가오 중화소바·라멘다이야·킨카) → [조사](../research/2026-08-26-ramendb-structure-korean-terms.md)
- 2026-09-02 시드 실측: 교카이 취급 14곳, 니보시 전문점 실존 — "5곳 이상이면 분리 승격" 조건 충족.

**버린 안:** 어패계 통합 값(초안) — 커뮤니티 용례가 없고, 교카이·니보시가 각각 5곳을 넘는다.

## 4. 토마토를 스프 값으로 승격 (2026-09-02)

**결정**

- 스프 값에 **토마토**를 추가한다. 초안 택소노미에 없어 `기타`로 들어가고 있었다.
- 조사 세부값 `토마토`·`토마토라멘`은 파이프라인이 스프 값 `토마토`로 승격한다(`SOUP_PROMOTIONS`).

**근거:** 시드 실측에서 토마토라멘 취급점이 서울 21곳(전문 체인 태양의토마토라멘·멘야포모·혼다라멘 등) — "5곳 이상이면 승격" 충족(PO 확정).

## 5. 아부라소바는 마제소바와 별도 형태 (2026-10-19)

**결정**

- 형태 값에 **아부라소바**를 추가한다.
- 세부값 `아부라소바`·`아부라라멘`·`아부라소바·파이탄`은 형태로 올리고 세부값에서는 뺀다(`scripts/lib/enrich.ts` `DETAIL_TO_FORM`). 메뉴명에 "아부라소바/아부라라멘/아부라멘"이 있으면 형태에 더한다(`promoteFromMenus`).

**근거**

- PO 결정: 지도 필터에서 아부라소바를 따로 찾게 한다.
- 세부값에 남겨 두면 상세 화면에 형태와 중복 노출된다.

**버린 안:** 마제소바에 통합(일본식 분류 — 국물 없는 면으로 한 계열) — 사용자가 필터로 따로 찾지 못한다.

## 6. 계보 표기는 "이에케" (2026-08-26)

**결정**

- 家系 라멘의 UI 라벨·본문·SEO 타이틀은 전부 **이에케**. 시트 값도 `이에케`.
- URL 슬러그는 로마자 `iekei`(한국어 검색과 무관).

**근거**

- 2026-08-26 구글 결과 수: "이에케" 라멘 약 50,400건 vs "이에케이" 약 4,240건 vs "이에게" 약 1,820건.
- 갤러리 최근 글: "이에케" 표기 다수("국내 이에케 추천좀", "지로이에케"), "이에케이" 0건.

**버린 안:** 이에케이(일본어 원음에 가까운 표기) — 실사용 빈도가 1/10 이하.

## 7. 무화조(無化調) 태그는 두지 않는다 (2026-08-25)

**결정:** ramendb 계보·특성 태그에 있는 무화조(화학조미료 무첨가)를 뺀다. 수요가 확인되면 추가한다.

**근거**

- 화학조미료 담론은 일본 특유의 축이다. 한국 커뮤니티에서 매장 선택 기준으로 쓰는 관찰이 없다.
- 한국 덕후 중 이 축을 쓰는 하위 그룹이 있는지는 미검증 → [조사](../research/2026-08-26-ramendb-structure-korean-terms.md) §5

## 8. "본토직영" 특성 태그를 둔다 (2026-08-25)

**결정**

- 계보·특성 태그에 **본토직영**을 둔다. 정의: **일본 브랜드가 한국에 낸 정식 지점**(라멘야 시마 서울점, 나가오 중화소바 등).
- 브랜드 단위 사실이라 체인 전 지점에 붙일 수 있다(`chainWide`) — 판정 기준은 [data-integrity 스킬](../../../../.claude/skills/data-integrity/SKILL.md).

**근거**

- 덕후에게 "본토 맛인가"는 실제 판단 축이고, 일본에는 존재할 수 없는 한국판 고유 태그로 차별화된다.
- 2026-10-27 계보 근거 재확인 때 이 정의로 코드·데이터를 통일했다(멘야하나비·태양의토마토라멘 체인 유지).

## 9. 편의 태그는 한국 실정으로 교체 (2026-08-25)

**결정**

- 편의 태그: 식권기 · 카에다마 · 원격 웨이팅 · 한정메뉴 · 심야 · 주차 · 1인 카운터.
- ramendb 편의 태그(금연·24시 이후·주차·뉴오픈·배리어프리·테이크아웃·어린이 대응) 중 금연(한국은 법으로 전면 금연이라 무의미), 배리어프리·어린이 대응(수요 축 아님)은 뺀다.
- **원격 웨이팅**(캐치테이블·테이블링 등록 여부)을 새로 둔다.

**근거:** 원격 웨이팅 등록 여부·현장 대기만인지가 한국 라멘집 방문 결정의 실질 변수다.
