# 토마토를 스프 값으로 승격한다

## 맥락

토마토라멘은 초안 택소노미에 없어 `기타`로 들어가고 있었다.

## 결정

- 스프 값에 **토마토**를 추가한다.
- 조사 세부값 `토마토`·`토마토라멘`은 파이프라인이 스프 값 `토마토`로 승격한다(`SOUP_PROMOTIONS`).

## 근거

- 시드 실측에서 토마토라멘 취급점이 서울 21곳(전문 체인 태양의토마토라멘·멘야포모·혼다라멘 등) — [0001](0001-taxonomy-axes-localization.md)의 "5곳 이상이면 승격" 충족(PO 확정).
