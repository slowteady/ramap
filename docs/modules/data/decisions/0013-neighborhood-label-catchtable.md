# 동네라벨은 캐치테이블 상권 구획의 개별 상권명

## 맥락

매장 위치를 사람이 쓰는 상권 이름으로 보여주고 지역 SEO 단위로 써야 한다. 행정동은 사람들이 쓰는 말과 다르다.

## 결정

- 동네라벨은 **캐치테이블 지역 필터의 상권 구획·명칭**을 따른다.
- 슬래시 번들 중 매장이 속한 **개별 상권명 하나**를 쓴다(성수/서울숲 → `성수` 또는 `서울숲`).
- 캐치테이블 목록에 없는 동은 가장 가까운 번들 구성원 이름으로 쓴다(자양동 → `건대`).
- 행정동·법정동 이름은 쓰지 않는다.
