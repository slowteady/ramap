# LOCALDATA 폐업은 2차 확인 없이 반영한다

## 맥락

LOCALDATA 신규·폐업 diff(`diff-localdata`)를 만들 때, 행정 데이터의 폐업 신고를 어떻게 다룰지 정했다.

## 결정

- LOCALDATA 폐업 전이는 행정 데이터라 2차 확인 없이 시트 `상태=폐업`으로 반영한다.
- 갱신 라운드 2차 검수에서 웹 "흔적 없음"이면 폐업으로 반영한다(2026-10-15 판정 규칙).
- 유저 폐업 제보만 2차 확인(전화·인스타) 후 승인한다.

## 근거

- 행정 데이터는 공식 기록이라고 봤다.

## 대체 사유

2026-10 라운드에서 "흔적 없음"으로 폐업 처리한 매장 중 4곳 이상이 실제 영업 중이었다(명의변경·재인허가로 '폐업'이 찍힌 경우). 폐업은 직접 증거로만 확정한다 → [0024](0024-폐업은-직접-증거로만-확정.md)
