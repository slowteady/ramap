# 모든 유저 기여 데이터는 검수 게이트를 거쳐 게재한다

## 맥락

데이터를 유저 기여로 늘려야 하지만, 라맵의 핵심 가치는 장르 택소노미의 정확성이다.

## 결정

- 유저가 기여한 데이터(제보·수정 제안 등)는 운영자 검수를 통과해야 매장 데이터에 들어간다.
- 개방 편집(위키식)은 채택하지 않는다.

## 근거

- 라이트 유저는 니보시와 돈코츠교카이를 구분하지 못한다. 잘못된 태깅 하나가 라오타층의 신뢰를 무너뜨린다.

## 버린 안

- 위키식 개방 편집: 택소노미 정확성을 지킬 수 없다.
