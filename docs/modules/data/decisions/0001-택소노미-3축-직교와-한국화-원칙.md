# 택소노미는 ramendb 3축 직교 구조를 한국화한다

## 맥락

라멘을 장르로 찾게 하려면 분류 체계가 먼저 필요하다. 일본 ramendb는 30년 가까이 다듬은 분류를 갖고 있지만, 한국은 매장 수가 수백 곳 규모이고 겸업이 흔하다.

## 결정

- 축: ① 제공 형태 ② 스프 계열 ③ 계보·특성 태그 ④ 편의·운영 태그. ①②③은 서로 직교한다(이에케 = 돈코츠쇼유 스프 + 계보 태그 이에케).
- 한국화 원칙 3개
  1. **필터 실효성:** 분류값은 눌렀을 때 결과가 최소 5곳 이상 나와야 존재한다. 시작은 얕게, 데이터가 차면 승격한다(내부 세부값 → 5곳 넘으면 분리 승격).
  2. **커뮤니티 용어:** 값 이름은 번역어가 아니라 한국 라멘 덕후가 실제 쓰는 말(갤러리 용어 기준).
  3. **한국 시장 구조:** 겸업(돈코츠+츠케멘+마제소바 동시 취급)이 흔하므로 매장당 단일 값을 강제하지 않는다 → [0002](0002-형태와-스프는-복수-허용과-대표값.md).
- 오픈일을 1급 데이터로 둔다.

## 근거

- ramendb 실구조 분석(Wayback 스냅샷): 3축 직교라 경계 사례가 없다(츠케멘×돈코츠교카이 성립). 오픈일이 매장 1급 필드 → [조사](../research/2026-08-26-ramendb-구조와-한국-용어-실측.md)
- 일본의 12개 스프 값을 그대로 옮기면 한국(전국 수백 곳)에서 빈 필터가 양산된다.
- supleks가 카레·교자·우동·소바 DB를 형제 사이트로 운영 — 같은 구조의 멀티 버티컬 확장이 검증돼 있다.

## 버린 안

- ramendb 값 그대로 이식: 빈 필터 양산.
