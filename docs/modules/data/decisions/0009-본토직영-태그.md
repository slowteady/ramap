# "본토직영" 특성 태그를 둔다

## 맥락

일본 라멘 브랜드의 한국 진출(라멘야 시마 서울점, 나가오 중화소바 등)이 늘고 있다. 덕후에게 "본토 맛인가"는 실제 판단 축이다.

## 결정

- 계보·특성 태그에 **본토직영**을 둔다. 정의: **일본 브랜드가 한국에 낸 정식 지점**.
- 브랜드 단위 사실이라 체인 전 지점에 붙일 수 있다(`chainWide`) — 판정 기준은 [data-integrity 스킬](../../../../.claude/skills/data-integrity/SKILL.md).

## 근거

- 일본에는 존재할 수 없는 한국판 고유 태그로 차별화된다.
- 2026-10-27 계보 근거 재확인 때 문서 정의로 코드·데이터를 통일했다(멘야하나비·태양의토마토라멘 체인 유지).
