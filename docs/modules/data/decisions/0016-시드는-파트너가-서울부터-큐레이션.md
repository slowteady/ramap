# 시드는 파트너가 서울 핵심 상권부터 큐레이션한다

## 맥락

출시 전 매장 데이터를 어떻게 채울지 정해야 했다.

## 결정

- 운영자가 전국을 채우지 않는다. 시드는 서울 핵심 상권 50~100곳이면 충분하고, 나머지는 커뮤니티 기여가 채운다.
- 상호·주소·좌표·오픈일은 LOCALDATA 인허가에서 키워드로 추출하고(`seed-candidates`), 태깅은 파트너가 온라인 조사로 구글시트에 입력한다.
- 작업 순서: 아는 집(확정) → 유명한데 안 가본 집(인스타로 추정 태깅) → 시딩 목록 나머지. 물량 목표 수도권 300곳(매장당 확정 3~5분·추정 ~10분, 주 5시간 기준 6~10주).

## 근거

- 한국 라멘 전문점은 수백 곳 규모라 좁은 도메인이다. 아는 집 100곳이 추정 300곳보다 가치 있다고 봤다.
