# data 요구사항

전국 라멘 매장 데이터를 장르로 찾을 수 있게 모으고, 정확하게 유지한다.

## 원칙

| 원칙 | 요구 |
|---|---|
| 정확성 우선 | 틀린 정보보다 빈 정보가 낫다. 같은 가게·같은 체인이라는 근거가 없으면 비운다 → [결정](decisions/0020-정보는-같은-가게-같은-체인에만-승계.md) |
| 검수 게이트 | 유저 기여 데이터는 운영자 검수를 거쳐 게재한다. 개방 편집은 하지 않는다 → [결정](decisions/0015-유저-기여는-검수-게이트를-거친다.md) |
| 타사 데이터 경계 | 지도사 지오코딩 결과 저장 금지, 네이버·카카오 크롤링 금지, 인스타 직접 조회·스크래핑 금지, 타인 사진 금지 → [공통 결정](../../decisions/0002-타사-플랫폼-데이터-경계.md) |
| 디깅 저작권 | 디깅 글은 존재를 아는 단서로만. 서술 복사·목록 배열 이식 금지 → [결정](decisions/0018-디깅-소스-저작권-경계.md) |
| 사진 | 사진 없이 시작하고 매장 공식 인스타 아웃링크로 대신한다. 직접 촬영·허락받은 사진만 쌓는다 |

## 택소노미

- 4축: 제공 형태 · 스프 계열 · 계보·특성 태그 · 편의·운영 태그. 앞의 셋은 서로 직교한다 → [결정](decisions/0001-택소노미-3축-직교와-한국화-원칙.md)
- 분류값은 결과가 5곳 이상일 때만 둔다. 미달 값은 내부 세부값으로 보관하고 5곳을 넘으면 승격한다.
- 값 이름은 한국 커뮤니티 실사용어로 쓴다(니보시·이에케·츠케멘).
- 형태·스프는 매장당 복수 + 대표 1개 필수 → [결정](decisions/0002-형태와-스프는-복수-허용과-대표값.md)
- 계보(이에케·지로계)는 대표 라멘이 그 계보인 가게에만 붙인다 → [결정](decisions/0011-계보는-대표-라멘-기준.md)
- 현재 값 목록은 [design.md](design.md#택소노미)

## 매장 필드

수집 대상: 상호·지점명 / 도로명 주소·좌표·시·구·동네라벨 / 영업시간·브레이크·휴무 / 오픈일 / 상태·상태변경일 / 형태·스프·세부·계보·편의 / 태깅확신도 / 대표메뉴(최대 3개, 이름·가격) / 좌석 / 한줄소개 / 인스타·네이버플레이스·웨이팅링크 / 검증상태·최종확인일·정보출처·메모.

- 좌표는 공공데이터(LOCALDATA·상가정보) 또는 수동 핀만.
- 오픈일은 인허가일 기준, 실제 오픈일이 확인되면 교체한다. 신규 오픈 표시의 원료다.
- 대표메뉴는 장르 판별 근거이자 가격대·SEO 원료다. 전체 메뉴판은 수집하지 않는다.
- 동네라벨은 캐치테이블 상권 구획의 개별 상권명, 행정동 이름 금지 → [결정](decisions/0013-동네라벨은-캐치테이블-상권명.md)
- `검증상태=운영자확인`은 사람이 실제 검수했을 때만. 자동 신뢰도는 태깅확신도가 맡는다 → [결정](decisions/0014-운영자확인은-사람-검수일-때만.md)
- 정기 휴무는 후기 2건 이상 일치할 때만 채운다 → [결정](decisions/0028-정기-휴무는-후기-2건-일치로-채택.md)
- 인스타는 지점 계정 → 브랜드 공식 계정 → 비움 → [결정](decisions/0027-인스타-링크는-지점-브랜드-비움-순.md)

## 시드·게재

- 후보는 공공데이터 보편 추출(LOCALDATA ∪ 상가정보) + 디깅 보강으로 만든다 → [결정](decisions/0017-시드는-보편-추출과-디깅-보강-2층.md)
- 웹 실존 신호가 있고 좌표가 있으며 위치가 확실한 매장만 게재한다. 라멘집이 아니면 제외 → [결정](decisions/0019-게재-게이트는-웹-실존-신호.md)
- 데이터 스키마는 시트 헤더와 1:1이고, 검증 문제가 하나라도 있으면 반영하지 않는다 → [결정](decisions/0012-시트-스키마가-매장-데이터-스키마.md)
- 재생성 후 소실·계보 변경은 한 곳도 빠짐없이 사유를 확인해야 반영한다(data-integrity 스킬).

## 갱신·폐업

- 격주로 LOCALDATA 전국본과 대조해 신규·폐업 전이·미발견·이전 의심을 뽑고 웹 근거로 2차 검수한다 → [결정](decisions/0022-갱신-라운드는-LOCALDATA-전국본-대조.md), [결정](decisions/0025-2차-검수-수단-고정.md)
- 자동 루틴은 검토 자료까지만 만들고 반영은 사람이 한다 → [결정](decisions/0026-격주-루틴은-검토-자료까지.md)
- 폐업은 행 삭제가 아니라 상태 변경이다.
- 폐업은 직접 증거로만 확정하고, 장부에 오른 매장만 폐업·이전 페이지를 공개한다 → [결정](decisions/0024-폐업은-직접-증거로만-확정.md)
- 같은 가게 중복 행을 합치면 지운 id는 남긴 id로 영구 리다이렉트해 색인·공유 링크를 지킨다.
- 매장 내용이 바뀐 날만 사이트맵 lastmod를 올린다.
