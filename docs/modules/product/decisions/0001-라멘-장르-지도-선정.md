# 라멘 장르 지도를 만들 서비스로 선정

## 맥락

수익이 아닌 트래픽 경험·완주·포트폴리오를 목표로 1~2인이 만들고 운영할 서비스를 찾았다.

## 결정

"한국 라멘을 장르로 찾는 지도"(라맵)를 만든다.

## 근거

- 2개 라운드 멀티에이전트 조사로 대안 아이디어 63개를 발굴·검증한 결과 채택 ([5각도 탐색](../research/2026-08-25-니즈있고-소프트웨어없는-분야-5각도-탐색검증.md), [2라운드 탐색](../research/2026-08-25-소비취미도메인-2라운드-탐색검증.md))
- 경쟁 구도가 가장 깨끗하다: 죽은 선행자 1개(라멘GPS — 월 방문 수천 이하, 체류 21초, 커뮤니티 언급 0)
- 재미(완주 동기) + 도메인 파트너 + 지표를 동시에 통과한 유일 후보
- 일본에 30년 검증된 원형이 있다: 라멘데이터뱅크(1996 → 2005 법인화), ramendb.supleks.jp — 타임머신 모델
- 이 선정이 통과한 판별 규칙
  1. 공백은 수요 축(상황·목적)이 아니라 **공급 축의 깊이**(고유 분류 체계)에 있다
  2. 데이터 3층 구조: 공공데이터 시딩 + 팀이 감당할 고유 속성 구축 + 유지해줄 덕후 커뮤니티
  3. "없는 것 같다"는 믿지 않는다 — 반드시 검증 검색(조사에서 3회 반증됨)
