# 수익 없이 비용 구조로 지속한다

## 맥락

수익은 목표가 아니다. 이 단계의 질문은 "수익 없이 성립하는가"이고, 답은 비용 구조에 있다.

## 결정

- 운영비를 연 2만 원(도메인) + 팀의 시간으로 묶는다. 지도 API·호스팅은 무료 티어 안에서 쓴다
- 수익화 옵션은 설계만 하고 켜지 않는다: 애드센스 배너, 어워드 스폰서(3막)

## 근거

- 사이드 프로젝트 사망 원인 2위(서버비 부담)를 원천 제거 → 수익 압박 없이 무기한 지속 가능
- 지도 API: 카카오 JS SDK 무료 쿼터, 초과 시 차단형 — 과금이 불가능한 구조
- 애드센스는 카카오 약관 위반이 아님을 공식 확인(상업 활용 시 비즈앱 전환 권고). 그러나 월 10만 PV여도 월 수만 원 수준 — UX를 해칠 가치가 없다
- 사업 규모 판정: 한국 라멘 전문점은 수백~천 개 규모 추정이라 사업이 아니라 트래픽 있는 사이드 프로젝트가 현실적 상한이며, 선언된 목표와 정합 ([시장 규모](../research/2026-08-26-시장규모.md))
