# 서비스명 "라맵", 도메인 ramap.kr

## 맥락

브랜드 이름 후보를 비교했다. 장기적으로 면 요리 전반(2막)으로 넓힐 가능성이 있다.

## 결정

- 서비스명 **라맵**, 도메인 **ramap.kr**
- 브랜드는 라멘 전용, 아키텍처(DB 스키마)는 다중 버티컬로 설계한다
- 보험으로 noodlemap.kr을 2막 대비 병행 등록한다(연 2만 원 옵션)

## 근거

- 라오타에게 "내 것"으로 읽히는 비치헤드 정합성
- 확장 시 리브랜딩은 싸고 스키마 마이그레이션은 비싸다
- ramap.kr·noodlemap.kr 모두 2026-08-25 미등록 확인

## 버린 안

- **누들맵** — 종합 포털로 읽혀 1막 정체성 희석 + 한국인은 "누들"로 검색하지 않음
- **누들로그** — "로그"는 기록·리뷰를 약속하는 이름인데 당시 MVP에 리뷰·기록 없음(이름-제품 불일치)
