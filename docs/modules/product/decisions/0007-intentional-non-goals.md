# 의도적으로 안 하는 것 (YAGNI)

## 맥락

MVP가 검증할 핵심 가설은 "라오타는 장르 필터가 있는 검증된 라멘 DB에 반응한다(방문하고, 커뮤니티에 공유하고, 제보한다)"이다. 이 검증에 필요 없는 기능은 뺀다.

## 결정

| 안 하는 것 | 언제 다시 보나 |
|---|---|
| 리뷰·평점 | 3막 이후 |
| 예약·주문 연동 | 하지 않음 |
| 네이티브 앱 | 하지 않음 — 웹 우선 |
| 어워드 | 3막 |
| 면 확장 버티컬(평양냉면·우동·소바) | 2막 |
| 수익화 | 켜지 않음 ([0005](0005-no-revenue-sustainability.md)) |

## 근거

- 리뷰·평점: 콜드스타트 함정
- 예약·주문 연동: 수익이 목표가 아니다
- 앱: SEO가 트래픽 엔진이므로 웹 우선
