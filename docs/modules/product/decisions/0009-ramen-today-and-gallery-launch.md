# 라멘 투데이와는 제휴를 우선하고, 갤러리 공개는 그 플레이북으로 한다

## 맥락

DC 라멘 미니갤러리는 1차 타깃(코어 라오타)이 모이는 곳이다. 갤 유저가 2026-03 개설한 영업 변동 사이트 "라멘 투데이"(ramentoday.xyz)가 파딱(운영진) 허락을 받아 공지에 고정돼 있고, 제보 루프가 실제로 돌고 있다(조회 8,922 / 추천 31 / 댓글 45). 라멘 투데이가 갤러리 침투에 성공한 공식이 공지에 그대로 남아 있다.

## 결정

### 라멘 투데이와의 관계

- 라멘 투데이는 경쟁자가 아니라 보완재로 대한다. **경쟁 금지, 제휴 우선**
- 갤러리 공개 후 신뢰를 확보한 상태에서 운영자에게 상호 링크를 제안한다. 라맵 매장 페이지에서 라멘 투데이 링크·연동을 제안할 수 있다
- 운영자가 DB·지도로 확장할 가능성은 모니터링한다

### 갤러리 공개 플레이북

1. **파딱 사전 허락** — 제목에 "(파딱허락o)" 표기
2. **세줄요약 + 겸손한 톤** — "만들어봤습니다", 광고 없음 선언, 서버비 언급
3. **제보 마찰 최소화** — 가게명·링크만 받고 나머지는 운영자가 정리
4. **피드백 채널 개방** — 댓글로 받고 주기적 반영 약속

공개 글 제목 형식: "(파딱허락o) 장르별로 라멘집 찾는 지도 만들어봤습니다".

## 근거

- 축이 다르다: 라멘 투데이 = 실시간 변동 게시판 / 라맵 = 정적 장르 DB + 지도 + SEO
- 겹치지 않는 것: 장르 필터, 지도, 매장 페이지, 검색 유입. 겹칠 수 있는 것: 신규 오픈·영업 정보 축
- 커뮤니티는 자기들 도구를 밀어낸 신참을 용서하지 않는다 — 라멘 투데이를 존중하는 포지션이 필수
- 확장 리스크는 낮게 평가: 5개월째 좁은 스코프 유지 + 겸손 운영
- 무허가 홍보는 사망. 뉴비 계정으로 사이트를 던지면 죽는다 — 파트너 계정의 신뢰 축적이 먼저
- 갤에는 바이럴·광고·인플루언서·외부인 유입에 대한 반감이 강하다 — "라오타가 쓰는 도구"로서 데이터 정확성과 제보 루프를 앞세워야 한다 ([라멘갤 페인포인트 조사](../research/2026-10-28-ramengal-pain-points.md) §4)
