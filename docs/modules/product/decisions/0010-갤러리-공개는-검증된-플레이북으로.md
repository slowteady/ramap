# 갤러리 공개는 라멘 투데이가 검증한 플레이북으로 한다

## 맥락

DC 라멘 미니갤러리는 1차 타깃(코어 라오타)이 모이는 곳이다. 라멘 투데이가 갤러리 침투에 성공한 공식이 공지에 그대로 남아 있다.

## 결정

1. **파딱 사전 허락** — 제목에 "(파딱허락o)" 표기
2. **세줄요약 + 겸손한 톤** — "만들어봤습니다", 광고 없음 선언, 서버비 언급
3. **제보 마찰 최소화** — 가게명·링크만 받고 나머지는 운영자가 정리
4. **피드백 채널 개방** — 댓글로 받고 주기적 반영 약속

공개 글 제목 형식: "(파딱허락o) 장르별로 라멘집 찾는 지도 만들어봤습니다".

## 근거

- 무허가 홍보는 사망. 뉴비 계정으로 사이트를 던지면 죽는다 — 파트너 계정의 신뢰 축적이 먼저
- 갤에는 바이럴·광고·인플루언서·외부인 유입에 대한 반감이 강하다 — "라오타가 쓰는 도구"로서 데이터 정확성과 제보 루프를 앞세워야 한다 ([라멘갤 페인포인트 조사](../research/2026-10-28-라멘갤-페인포인트-조사.md) §4)
