# 라멘 투데이와 경쟁하지 않고 제휴를 우선한다

## 맥락

DC 라멘 미니갤러리 유저가 2026-03 개설한 영업 변동 사이트 "라멘 투데이"(ramentoday.xyz)가 파딱(운영진) 허락을 받아 공지에 고정돼 있고, 제보 루프가 실제로 돌고 있다(조회 8,922 / 추천 31 / 댓글 45).

## 결정

- 라멘 투데이는 경쟁자가 아니라 보완재로 대한다. **경쟁 금지, 제휴 우선**
- 갤러리 공개 후 신뢰를 확보한 상태에서 운영자에게 상호 링크를 제안한다. 라맵 매장 페이지에서 라멘 투데이 링크·연동을 제안할 수 있다
- 운영자가 DB·지도로 확장할 가능성은 모니터링한다

## 근거

- 축이 다르다: 라멘 투데이 = 실시간 변동 게시판 / 라맵 = 정적 장르 DB + 지도 + SEO
- 겹치지 않는 것: 장르 필터, 지도, 매장 페이지, 검색 유입. 겹칠 수 있는 것: 신규 오픈·영업 정보 축
- 커뮤니티는 자기들 도구를 밀어낸 신참을 용서하지 않는다 — 라멘 투데이를 존중하는 포지션이 필수
- 확장 리스크는 낮게 평가: 5개월째 좁은 스코프 유지 + 겸손 운영
