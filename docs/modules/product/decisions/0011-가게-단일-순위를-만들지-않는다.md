# 가게 단일 순위·티어, 광고·협찬 노출, 실시간 줄 길이를 하지 않는다

## 맥락

라멘갤에서 가장 많이 읽히는 글은 티어리스트 같은 정리글이다(개념글 조회 1.8~2.5만). 순위를 만들면 유입은 늘 수 있다.

## 결정

- 가게 단일 순위·티어를 만들지 않는다. 대신 장르별 대표 매장 모음처럼 **기준을 밝힌 큐레이션**으로 답한다
- 광고·협찬을 노출하지 않는다
- 실시간 줄 길이를 표시하지 않는다(사용자 제보가 쌓이면 재검토)

## 근거

- 단일 순위는 갤 안에서도 갈린다 — 티어리스트끼리 같은 가게가 S급에서 꼴찌까지 갈리고 신뢰 논쟁을 부른다
- 후기·순위 불신(바이럴·인플루언서·다중 계정 의심)과 광고 반감이 강하다
- 줄 길이는 정적 데이터로 알 수 없다
