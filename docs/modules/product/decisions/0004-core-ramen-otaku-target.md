# 초기 타겟은 코어 덕후(라오타) 단독

## 맥락

라멘 소비자는 코어 덕후(A, 수백~수천 명)·라이트 애호가(B, 수만 명)·일반 소비자(C, 수십만 명)로 나뉜다.

## 결정

초기 타겟은 A 단독. B는 SEO 롱테일로 자연 유입시키는 2차 타겟. C는 타겟이 아니다.

## 근거

1. **데이터 생산자가 A뿐** — 장르 판별 가능한 유일한 집단. 제보·검증 모델의 전제
2. **A가 유통망** — 덕후의 커뮤니티 공유가 B에 도달하는 유일한 무료 경로. 역방향(B → A)은 성립하지 않는다: A는 어설픈 데이터에 신뢰를 거둔다
3. **A의 인정이 해자** — 택소노미 정확성은 A만 검증 가능, 통과하면 후발주자가 흉내 못 낸다
- 페인 강도: 일반 소비자에겐 Vitamin이나 코어 덕후에겐 반복 발생하는 실제 불편(Vitamin~Painkiller 사이)
- C는 "근처 라멘 맛집" 검색으로 충분 — 네이버로 해결된다
