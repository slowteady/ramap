# 제품 요구사항

## 정의

> **"한국 라멘을 장르로 찾는 지도"** — 돈코츠·쇼유·이에케이·지로계·츠케멘 등 라멘 덕후가 실제로 고르는 기준 그대로 전국 라멘집을 필터하는, 검증된 라멘 전문 DB.

- 포지셔닝: "일본에 30년 있던 것(ramendb)의 한국 첫 버전"
- 서비스명 **라맵**, 도메인 **ramap.kr**. 브랜드는 라멘 전용 → [0003](decisions/0003-서비스명-라맵.md)
- 선정 근거 → [0001](decisions/0001-라멘-장르-지도-선정.md)

## 프로젝트 목표 (수익 아님)

1. **트래픽 경험** — SEO 기반 오가닉 유입을 만들고 성장시켜 본다
2. **자아실현·완주** — 실제로 사람들이 쓰는 것을 만들어 운영한다
3. **포트폴리오** — 실유저·실트래픽·데이터 파이프라인·의사결정 기록을 갖춘 운영 프로젝트

## 팀

| 역할 | 책임 |
|---|---|
| 빌더 1명 | 개발 전반. 라이트 라멘 소비자(B) 관점 — 택소노미가 덕후만 아는 암호가 되는 것을 거르는 1차 필터 |
| 도메인 파트너 1명 (라오타, 공동 제작자) | 택소노미 설계·장르 태깅·커뮤니티 침투. 페르소나 A 본인 — 검증 접근 경로 |

## 문제

라멘 소비자가 **장르·속성(돈코츠/쇼유/이에케이/지로계, 면 굵기, 스프 농도, 주문 방식 등) 기준으로 라멘집을 찾을 수단이 없다.** 네이버·카카오는 이 축을 제공하지 않고, 정보는 커뮤니티·블로그·인스타에 파편화돼 있다. "맵 부재"가 아니라 "분류 체계 부재"다 → [0002](decisions/0002-문제를-분류-체계-부재로-정의.md)

문제의 실재 증거:

- DC 라멘 미니갤러리 유저가 자작 지도(「라멘 뉴비가 서울 라멘 지도 만들었어!」)와 자작 영업 변동 사이트(라멘 투데이, 공지 고정·제보 루프 작동)를 만들었다 — 커뮤니티가 스스로 도구를 만들고 유지한다
- 장르별 라멘 연말결산 블로그 존재 — 돈코츠/쇼유/시오/츠케멘 분류가 이미 커뮤니티 표준어
- 타베로그 도쿄 라멘 1위 '라멘야 시마' 서울 진출 — 시장 성숙 신호
- 라멘갤 최근 6개월 글 25,195건 중 질문·추천 요청 31%, 그중 장르·스타일 21%·지역 15%·웨이팅 14% ([라멘갤 페인포인트 조사](research/2026-10-28-라멘갤-페인포인트-조사.md))

진짜 경쟁자는 네이버 지도 저장 리스트 + 구글 마이맵 + 인스타 해시태그 + 갤러리 스크랩이다. 라맵은 이들이 구조적으로 못 하는 것 — 정규화된 장르 필터, 크로스 리스트 통합, 신규 오픈 추적 — 을 제공해야 한다.

## 타겟

| 세그먼트 | 규모 | 페인 강도 | 기여 의향 | 특징 | 위치 |
|---|---|---|---|---|---|
| **A. 코어 덕후 (한국형 라오타)** | 수백~수천 명 | ◎ | ◎ | DC 미니갤·트위터 라멘계. 장르 용어 구사, 신규 오픈 추적, 원정 방문, 자기 리스트 보유 | **초기 타겟** |
| B. 라이트 애호가 | 수만 명 | ○ | △ | 월 2~4회 소비, "츠케멘이 뭔지 아는" 수준. 소비만 하고 기여 안 함 | 2차 — SEO 롱테일로 자연 유입 |
| C. 일반 소비자 | 수십만 명 | △ | ✕ | "근처 라멘 맛집" 검색으로 충분 — 네이버로 해결 | 타겟 아님 |

근거 → [0004](decisions/0004-초기-타겟-코어-라오타.md)

페르소나:

> 20대 후반~30대 중반, 수도권 거주. 월 4회+ 라멘 소비, 신규 오픈을 트위터·갤러리에서 추적. 네이버 저장 리스트에 라멘집 30개+.
> **불편:** 저장 리스트에 장르 구분이 안 되고, 남의 리스트와 합칠 수 없고, 신규 오픈을 놓친다.
> **원하는 것:** 내 기준(장르·지역·미방문)으로 필터 가능한, 신뢰할 수 있는 전국 라멘 DB.

## 가치 제안

| 기존 대안 | 못 하는 것 | 라맵 |
|---|---|---|
| 네이버·카카오 지도 | "라멘" 검색만, 장르 축 없음 | 장르·면·스프·주문방식 필터 |
| 라멘GPS | 데이터 얕음, 검증 없음, 신뢰 0 | 라오타 감수 태깅 + 제보·검증 루프 |
| 갤러리 자작 지도 | 갱신 안 됨, 필터 불가 | 지속 갱신되는 구조화 DB |
| 인스타 저장·블로그 | 파편화, 검색 불가 | "성수 이에케이" 조합 검색 |

해자:

1. **택소노미** — ramendb 30년 분류 체계의 한국화(제공 형태 × 스프 계열 × 계보·특성 태그 3축). 네이버가 못 베끼는 게 아니라 **만들 이유가 없는** 축
2. **검증된 태깅** — 장르 판별은 라오타만 가능. 데이터 자체가 해자
3. **신규 오픈 추적** — 덕후 최대 관심사이자 재방문 훅

## 범위

MVP가 검증할 핵심 가설: **"라오타는 장르 필터가 있는 검증된 라멘 DB에 반응한다(방문하고, 커뮤니티에 공유하고, 제보한다)."** 이 검증에 필요 없는 기능은 넣지 않는다.

### MUST

| 기능 | 요구 | 현재 |
|---|---|---|
| 라멘 DB | 장르·속성 태깅을 끝낸 300곳+ 상태로 공개(콜드스타트는 팀이 채운 데이터로 → [0008](decisions/0008-콜드스타트는-팀이-채운-데이터로.md)) | 충족 — `data/shops.json` 1,332행(영업 1,289·폐업 43), 전국 |
| 지도 뷰 + 장르 필터 | "지도에서 이에케이만 보기"가 핵심 경험. 카카오 JS SDK, 마커·클러스터링 | 충족 — 홈 `/` |
| 매장 상세 (SSR) | 장르·속성·기본정보 + 구조화 데이터 마크업 — SEO 단위 | 충족 — `/shop/[slug]` |
| 지역×장르 페이지 | "성수 츠케멘" 류 롱테일 — 트래픽 엔진, 지도는 lazy-load | 충족 — `/area/[area]`, `/area/[area]/[genre]` |
| 제보·수정 폼 | 로그인 없이 제출 → 운영자 승인. 유저 검증 루프의 최소형 | 충족 — `/report`, 검수 `/admin` |
| 완식·저장 기록 | 완식(먹은 집)·저장(가고 싶은 집) 2상태, 날짜 저장. 기록은 카카오 로그인 필요(열람은 비로그인) | 충족 — 마이 `/me` |

## 성장 전략

- **뼈대:** 코어 라오타(SOM, 수백~수천 명)를 잡으면 장르 인지 라이트층(SAM, 수만 명)이 SEO로 따라온다. 일반 소비자는 목표가 아니다 ([시장 규모](research/2026-08-26-시장규모.md))
- **유통 채널:** DC 라멘 미니갤러리. 공개는 검증된 플레이북(파딱 사전 허락·세줄요약 겸손 톤·광고 없음·제보 마찰 최소화·댓글 피드백 반영)으로 → [0010](decisions/0010-갤러리-공개는-검증된-플레이북으로.md)
- **라멘 투데이:** 경쟁 금지, 제휴 우선 → [0009](decisions/0009-라멘-투데이와-제휴-우선.md)
- **실행 순서:**
  1. 파트너가 갤러리에서 눈팅 + 후기 기여로 계정 신뢰 축적
  2. 데이터를 300곳+ 태깅 완료 상태로 준비 — 공개 시점에 "빈 껍데기"면 한 방에 끝난다. 갤에서 화제인 매장의 누락도 같은 신뢰 결함이다([백로그](../../backlog.md) D-11)
  3. 파딱 허락 → "(파딱허락o) 장르별로 라멘집 찾는 지도 만들어봤습니다" 공개. 광고 없음 명시, 제보 폼 안내
  4. 직후 며칠간 댓글 피드백 즉시 반영을 보여준다 — 초기 신뢰의 승부처
  5. 갤러리 공개로 신뢰를 확보한 뒤 라멘 투데이 운영자에게 상호 링크 제안
- 현재 갤러리 소개 글은 게시 전이다(PO 몫, [백로그](../../backlog.md) G-03)
