# 라멘갤 요구사항 조사 — 페인포인트·니즈·라맵이 해결할 것 (2026-10-28)

DC 라멘 미니갤러리(goodramen)는 라맵 1차 타깃(코어 라오타)이 모이는 곳이다. 2026-08 정찰(04·11번)이 "불편이 실재한다(H1)"를 확인했다면, 이번 조사는 "무엇이 얼마나 불편한가(H2)"를 글 데이터로 채운다.

## 방법

- 제목 전수: 최근 6개월 전체 글 25,195건(2026-04-27~10-28, 하루 약 140건) + 개념글 3,647건(2024-02~). 제목 키워드로 주제를 분류해 빈도·조회·댓글을 집계
- 본문 정독: 질문 유형별 댓글 상위 + 개념글(정리·불만·휴무·이벤트 등) + 도구·정리글 506건 본문을 3개 묶음으로 나눠 분석(본문 있는 글 364건, 나머지는 이미지 글이라 제목 기준)
- 갤 글은 작성자 콘텐츠라 원문 인용 대신 요지만 적는다. 수집 원문은 레포에 커밋하지 않는다

## 2. 페인포인트 (본문 분석, 빈도 순)

1. **웨이팅의 불확실성** — 현장 대기만 받는 곳, 명부·번호표·캐치테이블이 가게마다 다르고, 몇 시에 가야 먹는지 모른다. 한 시간 줄 선 뒤 재고 소진으로 끝나는 경우도 반복(본문 70건 안팎)
2. **헛걸음: 조기 마감·기습 휴무·브레이크타임** — 공지 없이 당일 휴무, 재료 소진 조기 마감. 지방에서 첫차 타고 온 원정자에게 특히 치명적(40건 안팎)
3. **영업 정보가 흩어져 있고 서로 다르다** — 네이버·캐치테이블은 영업, 카카오맵은 휴무처럼 앱끼리 상충. 공지가 인스타에만 있어 하나하나 뒤져야 하고, 결국 "갤을 봐야 마감인 줄 안다"(20건 안팎)
4. **처음 가면 뭘 어떻게 시킬지 모른다** — 시그니처, 염도·기름 조절, 지로 콜, 키오스크 여부(40건 안팎)
5. **입문자 염도·취향 미스매치** — "너무 짜서 포기", 입문용 순서를 묻는다(25건 안팎)
6. **후기·순위를 믿기 어렵다** — 바이럴·인플루언서·다중 계정 의심이 강하고, 티어리스트끼리도 같은 가게가 S급에서 꼴찌까지 갈린다(30건 안팎)
7. **이벤트·한정 메뉴 정보 파편화** — 날짜·가격·수량이 인스타 곳곳에 흩어져 있고, 평일 점심 이벤트는 직장인이 가기 어렵다(20건 안팎)
8. **가격 상승 체감**, **맛 기복(폼)**, **위생·사장 태도** — 반복되지만 라맵이 직접 해결할 영역은 아님

## 3. 니즈 → 라맵이 할 수 있는 것

| 니즈 | 강도 | 라맵 현재 | 할 수 있는 것 |
|---|---|---|---|
| 장르 × 지역 × 상황으로 추천 | ◎ (질문의 36%) | 장르 필터·지역 페이지·지역×장르 페이지 있음 | 상황 조건(늦게까지·브레이크 없음·월요일 영업·혼밥) 추가, 검색어에 맞춘 모음 페이지(P-01) |
| 웨이팅 방식·요령 | ◎ (질문의 14%) | 원격 줄서기 링크만 | **매장별 "웨이팅" 정보**: 방식(캐치테이블 원격/현장 명부/번호표), 접수 시작 시각, 재료 소진 여부. 실시간 줄 길이는 제외 |
| 휴무·영업 확인 | ◎ | 정기 휴무·영업시간(69%) | **휴무 요일 필터**("월요일 영업하는 곳"), **명절·연휴 휴무 모아보기**(추석 정리글 5.5천 조회), 정보 확인일 표시 |
| 처음 가는 가게 주문법 | ○ | 없음 | 상세 "주문 방법"(P-10): 대표 메뉴, 조절 옵션(염도·기름·면), 콜·키오스크 |
| 이벤트·한정 메뉴 일정 | ○ (정리글 4천 조회) | 없음 | 이벤트 피드·월간 캘린더(P-02). 수집은 격주 루틴의 라멘갤 단서 수집을 확장 |
| 입문 코스 | ○ | 가이드(장르 설명) | "입문자용"·"짠맛 약한 곳" 같은 모음(P-01) |
| 계보·관계 | △ (관계도 3.5천 조회) | 계보 태그·계보 페이지 | 계보도(P-03), 사장 출신·직계 관계 |
| 순위·티어 | 조회는 최고, 논쟁도 최고 | 없음 | **하지 않는다** — 단일 순위는 갤 안에서도 갈리고 신뢰 논쟁을 부른다. 장르별 대표 매장 모음처럼 기준을 밝힌 큐레이션으로 대체 |
| 일본 원정 | ○ | 없음 | 범위 밖(X-05 일본 확장 보류) |

## 4. 라맵에 바로 영향을 주는 발견

1. **갤에서 화제인 매장이 라맵에 없을 수 있다.** 제목 언급 상위 매장 중 맛스구·사이토라·카라미·반라이·후레쉬·소바준·시시오·코이시·아사히야·토키·라멘시미즈·마포라를 라맵 데이터에서 찾지 못했다(갤 약칭이라 다른 이름으로 있을 수도 있음). 신바야시 쇼쿠도는 후보에만 있다. 라오타가 들어와 자기가 아는 집이 없으면 "빈 껍데기"로 본다(11번 공략 문서의 경고) — 기능보다 먼저 메울 결함
2. **언급이 몰리는 매장은 소수다.** 하쿠텐(937회)·희옥·류진·나니요리·멘코지·요아케 등 상위 매장의 상세 정보(웨이팅·주문법·휴무)를 먼저 채우면 질문 대부분을 덮는다
3. **반감: 바이럴·광고·외부인 유입.** 인플루언서 쏠림과 "일반인" 유입으로 줄이 길어지는 데 대한 적대감이 강하고, 웨이팅 적은 집을 숨기려는 정서도 있다. 라맵은 광고·협찬 노출을 하지 않고, 갤 소개(G-03)는 "라오타가 쓰는 도구"로서 데이터 정확성과 제보 루프를 앞세워야 한다
4. **정보 신뢰는 "최신 확인"에서 나온다.** 앱끼리 영업 정보가 다를 때 사람들은 가장 최근 후기를 믿는다. 정보 확인일·출처 표시(P-12)가 차별점이 된다
5. 라멘 투데이(유저 자작 영업 변동 사이트)는 최근 6개월 제목 언급 0건 — 공백이 생겼을 가능성. 라맵의 폐업·휴무 정보가 그 자리를 채울 수 있다

## 5. 권장 우선순위

| 순서 | 할 일 | 이유 |
|---|---|---|
| 1 | 갤 화제 매장 누락 점검·보강(D-10) | 신뢰의 전제. 기존 파이프라인으로 바로 가능 |
| 2 | 매장별 웨이팅 정보(P-27) — 상위 언급 매장부터 | 질문의 14%, 정적 정보로 해결 가능 |
| 3 | 휴무 요일 필터 + 명절 휴무 모아보기(P-28) | 데이터 이미 있음(정기 휴무). 다음 설 연휴 전 공개 |
| 4 | 상황 조건 필터(P-29) + 검색어 맞춤 모음 페이지(P-01) | 질문의 36%를 차지하는 추천 요청에 직접 답함 |
| 5 | 주문 방법(P-10), 이벤트 피드(P-02), 계보도(P-03) | 수집 체계가 필요한 것 |

하지 않을 것: 단일 순위·티어, 광고·협찬 노출, 실시간 줄 길이 표시(정적 데이터로 불가 — 사용자 제보가 쌓이면 재검토).
