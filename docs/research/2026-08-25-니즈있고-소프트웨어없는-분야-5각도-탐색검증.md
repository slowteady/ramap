# 니즈는 있는데 소프트웨어가 없는 분야 — 5각도 탐색·검증 (2026-08-25)

## 조사 방법

멀티에이전트 워크플로 (에이전트 14개, 검색·크롤링 351회):

1. **탐색 (5각도 병렬):** 커뮤니티 불만 신호 / 덕후 도메인 / 오프라인 정보공백 / 해외 미수입 모델 / 공공데이터 방치 영역 → **34개 기회 발굴**
2. **통합·스코어링:** 중복 병합 후 6개 기준(페인 증거, 소프트웨어 공백, 분류 깊이, 1~2인 구현성, 데이터 확보, 트래픽 잠재력)으로 상위 10개 랭킹
3. **경쟁 검증:** 상위 8개에 회의론자 에이전트를 붙여 "정말 소프트웨어가 없는가"를 반박 관점으로 재검색 (실사이트 크롤링·앱스토어 API 조회 포함)

평가 전제: 2인 사이드 프로젝트(개발 1 + 도메인 파트너 1), 목표는 수익이 아닌 트래픽 경험과 완성.

## 핵심 교훈: 검증 단계가 순위를 뒤집었다

스코어링 시점의 순위와 검증 후 실질 순위가 다르다. **탐색 에이전트가 "경쟁 미발견"이라 보고한 항목 중 실제 공백은 8개 중 2개뿐이었다.** 필름 현상소(76점)는 검증에서 5ftmag.com/labs(91개 현상소, 구조화 데이터, 활발히 갱신 중)가 발견되어 탈락했다. 라멘GPS·콜키지맵 사례와 동일한 패턴 — **아이디어 단계의 "없는 것 같다"는 신뢰할 수 없다.**

## 검증 완료 후보 (실질 순위)

### 1위. 러닝 트랙(400m) 개방 정보 DB — 88점, 경쟁존재_약함

- **니즈:** 러닝 붐으로 트랙 인터벌 수요 급증. 공설운동장·대학 트랙의 개방시간·요금·재질·조명·통제일정이 파편화되어 러너들이 커뮤니티 수기 표와 전화 문의에 의존.
- **증거:** 5개 각도 중 **3개에서 독립 발굴된 유일한 항목.** 디시 러닝갤 자작 표·구글마이맵스 전국 트랙 지도, Threads 수기 리스트, 한체대 홈페이지 개방시간 문의 글.
- **분류 깊이:** 재질(우레탄/마사토)×레인 수×개방 시간대×무료/유료/구민한정×야간 조명×스파이크 허용×통제 일정.
- **경쟁:** BlackRoad(blackroad.run/tracks, 337개 트랙 목록)가 있으나 상세 페이지 직접 확인 결과 **개방시간·요금·재질·조명 전부 부재** — 라멘GPS급 얇은 목록. 러너온·런맵·런하우스 등은 코스/크루 축이라 다름.
- **리스크:** 진짜 난제는 소프트웨어가 아니라 데이터 최신성 유지(시설별 전화 확인, 통제일정 변동). BlackRoad가 필드 추가로 따라올 수 있는 위치.
- **강점:** 러닝은 국내 최대 성장 취미 — 후보 중 트래픽 잠재력 1위.

### 2위. 파워리프팅·스트렝스 짐 디렉토리 — 86점, ★공백확인★

- **니즈:** '땅데드 가능, 데드존/플랫폼, IPF 원판, 초크 허용, 파워랙 수' 조건으로 헬스장을 등록 전에 확인 불가 → 등록 후 제지·환불 분쟁 반복.
- **증거:** **나무위키 데드리프트 문서에 '등록 전에 물어보라'가 체크리스트로 정착** — 페인이 문화적 규범으로 굳어진 상태. 후보 전체에서 가장 강한 증거 형태.
- **검증 결과:** 8개 각도 검색 + curl 크롤링에도 국내 경쟁자 미발견. 유일하게 '공백확인' 판정이 가장 확실한 항목. 글로벌 PowerliftIQ(1,194개 짐, 동일 필터 체계)가 존재하나 한국 등재 2~3건 — **컨셉이 해외에서 검증됐다는 방증이기도 함.**
- **리스크:** 파워리프팅 인구가 니치라 트래픽 절대량이 러닝 대비 열위. 실제 경쟁은 커뮤니티 구전(디시 갤·오픈채팅).

### 3위. 만화카페 보유 도서 통합 검색 — 84점, 공백확인 (단, 데이터 병목)

- **니즈:** 특정 만화가 어느 만화카페에 있는지 미리 알 수 없어 헛걸음·전화 순회.
- **증거:** 커뮤니티 3곳+ 동일 질문 반복. 과거 동일 서비스가 존재했다 죽은 이력.
- **분류 깊이:** 작품 수만 종 × 지점 수백 곳의 도서관 OPAC급 매트릭스 — 후보 중 최고. '작품명+만화카페' SEO 페이지 자동 생성 구조.
- **치명적 리스크:** 장서 데이터가 폐쇄적 POS/키오스크에 갇혀 있음. **놀숲이 온라인 도서검색을 제공하다 차단한 전례** = 프랜차이즈가 데이터 공개를 원치 않는다는 신호. 크롤링이 막히면 제휴 영업 필요 → 2인 데이터+웹 전략과 결이 어긋남.

### 4위. 도서관 실시간 대출가능 통합검색 — 83점, 경쟁존재_약함 (무덤 의심)

- **강점:** 도서관 정보나루 공식 Open API로 데이터 확보 후보 중 1위. 구현 난도 최소.
- **검증 결과:** bookmarking.kr, 우리동네책(near-book.com), 웹러브 북스 등 **동일 아이디어 인디 서비스가 이미 3개+ 존재하는데 아무도 크지 못했다.** 공백이 아니라 '무덤'일 가능성 — API 진입장벽이 낮아 차별화 불가, 저빈도 유틸리티라 리텐션 부족이 원인으로 추정.

### 5위. 공공체육시설 강습·접수 통합 정보 — 80점, 경쟁존재_약함

- **강점:** 국민권익위가 2023년 대책 권고 — 페인이 국가 공식 문서화된 유일한 항목. 수영·배드민턴은 전국민 세그먼트.
- **리스크:** 수영 쪽은 '셩'(전국 1,000+ 수영장 DB, 언론 보도될 정도로 침투)이 접수일 필드만 추가하면 되는 위치. 정부 공유누리가 네이버지도·카카오톡 연계 확장 중. 수십 개 이질적 지자체 사이트 크롤러 유지보수가 2인 팀에 부담.

### 6위. 셀프세차장 속성 필터 지도 — 79점, 경쟁존재_약함 (수익화 경고)

- **검증에서 드러난 사실:** 동일 컨셉을 '세차장 찾기-내차'가 2014년에 이미 구현, 10만+ 다운로드 확보 후 **세차장 단독으론 안 돼서 유가 앱으로 피벗.** 현재 활성 경쟁자는 약하나(워시맵=가격 축, 세차광=트랙션 0), 선행자의 피벗 이력 자체가 이 아이템의 상한에 대한 경고.

### 7위. 전국 오일장(5일장) 캘린더·지도 — 77점, 경쟁존재_약함

- **강점:** 구현 노동 최소(공공데이터+날짜 로직), 연중 성립, '지역×장날' 롱테일.
- **검증 결과:** 축제모아 장터(chukjemoa.co.kr/jangteo)가 155곳, 날짜 기반 탐색·주기 필터·지도까지 이미 구현 — "한 번에 확인 못 한다"는 전제가 부분 반증됨. 공공데이터 기반이라 해자 없음.

### 8위. 필름 현상소 비교 디렉토리 — 76점, ✕경쟁존재_강함 (탈락)

- 5ftmag.com/labs가 전국 91개 현상소의 현상 종류·가격·해상도를 구조화 JSON으로 보유, 2026-05 갱신. 공백 주장 반증. Pellica·Grainium 앱도 한국어 서비스 중.

## 탈락 항목 요약 (통합 단계, 18건)

- **시즌성 사망:** 텃밭 분양, 물놀이 계곡(선행자 '물꼬' 존재), 바닥분수, 절임배추 직거래 — 연중 트래픽 불성립
- **비공개 문화 충돌:** 천체관측지, 출사 스팟 — 코어 유저의 '스팟 비공개 문화'가 DB화와 정면 충돌
- **경쟁 밀집:** 목욕탕·사우나(온탕·모두의사우나·사우나데이 3파전), 문화센터(mooncen), 수확 체험농장
- **페인/규모 미달:** K-드라마 촬영지(검색 수요≠페인), 보드게임카페, 레코드샵, 티하우스, 옷수선집(전국 수만 개 — 전수 불가), 음악 연습실, 무인민원발급기(저빈도), 유아숲, 위스키바 보틀리스트

## 라멘맵과의 비교

| 기준 | 라멘맵 | 러닝트랙 DB | 파워리프팅 짐 |
|---|---|---|---|
| 페인 증거 | 자작 지도 1건+갤러리 | 3각도 교차 발굴, 수기 표 다수 | 나무위키 규범화 (최강) |

| 트래픽 상한 | 중 (라멘 인구) | 상 (러닝 붐) | 중하 (파리프 니치) |
| 데이터 유지 노동 | 낮음 (메뉴는 잘 안 변함) | 높음 (개방시간 수시 변동) | 중 (짐 정책 가끔 변동) |

**결론:** 지표만 보면 러닝트랙·파워리프팅이 라멘맵과 동급 이상. 그러나 컨셉 맵의 병목은 데이터 수집·태깅 노동이며, 완주 확률은 도메인 파트너 유무가 결정한다. 라멘맵은 유일하게 파트너가 확보된 후보. 팀 중 러닝/리프팅 당사자가 없다면 지표 우위는 상쇄된다.

## 검증 한계

- 각 검증 에이전트가 세션 검색 예산 소진으로 앱스토어 전수·인스타 큐레이션 계정·영문 검색 일부를 미수행 — "공백확인" 판정도 100% 보장은 아님
- 셩 앱 내부에 접수일 정보 존재 여부는 앱 미설치로 미확인
- 트래픽 수치(검색량)는 미조사 — 착수 전 네이버 데이터랩 확인 필요
