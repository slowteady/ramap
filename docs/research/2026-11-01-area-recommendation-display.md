# 지역 페이지 "라맵 추천" 표시 방식 조사

[추천 후보 조사](2026-11-01-area-curation-candidates.md)로 지역별 A·B 등급을 뽑았다. 이 문서는 그 추천을 지역 페이지(`/area/[area]`)에 **무엇을, 어떻게** 보여 줄지 정하기 위한 사례·지침 조사다. `ui.md`에 따라 배치 근거는 실제 화면 캡처로 본 것만 쓴다.

표시: **[화면]** 2026-11-01 직접 캡처 / **[확인]** 원문 확인 / **[2차]** 기사·요약 등 2차 출처 / **[추측]** 출처 없는 판단

## 1. 맛집 가이드 서비스 화면

| 서비스 | 목록 카드에 보이는 것 | 추천 이유는 어디에 | 출처 |
|---|---|---|---|
| 미쉐린 가이드 | 이름 위 등급 기호 하나 + 지역 · 가격 · 요리. 평가 글 없음 | 가게 상세에 평가원 글 한 단락 | [화면] https://guide.michelin.com/kr/ko/seoul-capital-area/kr-seoul/restaurants/ramen |
| 블루리본 서베이 | 이름 · `#장르` · 주소 · 영업 상태 + 소개 글 2줄(말줄임) | 카드 안 2줄 | [화면] https://www.bluer.co.kr/search?query=라멘 |
| 캐치테이블 블루리본 탭 | 이름 위 작은 라벨 "블루리본 서울 2027"(기호 + 출처 + 연도). 필터 줄 "블루리본 ⓘ · 리본 3개 · 2개 · 1개 · 수록맛집" | ⓘ에 기준 설명, 상세 | [화면] https://app.catchtable.co.kr/ |

- 미쉐린 발표 기사는 가게마다 뽑힌 이유를 한 문장으로 쓰고(예: "통밀·녹두·황태로 만든 자가제면"), 선정 기준(1인 45,000원 이하)을 같이 밝힌다 [확인] https://guide.michelin.com/kr/en/article/michelin-guide-ceremony/the-michelin-guide-seoul-busan-2025-bib-gourmand-selection-a-culinary-journey-through-korea-s-finest-affordable-eats
- 빕 구르망 기호는 "합리적 가격의 좋은 음식" 한 가지 뜻만 가진다 [확인] https://guide.michelin.com/kr/en/article/features/all-about-bib-gourmand
- 타베로그 라멘 백명점은 지역별 100곳, 카드에는 이름 · 위치 · 휴무 · "첫 선정"만 두고, 페이지에 선정 기준과 기준일(2025-10-16)을 적는다 [확인] https://award.tabelog.com/hyakumeiten/ramen_tokyo
- The Infatuation은 모두 직접 방문했다고 밝히고 점수의 뜻을 별도 페이지로 설명한다 [확인] https://www.theinfatuation.com/ratings-explainer
- 블루리본은 등재 경로 중 하나가 유료 등록 신청이라고 공개돼 있다 [2차] https://www.venturesquare.net/1120098/

공통점: 목록 카드에는 **기호·라벨 하나**만 두고, 이유는 짧게(한 문장) 또는 상세로 보낸다. 기준은 별도 설명(ⓘ·기준 페이지)으로 공개한다.

## 2. 사용성 지침

- 대부분의 항목에 배지가 붙으면 강조 기능을 잃는다. 배지는 적게, 문구는 바로 이해되는 말로 쓰고 사내 용어는 피한다 [확인] https://baymard.com/blog/badge-ui
- 사용자는 명시적인 제목으로 추천 영역을 알아보고, 회사에 이득이 되는 추천인지 의심한다 [확인] https://www.nngroup.com/articles/recommendation-expectations/
- 목록 안 표시는 모양이 서로 달라야 빨리 구별된다 [2차] https://nngroup.com/articles/gestalt-similarity
- 추천 이유를 설명하면 수용도와 신뢰가 오른다(학술 연구) [2차] https://link.springer.com/article/10.1007/s11257-008-9051-3

## 3. 구글 검색 지침

- 리뷰 지침: 최고라고 추천하려면 왜 최고인지 근거를 함께 쓰고, 순위 목록은 그 자체로 쓸모 있을 만큼 내용을 갖춘다 [확인] https://developers.google.com/search/docs/specialty/ecommerce/write-high-quality-reviews
- 도움이 되는 콘텐츠: 누가 · 어떻게 · 왜 만들었는지 드러낸다. 남의 글 요약만 하거나 실질 변경 없이 날짜만 바꾸는 것은 나쁜 신호다 [확인] https://developers.google.com/search/docs/fundamentals/creating-helpful-content
- ItemList: 음식점은 캐러셀 대상. 페이지의 항목을 전부 넣고 순서는 `position`을 따른다 [확인] https://developers.google.com/search/docs/appearance/structured-data/carousel
- 위 지침은 순위 요소 목록이 아니라 일반 조언이다 [2차] https://developers.google.com/search/blog/2022/03/product-review-ranking-one-year-on

## 4. 법·약관

- 공정위 「추천·보증 등에 관한 표시·광고 심사지침」의 표시 의무는 경제적 이해관계(대가·무료 제공·고용 등)가 있을 때 생긴다 [2차] https://www.ajunews.com/view/20251202085042877 — 대가 없는 편집 추천은 표시 의무가 없다고 본다 [추측, 원문 미확인]
- 경쟁 음식점을 깎아내린 글이 명예훼손·업무방해로 처벌된 사례가 있다. 라맵은 라멘집과 경쟁하지 않지만, 뽑히지 않은 곳을 낮춰 보이게 하는 표현은 피한다 [2차] https://www.lawtimes.co.kr/news/196523
- 라맵 자체 제약: 근거 글 원문·사진·점수를 옮기지 않는다([타사 데이터 경계](../decisions/0002-third-party-data-boundary.md)). 출처 이름과 링크만 둔다

## 라맵에 적용할 안

| 항목 | 안 | 근거 |
|---|---|---|
| 위치 | 제목 아래 맨 위에 "라맵 추천" 구역, 그 아래 나머지 라멘집 목록. 추천된 곳을 아래에 다시 넣지 않는다 | 캐치테이블 블루리본 탭의 분리 [화면], NN/g 명시적 제목 [확인], `ui.md` "한 화면에서 같은 말을 되풀이하지 않는다" |
| 대상 | A 등급만. A가 없는 지역은 구역을 두지 않는다 | Baymard "많으면 무력화" [확인]. 현재 A는 지역당 1~5곳 |
| 라벨 | "라맵 추천" 하나. A·B 등급·점수·순위 번호는 보이지 않는다. "베스트·1위·최고"는 쓰지 않는다 | 빕 구르망 한 기호 한 뜻 [확인], 비방 위험 [2차] |
| 추천 카드 | 기존 카드(이름 · 장르 칩 · 영업 상태)에 **이유 한 줄**을 더한다. 라맵이 직접 쓴 문장(예: "라멘갤 티어글 여러 곳에서 최상위", "미쉐린 빕 구르망 2025") | 미쉐린 한 문장 [확인], 블루리본 카드 소개 [화면], 구글 "왜 최고인지" [확인] |
| 출처 | 카드에는 출처 종류만. 원문 링크는 가게 상세 페이지의 추천 이유 영역에 둔다 | 미쉐린 목록/상세 분리 [화면], 타사 데이터 경계 |
| 기준 공개 | 구역 제목 옆 ⓘ 버튼 → 기준(근거 2개 이상, 돈 받고 넣지 않음, 확인 시점) 시트. 회색 보조 설명 줄은 두지 않는다 | 캐치테이블 ⓘ [화면], 타베로그 기준일 [확인], 라맵 "회색 보조 설명 줄 금지" |
| 검색 | ItemList는 전체 목록 그대로, 추천을 앞 순서(`position`)로. 날짜는 추천이 실제로 바뀔 때만 | 구글 캐러셀 문서 [확인] |
| 광고 표시 | 필요 없음. 제휴가 생기면 그 카드 첫 부분에 한국어로 표시 | 공정위 지침 [2차] |

### 정할 것

1. 추천된 곳을 아래 전체 목록에서 뺄지(위 안) 또는 둘 다 보여 주고 아래에는 라벨만 붙일지 — 빼면 중복이 없고, 두면 전체 목록 개수와 순서가 그대로다
2. 이유 한 줄을 지역마다 사람이 쓸지, 근거 종류에서 자동으로 만들지 — 자동은 문장이 반복된다
3. 가게 상세 페이지에도 추천 이유·출처 링크 영역을 둘지

## 한계
