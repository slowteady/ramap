# 라멘집 사진·메뉴판 사진 확보 조사

매장 사진이 1,245곳 중 0곳(승인된 완식 사진 1장)이다. 다른 서비스가 사진·메뉴판 사진을 어떻게 처음 채웠는지, 사용자 등록을 어떻게 늘렸는지, 보상(기프티콘)을 걸 때 무엇이 필요한지, 사진 기여 화면을 어떻게 만들었는지 조사했다. 결정은 [0031 사용자 사진 기여](../decisions/0031-user-photo-contribution.md).

표시: **[확인]** 원문에서 봄 / **[2차]** 기사·사용기 등 2차 출처 / **[추측]** 출처 없는 판단

## 1. 시중 사진을 쓸 수 있는가

| 방법 | 판단 | 근거 |
|---|---|---|
| 블로그·인스타 사진을 그대로 가져다 쓰기 | 불가 | 찍은 사람의 사진저작물. 모으는 과정이 네이버·카카오 크롤링·인스타 스크래핑 금지([0002](../decisions/0002-third-party-data-boundary.md))에 걸린다 |
| 메뉴판의 메뉴명·가격을 글자로 옮기기 | 가능 | 사실 정보는 저작물이 아니다 |
| 원문 게시물로 링크 | 가능 | 링크는 복제가 아니다 |
| 인스타그램 공식 임베드 | 조건부 | 2026-06-15부터 토큰 없이 시간당 1,000회 [확인]. 2025-11부터 썸네일·작성자 칸 제거 [확인] → 우리 갤러리·og:image에 못 씀. 0002 예외 여부는 PO 판단 |
| 구글 Places 사진 | 부적합 | Place Photos 월 1,000회 무료 후 1,000회당 $7 [2차]. 저장 불가, 메뉴판 구분 불가. 구글 지도가 아닌 지도와 함께 쓰는 것을 약관이 막는다고 알려져 있음 [추측: 원문 미확인] |
| 네이버·카카오 장소 사진 | 불가 | 사진 공개 API 없음, 크롤링 금지 |

출처: [Meta oEmbed 업데이트](https://developers.facebook.com/blog/post/2025/04/08/oembed-updates/), [Instagram oEmbed 썸네일 제거](https://iframely.com/updates/193071-facebook-and-instagram-oembed-thumbnail-deprecation), [Google Maps Platform 가격](https://developers.google.com/maps/billing-and-pricing/pricing)

## 2. 다른 서비스는 사진을 어떻게 채웠나

| 서비스 | 처음 채운 방법 | 등록 유도 | 메뉴판 처리 |
|---|---|---|---|
| 카카오맵 | 사장님 사진(최대 100장) + 후기 사진 [확인] | 2025-07 제보 리워드: 메뉴·영업시간 사진 제보 승인 시 장소당 최대 400P, 첫 승인 1,000P 추가 [확인] | 사장님이 `#메뉴판` 태그 [확인] |
| 네이버 플레이스 | 자사 블로그 사진 자동 수집 + 사장님 + 방문자 [확인] | 영수증 리뷰 포인트(10~50원) → 2022-10 종료, 미션형으로 [확인] | AI가 메뉴·음식·풍경으로 자동 분류(2025-07) [확인] |
| 다이닝코드 | 블로그 글 링크 [확인] | 리뷰 1건 약 300원 포인트 [2차] | — |
| 배달의민족 | 사장님 등록 + 무료 촬영 지원(3년 160곳) [확인] | — | 사장님이 메뉴마다 사진 |
| 망고플레이트 | 사용자 리뷰 | '홀릭' 등급, 다작 상품 → 질 저하, 2023-10 종료 [2차] | — |
| Zomato | 창업자가 주말마다 메뉴판을 직접 스캔, 이후 직원이 하루 50~60곳 [확인] | 레벨·리더보드 | 메뉴판 스캔이 출발점 |
| Yelp | 새 도시에서 유급 작성자를 2개월 한정·공개로 [확인] | Elite 등급 | 메뉴 제휴(SinglePlatform·Locu) |
| Google Maps | 사용자 + 업주 | 방문 감지 후 "사진 올릴래요?"(첫 사진일 때 강조), 조회수 메일 [확인] | 사진 종류 'Menu' 분리, AI 메뉴 추출 [확인] |
| Untappd | 체크인 사진 | 체크인 순간에 사진 [확인] | — |
| Ramen Beast | 운영팀이 직접 1만 그릇·약 700곳 [확인] | — | 라멘집별 주문 추천 |

결론: 사용자만으로 처음부터 채운 서비스는 없다. 사장님 사진이나 운영자 직접 수집을 바탕에 깔고 사용자 사진을 쌓았다.

## 3. 보상(기프티콘)

- 효과: 돈을 주면 작성률이 오른다(약 30% → 50%, Burtch 외, Management Science 2018) [확인].
- 부작용: 질 저하·긍정 편향(Khern-am-nuai 외, ISR 2018) [확인]. 구글은 2022년 사진 2억 장 삭제, Local Guides 특전 1TB → 100GB 축소 [확인].
- 피드백 문구: "덕분에 도움을 받았어요"(이타)는 기여를 늘리고, 남과 비교하는 문구는 효과가 없었다 [확인].
- 법규
  - 추천·보증 심사지침(2024-12-01 개정): 경품·우수 후기 선정을 노린 후기도 경제적 이해관계 [확인]. 메뉴판은 평가가 아닌 사실 정보라 표시 의무 대상이 아닐 가능성이 높다 [해석]. 한줄평·별점에 보상하면 표시 대상.
  - 소득세법 제84조: 건별 기타소득금액 5만원 이하 과세최저한 [확인].
  - 공정위 경품 고시는 2016년 폐지 예고, 이후 금액 한도 없음 [확인].
  - 휴대전화번호 수집은 개인정보처리방침 개정이 먼저(지금 방침에 없음) [확인].
- 발송 수단: 카카오 선물하기 for Biz·기프티쇼 비즈 모두 사업자만 [확인]. 사업자등록 전에는 수동 발송.
- 라멘 미니갤: 부매니저 허락을 받은 서비스 소개글("라멘투데이", 2026-03)은 공지로 고정 [확인]. 이벤트 홍보글은 광고로 삭제될 위험 [해석].
- 권장 구성(조사 제안): 기간 한정, 메뉴판이 없는 곳의 첫 승인만, 승인 3곳마다 커피 1잔, 1인 월 1회, 월 선착순 15잔(약 7만원).

## 4. 사진 기여 화면 UX

| 단계 | 패턴 | 출처 |
|---|---|---|
| 입구 | 빈 상태에서 바로 올리기 버튼(NN/g 빈 상태 원칙) | [확인] NN/g |
| 입구 | 방문 직후 사진 요청 | 캐치테이블(방문 완료 알림) [확인], Google·Apple(방문 감지) [확인] |
| 입구 | 정보가 필요한 후보 장소 목록 | 카카오맵 제보 리워드 [확인] |
| 올리기 | 최대 5장, 사진 외 필수 입력 없음 | 배민 [확인] |
| 올리기 | 종류를 사용자가 고름 | 네이버 제보 항목 [확인] / Google은 사용자가 고르지 않음 [2차] |
| 로그인 | Google·Apple은 로그인 필수 [확인]. 위키 136곳이 로그인을 필수로 바꾸자 고품질 기여가 저품질보다 크게 줄었다(Hill & Shaw 2020) [확인] | |
| 제출 후 | 대기·게시 안 됨 상태 표시 | Google [2차], 카카오 마이탭 [확인] |
| 공개 | Apple은 기본 익명, 원하면 닉네임 [확인]. Google은 실명과 다른 기여까지 공개 [확인] | |
| 검수 | 그 장소 사진인지 알 수 없는 사진·체인 메뉴판 반복 제보는 제외 | 네이버 스마트플레이스 제보 운영정책 [확인] |

## 5. 따라 하지 않을 것

- 블로그 사진 자동 수집(네이버·다이닝코드) — 타인 사진 금지
- 배지·등급·리더보드 — product 금지 목록, 비교 문구는 효과 없음
- 건당 무제한 현금 보상, 한줄평·별점 보상, 라멘집이 대는 보상
- 방문 인증 필수(영수증) — 비로그인 기여와 맞지 않음
- 실명·다른 기여 기록 공개(Google), 위치정보를 남긴 공개 사진
- AI로 만든 메뉴 사진 — 실물과 다르면 식품표시광고법 위반 소지 [2차]
