# 지역 페이지 "맛집" 추천 후보 조사 (라멘집 8곳 이상 지역 23곳)

지역 페이지("망원 라멘 맛집 10곳")는 지금 그 지역의 폐업하지 않은 라멘집을 전부 보여 준다(`shopsByArea`). 평판으로 고른 목록이 아니어서, 라멘집 8곳 이상인 지역 23곳(270곳)의 평판 근거를 모았다. 지역 페이지에 "라맵 추천"을 붙일지·어떻게 붙일지 정할 때 쓴다.

## 방법

- 출처: 디시인사이드 라멘 미니갤(`goodramen`)·부산 라멘 마이너갤(`busanramen`)의 티어글·정리글·후기, 미쉐린 가이드, 언론 기사, 티스토리·브런치 등 블로그. 사람이 검색하듯 가게 이름·지역으로 찾아 읽었다
- 쓰지 않은 출처: 네이버(블로그·플레이스)·카카오맵·인스타그램 — [타사 데이터 경계](../decisions/0002-third-party-data-boundary.md)
- 등급: **A** 서로 독립된 강한 근거 2개 이상 / **B** 강한 근거 1개 또는 긍정 후기 여럿 / **C** 근거 없음. 근거 URL 없는 판정은 C
- 결과: A 42 · B 51 · C 177(270곳)
